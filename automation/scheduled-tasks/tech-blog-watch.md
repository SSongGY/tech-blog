기술 블로그 루틴이 권한 프롬프트 앞에서 멈춰 있는지 확인한다.
**짧게 끝낸다. 문제가 없으면 아무것도 하지 않는다.**

## 작업 위치

`D:\workspace\claude\tech_blog`

## 1. 멈춘 회차 찾기

```bash
cd /d/workspace/claude/tech_blog
PYTHONUTF8=1 python scripts/check_stuck.py
```

결과가 돌아오지 않은 도구 호출을 15분 넘게 붙들고 있는 세션을 찾아 준다.
`멈춘 회차 없음`이면 **여기서 끝낸다.** 더 조사하지 않는다.

## 2. 멈춘 것이 있으면 알린다

`PushNotification`으로 한 줄 보낸다. 200자를 넘기지 않는다.
무엇이 막혔는지 **행동할 수 있는 형태**로 쓴다.

좋은 예:
- `기출 회차가 40분째 멈춤 — clik.nanet.go.kr 도메인 승인 대기`
- `저녁 작성 회차가 25분째 멈춤 — Bash 명령 승인 대기`

나쁜 예: `루틴 점검 완료`, `문제 발견` (무엇을 해야 하는지 알 수 없다)

그다음 대화에도 같은 내용을 적고, **반복되는 도메인이면** `.claude/settings.json`의
`allow`에 넣을 `"WebFetch(domain:...)"` 줄을 그대로 만들어 준다.
사용자가 붙여넣기만 하면 되게 한다.

## 하지 말 것

- **승인을 대신하려 하지 않는다.** 권한 프롬프트는 그 세션에서 사용자가 답하는 것이고,
  무인 세션은 `set_session_permission_mode`를 쓸 수 없다. 시도하지 않는다
- **저장소를 고치지 않는다.** 커밋·푸시·파일 수정·`git add` 전부 금지
- **`.claude/settings.json`을 고치지 않는다.** 넣을 줄만 만들어 준다
- 멈춘 세션을 중지시키지 않는다. 승인만 되면 이어서 돈다
- 글을 대신 써주지 않는다
- 멈춘 것이 없으면 **알림을 보내지 않는다.** 매시간 울리면 알림이 무의미해진다

이 작업은 매시간 돈다. 할 일이 없으면 30초 안에 끝나야 한다.
