저장소 `D:\workspace\claude\tech_blog` 에서 주식·재무 공부 글 2편을 쓰고 커밋·푸시한다.

**절차서는 `.claude/commands/finance-daily.md` 다. 먼저 전부 읽고 그대로 따른다.**
규칙의 본체는 `CLAUDE.md` **§13 주식·재무 글** 이고, 구조·코드·도식·버전 규칙
(§2·§3·§4·§5)도 그대로 적용된다.

기술 블로그와 **별도 트랙**이다. 기술 트랙의 자리를 나눠 쓰지 않는다.

## 타협 불가

- **숫자는 가상 회사로 만든다.** 실제 기업의 재무제표를 예제로 쓰지 않는다.
  회사 이름은 `가나전자`처럼 실재하지 않는 것을 쓴다. 숫자가 분기마다 바뀌면
  글이 조용히 낡고, 특정 종목을 들면 계산 설명이 투자 권유로 읽힌다.
- **특정 종목을 사라·팔라로 읽힐 문장을 쓰지 않는다.** 지표가 높다·낮다는 사실과
  그것이 뜻하는 바까지만 쓴다. 수익률·주가 전망은 쓰지 않는다.
- **계산이 들어가면 직접 계산해 출력을 남긴다.** `code/` 에 파이썬으로 두고
  `python scripts/blog.py run-example <글 폴더>` 로 `output.txt` 를 만든다.
  본문에 싣는 숫자는 그 파일에서 가져온다. 지어내지 않는다.
- **비율의 "적정 수준"을 쓸 때는 그 기준의 출처를 밝힌다.** 근거 없이
  "부채비율 200% 이하가 건전하다" 같은 기준선을 쓰지 않는다.

## 흐름

1. 겹침 확인 — `mcp__scheduled-tasks__list_task_runs` 로 `tech-blog-daily`·
   `tech-blog-exam`·`tech-blog-concept` 를 본다. `running` 인데 `started_at` 이
   3시간을 넘었으면 돌고 있는 게 아니라 멈춘 것이다. `PushNotification` 으로
   알리고 오늘은 건너뛴다. 저장소는 건드리지 않는다.
2. `python scripts/blog.py pick-finance` — 백로그 순서가 곧 학습 순서다.
   재무제표 세 장 → 비율 → 밸류에이션. 앞질러 고르지 않는다.
3. 조사 — 회계 기준은 K-IFRS 기준서·금융감독원 회계포털·한국거래소 규정을
   1차 자료로 쓴다. 제도·규정에는 발효일을 적는다.
4. `python scripts/blog.py new <주제id> <slug>` 로 폴더를 만든다.
5. 본문을 쓰고, 계산 예제와 SVG 도식을 넣는다. 도식 아래 `> **출처**:` 줄을
   빠뜨리지 않는다.
6. `lint` → `index` → `done` 순으로 마무리하고 글마다 한 커밋으로 나눠 푸시한다.

## 명령 실행 규칙

- **Bash 도구로 실행한다.** PowerShell 도구는 허용 규칙이 없어 전부 물어본다
- **`cd` 로 작업 폴더를 옮기지 않는다.** 이미 저장소 루트에서 시작한다
- **명령 앞에 환경변수나 변수 할당을 붙이지 않는다.** 규칙이 맨 앞부분으로 맞춰 본다
- **`python -c` 로 즉석 코드를 짜지 않는다.** 필요한 일은 `blog.py` 에 명령이 있다
- **`rm`·`mv` 를 쓰지 않는다.** 버릴 파일은 이름을 `probe` 로 시작하면 gitignore 된다
- `for`·`while` 루프, `sleep` 대기, `find -exec`, 서브셸, `xargs`,
  명령 치환 `$(...)` 을 쓰지 않는다
