# 예제 코드 — xargs

외부 의존성 없다. 스크립트가 임시 폴더(`mktemp -d`)에 공백·작은따옴표·줄바꿈이 든 파일 이름과
작은 입력 파일을 만들고, `xargs` 옵션을 갈래별로 돌린 뒤 폴더째 지운다. 각 명령은 stderr를 합쳐
찍으므로 에러 메시지가 출력 순서대로 남는다.

## 실행

```bash
bash xargs_options.sh
```

확인 환경: GNU findutils 4.10.0 / GNU bash 5.3.9 (Git Bash on Windows 11).

## 각 장이 보는 것

| 장 | 확인하는 것 |
|---|---|
| 0 | 판 번호와 `--show-limits` 명령줄 길이 한도 |
| 1 | 기본 모드의 공백·따옴표·역슬래시 처리, 명령을 빼면 `echo` |
| 2 | 파일 이름을 기본 모드 / `-d '\n'` / `-0` 으로 넘길 때의 차이 |
| 3 | `-E` 논리적 끝, `-0` 과 함께면 무시되는 것, `-a` |
| 4 | `-n`·`-L`·`-l`, 줄 끝 공백이 다음 줄로 이어지는 것 |
| 5 | `-s`·`-x`, `-x` 가 `-n` 과 함께일 때만 차이를 만드는 것 |
| 6 | `-I`·`-i`, 줄 앞 공백을 지우는 것 |
| 7 | 빈 입력에서도 한 번 도는 것과 `-r` |
| 8 | `-t` |
| 9 | `-P` 가 끝난 순서로 출력하는 것, 동시 개수별 시간, `--process-slot-var`, `-P 0` |
| 10 | 종료 코드 123·124·127·1 |

## 바꿔 볼 값

- `make_files` 의 `it's.log` 를 지우면 2장 첫 명령이 따옴표 에러 없이 더 멀리 가고, 공백 든 이름에서 깨진다.
- 9장 `elapsed` 의 `sleep 0.5` 를 늘리면 프로세스를 띄우는 비용이 차지하는 몫이 줄어 `-P` 효과가 더 선명해진다.
- 10장 `exit 255` 를 `exit 1` 로 바꾸면 두 번째 항목도 돌고 종료 코드가 123 이 된다.
- 10장의 `not_exec.sh` 는 이 환경에서 권한 비트 없이도 실행돼 0 이 나왔다. 리눅스에서 돌려 126 이 나오는지 확인해 볼 부분이다.
