# 예제 코드 — openssl s_client 인증서 점검

외부 서버에 붙지 않는다. 스크립트가 사설 CA(루트 → 중간 → 서버)를 만들고
`127.0.0.1`에 `openssl s_server`를 연결 하나씩 받도록 띄운 뒤 `s_client`로 붙는다.
중간 인증서를 빠뜨린 서버, 만료된 서버, 이름이 다른 서버를 일부러 만들어 출력이 어떻게 달라지는지 본다.

키와 인증서는 `probe_pki/`에 생기고 gitignore 대상이라 저장소에 올라가지 않는다. 실행할 때마다 새로 만든다.
서버 일련번호는 매번 난수라 출력에서 가린다.

## 실행

```bash
bash cert_check.sh
```

## 바꿔볼 값

- 1절 `serve`에서 `-cert_chain inter.pem`을 빼면 2절과 같은 결과가 된다.
- 10절의 `604800`(7일)을 `60`으로 줄이면 `soon` 인증서도 통과한다.
- 7절의 `-tls1_2`를 `-tls1_3`으로 바꾸면 Protocol version 줄이 바뀐다.
