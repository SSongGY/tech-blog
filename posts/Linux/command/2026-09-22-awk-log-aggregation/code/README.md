# 예제 코드 — awk로 로그를 표로 집계하기

외부 의존성 없다. 스크립트가 10줄짜리 접근 로그(`access.log`)와 빈 줄이 섞인
CSV(`latency.csv`)를 직접 만들고, 필드 분리·패턴·연관배열·`printf`·`-v`·`-f`를
한 파일 위에서 확인한 뒤 전부 지운다.

## 실행

```bash
bash awk_aggregate.sh
```

확인 환경: GNU Awk 5.4.0 / bash 5.3.9 (Git Bash on Windows 11).

## 각 장이 보는 것

| 장 | 확인하는 것 |
|---|---|
| 1 | 기본 구분자가 연속 공백이라는 것과 `NF` |
| 2 | `-F`로 구분자를 바꾸는 것 |
| 3 | 패턴만 적으면 필터, 액션만 적으면 전체 처리 |
| 4~5 | 연관배열로 세는 것과 `for (k in arr)` 순회 순서가 정해져 있지 않다는 것 |
| 6~7 | 키 두 개로 묶어 평균을 내고 `printf`로 폭을 맞추는 것 |
| 8 | `-v`로 셸 변수를 넘기는 것 |
| 9 | 정의되지 않은 변수가 `0`이자 빈 문자열이라는 것 |
| 10 | `NR`·`FNR`·`FILENAME`이 파일 경계에서 갈리는 것 |
| 11 | 빈 줄도 레코드로 세지는 것과 `NF`로 거르는 것 |
| 12 | 같은 값이 숫자 비교와 문자열 비교에서 다르게 갈리는 것 |
| 13 | `-f`로 프로그램을 파일에서 읽는 것 |
| 14 | `exit`로 종료 코드를 정하는 것 |

## 바꿔 볼 값

- 8장의 `threshold` — 200으로 낮추면 건수가 늘어난다. 셸 변수를 `-v`가 아니라
  프로그램 안에 직접 끼워 넣으면 값에 따옴표가 들어갈 때 깨진다.
- 12장의 `$3 "" > "100"` — 뒤의 `""`를 빼면 숫자 비교로 돌아가 결과가 달라진다.
- 13장 `status_report.awk`의 `int($9 / 100)` — `$9`를 `$10`으로 바꾸면
  응답시간을 100ms 단위로 묶는 집계가 된다.
- `latency.csv`의 빈 줄 — 지우면 11장의 두 숫자가 같아진다.
