==============================================================
## 3. -A 와 -B 는 방향이 다르다

$ grep -A 2 'acquire failed' app.log
2026-09-22T09:00:05 ERROR pool  acquire failed: timeout after 5000ms
2026-09-22T09:00:05 INFO  http  GET /api/orders 500 5002ms
2026-09-22T09:00:06 INFO  pool  connection released id=17

$ grep -B 2 'acquire failed' app.log
2026-09-22T09:00:03 WARN  pool  wait time above threshold wait=812ms
2026-09-22T09:00:04 INFO  http  GET /api/orders 200 39ms
2026-09-22T09:00:05 ERROR pool  acquire failed: timeout after 5000ms

==============================================================
## 4. 줄 번호와 건수

$ grep -n ERROR app.log
5:2026-09-22T09:00:05 ERROR pool  acquire failed: timeout after 5000ms
9:2026-09-22T09:00:12 ERROR http  upstream returned 503 for /api/stock

$ grep -c ERROR app.log
2

$ grep -ic error app.log
3

==============================================================
## 5. 점은 임의의 한 글자다

$ grep -c 5.0 app.log
2

$ grep -c -F 5.0 app.log
0
(종료 코드 1)

==============================================================
## 6. 단어 경계

$ grep -c id=1 app.log
2

$ grep -c -w id=1 app.log
0
(종료 코드 1)

==============================================================
## 7. BRE / ERE / PCRE 가 같은 패턴을 다르게 읽는다

$ grep -c 'wait=[0-9]\+ms' app.log
2

$ grep -c -E 'wait=[0-9]+ms' app.log
2

$ grep -c -E 'wait=\d+ms' app.log
0
(종료 코드 1)

$ grep -c -P 'wait=\d+ms' app.log
2

==============================================================
## 8. PCRE 가 필요한 순간 — 있고 없고를 한 번에

$ grep -P '^(?=.*ERROR)(?!.*timeout)' app.log
2026-09-22T09:00:12 ERROR http  upstream returned 503 for /api/stock

==============================================================
## 9. 매칭된 부분만 뽑아 집계

$ grep -o -P '(?<= )\d{3}(?= \d+ms)' app.log
200
200
500
201
201
200

==============================================================
## 10. -c 는 줄 수지 매칭 수가 아니다

$ grep -c 00 app.log
12

$ grep -o '00' app.log | wc -l
18

==============================================================
## 11. 못 찾으면 종료 코드가 1 이다

$ grep -q FATAL app.log
(종료 코드 1)

$ grep -q ERROR app.log
(종료 코드 0)

## 12. 여러 파일과 재귀 — 파일 이름이 언제 붙는가

$ grep -r -l ERROR grep_demo_tree

$ grep -r -L ERROR grep_demo_tree
