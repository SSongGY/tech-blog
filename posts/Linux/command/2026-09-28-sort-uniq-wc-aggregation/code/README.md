# 예제 코드 — sort, uniq, wc

외부 의존성 없다. 스크립트가 접속 IP 10줄, CSV, 크기·버전·월 목록 같은 작은 샘플 파일을 직접
만들고, `sort`·`uniq`·`wc`의 옵션을 하나씩 돌린 뒤 전부 지운다.

## 실행

```bash
bash sort_uniq_wc.sh
```

확인 환경: GNU coreutils 8.32 / bash 5.3.9 (Git Bash on Windows 11).

## 각 장이 보는 것

| 장 | 확인하는 것 |
|---|---|
| 1 | 로케일에 따라 기본 정렬 순서가 바뀌는 것 |
| 2~3 | `-n`·`-g`·`-h`·`-V`·`-M`·`-r` 이 값을 어떻게 읽는가 |
| 4 | `-f`·`-b`·`-d`·`-i` 가 비교 전에 무엇을 무시하는가 |
| 5 | `-k` 의 끝 위치를 생략하면 키가 줄 끝까지 늘어나는 것 (`--debug`) |
| 6 | `-s` 가 마지막 전체 줄 비교를 끄는 것 |
| 7 | `-u` 가 키 기준으로 첫 줄만 남기는 것 |
| 8 | `-c`·`-C` 의 종료 코드 |
| 9 | `-m` 병합, `> 같은파일` 이 파일을 비우는 것과 `-o` |
| 10~11 | `-z`, 재현 가능한 `-R`, 결과를 바꾸지 않는 자원 옵션 |
| 12~14 | `uniq` 가 인접한 줄만 비교하는 것과 각 옵션 |
| 15~16 | `wc` 가 개행을 센다는 것, 바이트와 문자, 출력 모양 |

## 바꿔 볼 값

- `make_files` 의 `ip.txt` 순서 — 같은 IP 를 붙여 두면 12장의 `uniq -c` 가 `sort` 없이도 맞는 숫자를 낸다.
- 5장의 `-k2,2` — `-k2` 로 바꾸면 같은 부서 안에서 급여 문자열까지 비교에 들어간다.
- 15장의 `LC_ALL` — `C` 에서는 `-m` 이 바이트 수와 같아진다.
- `seed.bin` 내용 — 바꾸면 10장 `-R` 의 순서가 바뀌고, 같은 파일을 쓰는 동안은 매번 같다.
