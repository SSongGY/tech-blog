== 강한 ETag (서버의 ETag = "v1-abc")
요청 헤더                                                    상태  본문
----------------------------------------------------------------------
(조건 헤더 없음)                                               200   26B
If-None-Match: 같은 강한 태그                                  304   0B
If-None-Match: 같은 값의 약한 태그                               304   0B
If-None-Match: 다른 태그                                     200   26B
If-None-Match: 여러 개 중 하나가 일치                             304   0B
If-None-Match: *                                         304   0B
If-Match: 같은 강한 태그                                       200   26B
If-Match: 다른 태그                                          412   0B
If-Match: 같은 값의 약한 태그                                    412   0B

== 약한 ETag (서버의 ETag = W/"v1-abc")
요청 헤더                                                    상태  본문
----------------------------------------------------------------------
If-None-Match: 같은 약한 태그                                  304   0B
If-None-Match: 같은 값의 강한 태그                               304   0B
If-Match: 같은 약한 태그                                       412   0B
If-Match: 같은 값의 강한 태그                                    412   0B

== 날짜 헤더와 우선순위 (서버의 ETag = "v1-abc")
요청 헤더                                                    상태  본문
----------------------------------------------------------------------
If-Modified-Since: 수정 시각과 같음                             304   0B
If-Modified-Since: 수정 시각보다 이전                            200   26B
If-Modified-Since: 수정 시각보다 이후                            304   0B
If-Modified-Since 이후 + If-None-Match 다름                  200   26B
If-Modified-Since 이전 + If-None-Match 같음                  304   0B
