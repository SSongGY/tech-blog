# 예제 코드 — 이중 쓰기와 아웃박스

메모리 SQLite를 업무 DB로, 리스트 하나를 브로커로 두고 이중 쓰기와 아웃박스를
같은 실패 지점 다섯 곳에서 각각 돌린다. 장애는 난수가 아니라 인자로 지정하므로
몇 번을 돌려도 결과가 같다.

외부 브로커나 컨테이너가 필요 없다. 표준 라이브러리만 쓴다.

## 실행

```bash
python dual_write.py
```

## 바꿔볼 값

- `attempt` 의 `retry` 조건을 모든 지점으로 넓히면, 재시도가 유실을 줄이는 대신
  중복을 만드는 지점이 어디인지 보인다.
- `run_outbox` 의 `relay` 호출을 빼면 아웃박스 행만 쌓이고 발행은 0건이 된다.
  릴레이가 멈췄을 때의 모습이다.
- `relay` 에서 `UPDATE ... sent_at` 을 발행보다 **앞으로** 옮기면 중복 대신 유실이
  생긴다. 어느 쪽을 택할지가 전달 보장을 정한다.
