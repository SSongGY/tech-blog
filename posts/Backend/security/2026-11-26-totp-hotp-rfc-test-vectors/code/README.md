# 예제 코드 — HOTP·TOTP 를 RFC 시험 벡터와 맞춰 보기

파이썬 표준 라이브러리(`hmac`, `hashlib`, `struct`, `random`)만 쓴다. 설치할 것이 없다.
Python 3.13.5 에서 돌렸다. 난수 시드를 고정해 [6]·[7] 의 숫자가 매번 같게 나온다.

## 실행

```bash
python totp_vectors.py
```

## 바꿔 볼 값

- `dynamic_truncate` 의 `& 0x7FFFFFFF` 를 지우면 [2] 의 일치 건수가 줄어든다. 최상위 비트가 1 인 벡터가 어긋난다
- `struct.pack(">Q", counter)` 를 `">I"` 로 바꾸면 카운터가 4바이트가 되어 [2]·[3] 이 전부 어긋난다. RFC 는 8바이트를 쓴다
- [7] 의 `attempts` 를 5 에서 50 으로 올리면 잠금 횟수가 추측 성공 확률에 그대로 곱해지는 것이 보인다
- [8] 의 40초를 70초로 바꾸면 창 ±1 로는 맞지 않고 ±2 가 필요하다
