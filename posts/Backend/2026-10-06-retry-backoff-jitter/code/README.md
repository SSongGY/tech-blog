# 예제 코드 — 지수 백오프와 지터

장애 직후 클라이언트 100개가 동시에 요청하고, 10ms 칸마다 5건까지만 처리하는 서버가
나머지를 즉시 거절할 때, 백오프 방식 6가지의 총 호출 수·완료 시각·칸별 부하를 센다.
난수는 시드를 고정했다. 외부 의존성 없이 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python retry_storm.py
```

## 바꿔볼 값

- `CAPACITY_PER_SLOT`을 20으로 올리면 지터의 효과가 얼마나 줄어드는지 본다.
- `CAP_MS`를 200으로 낮추면 지수 백오프(지터 없음)의 완료 시각이 어떻게 바뀌는지 본다.
- `CLIENT_COUNT`를 1000으로 늘려 방식 간 차이가 커지는지 본다.
