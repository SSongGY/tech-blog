# 예제 코드 — rsync 롤링 체크섬으로 바뀐 부분만 보내기

파이썬 표준 라이브러리(`hashlib`, `random`)만 쓴다. 설치할 것이 없다.
테스트 파일은 시드를 고정한 난수로 만들므로 매번 같은 결과가 나온다.

## 실행

```bash
python rolling_delta.py
```

## 바꿔 볼 값

- `make_files` 의 `new[1000:1000] = b"[NEW]"` 를 지우면 고정 위치 비교도 앞쪽 블록을 찾기 시작한다. 삽입 하나가 고정 위치 비교를 얼마나 무너뜨리는지 비교한다
- `TOKEN_BYTES` 는 이 예제의 가정이다. 0 이나 8 로 바꾸면 블록 크기별 총량의 최솟값 자리가 움직이는지 본다
- `words` 를 바이트 전 범위(`bytes(rng.randrange(256) for _ in range(...))`)로 바꾸면 [5]의 약한 체크섬 겹침이 어떻게 달라지는지 본다
