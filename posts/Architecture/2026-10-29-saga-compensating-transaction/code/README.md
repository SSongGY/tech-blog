# 사가 보상 트랜잭션 예제

주문 한 건을 결제 → 재고 확보 → 배송 예약 세 단계로 처리하고, 중간에서
실패했을 때 보상이 어디까지 되돌리는지를 상태 값으로 확인한다.

의존성은 없다. 파이썬 표준 라이브러리만 쓴다. 난수도 쓰지 않으므로
몇 번을 돌려도 같은 출력이 나온다.

## 실행

```bash
python saga.py
```

## 바꿔 볼 값

| 자리 | 기본 | 바꾸면 |
|---|---|---|
| `RETRY_LIMIT` | `3` | `1` 로 두면 3번 시나리오도 보류 큐로 넘어간다 |
| `run_saga(..., fail_step=...)` | `"배송 예약"` | `"재고 확보"` 로 바꾸면 보상이 하나만 돈다 |
| `failing_compensations={"결제": 5}` | 5회 | `RETRY_LIMIT` 이하로 낮추면 재시도로 복구된다 |
| `idempotent_compensation` | `True` | `False` 면 중복 배달이 상태를 시작값 너머로 민다 |
| `INITIAL_BALANCE` | `100_000` | `PRICE` 보다 작게 두면 첫 단계에서 바로 거부된다 |

`failing_compensations` 는 `{단계 이름: 연속 실패 횟수}` 다. 지정한 횟수만큼
보상이 예외를 내고 그 뒤에는 성공하므로, 재시도로 복구되는 경우와 끝내
복구되지 않는 경우를 같은 코드로 볼 수 있다.
