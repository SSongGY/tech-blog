# 쿠쿠 필터 실측

Fan 외(CoNEXT 2014)의 부분 키 쿠쿠 해싱(Algorithm 1~3)을 표준 라이브러리로 구현하고,
버킷 크기별 최대 적재율, 지문 길이별 오탐률, 같은 메모리의 블룸 필터와의 비교,
삭제 동작을 잰다. 해시는 `hashlib.blake2b`, 쫓아내기의 무작위 선택은 시드를 고정한
`random.Random`이라 다시 돌려도 같은 값이 나온다. 외부 의존성은 없다.

## 실행

```bash
python cuckoo_filter.py
```

## 바꿔 볼 값

- `TOTAL_SLOTS` — 전체 칸 수. 논문은 Figure 2에서 표가 커질수록 높은 적재율에 필요한
  최소 지문 길이가 늘어난다고 한다. 칸을 늘리고 7번의 짧은 지문(f=4)을 다시 본다.
- `MAX_NUM_KICKS` — 쫓아내기 상한. 줄이면 1번의 적재율이 먼저 떨어진다.
- 3번의 `f` — 지문을 늘리면 쿠쿠 쪽 bits/item 이 늘어난다. 같은 비트로 블룸 필터와 다시 견준다.
