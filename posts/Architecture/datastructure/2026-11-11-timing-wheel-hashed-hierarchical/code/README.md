# 예제 코드 — 타이머 휠

파이썬 표준 라이브러리만 쓴다. 설치할 것이 없다.

## 실행

```bash
python timing_wheels.py
```

난수 시드를 고정했으므로 몇 번을 돌려도 같은 숫자가 나온다. 시간 대신 "타이머 항목을 건드린 횟수"를 센다.

## 바꿔 볼 값

- `STOP_RATIO` 를 0.9 로 올리면 힙의 지연 삭제가 남기는 쓰레기가 늘어 틱당 일이 어떻게 바뀌는지 본다
- `HierarchicalWheel.BITS` 를 3 으로 줄이면(휠 3개 x 8슬롯) 담을 수 있는 길이가 짧아져 `assert` 가 걸린다 — `LEVELS` 를 4 로 같이 올린다
- `MAX_INTERVAL` 을 4,096 이상으로 올리면 단순 휠(슬롯 4,096개)이 `assert` 로 멈춘다. 논문이 말하는 MaxInterval 제약이다
