# 예제 코드 — Gorilla 시계열 압축

파이썬 표준 라이브러리만 쓴다(`struct`, `zlib`, `random`). 설치할 것이 없다.
난수는 `SEED = 20261115` 로 고정했다.

## 실행

```bash
python gorilla.py
```

## 바꿔 볼 값

- `series_compare()` 의 게이지 단위를 `0.25` 에서 `0.1` 로 바꾸면 2진수로 딱 떨어지지 않는 소수가 되어 점당 비트가 늘어난다
- `timestamp_compare()` 의 흔들림 비율 `0.1` 을 `0.5` 로 올리면 `ts 10` 칸이 늘어난다
- 부호기는 비트를 파이썬 리스트에 하나씩 담는 학습용 구현이라 느리다. 비트 수만 본다
