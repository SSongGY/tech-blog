# 예제 코드 — 일관 해싱과 키 이동 비율

표준 라이브러리만 쓴다. 키 10만 개를 나머지 분배와 해시 링(가상 노드 1~1000개)으로
나눠 보고, 노드를 하나 더하거나 뺄 때 옮겨지는 키와 노드별 부하를 센다.

## 실행

```bash
python consistent_hashing.py
```

## 파일

| 파일 | 무엇 |
|---|---|
| `consistent_hashing.py` | 본문 출력을 내는 스크립트 |
| `output.txt` | `blog.py run-example` 이 남긴 수행 기록 |

## 바꿔볼 값

- `NODE_COUNT` — 노드 수를 바꾸면 이상적인 이동 비율 1/(N+1) 도 바뀐다
- `HashRing` 의 점 이름 `"%s#%d"` — 이름 규칙만 바꿔도 가상 노드 1개일 때의 부하가 크게 달라진다
- `hash64()` — sha1 등으로 바꿔도 이동 비율의 모양은 같아야 한다

키 해시는 md5 로 고정했으므로 몇 번을 돌려도 같은 숫자가 나온다.
