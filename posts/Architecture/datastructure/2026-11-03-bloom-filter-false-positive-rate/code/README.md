# 예제 코드 — 블룸 필터를 직접 만들어 오탐률 수식과 맞춰 보기

표준 라이브러리만 쓴다. 비트 배열과 해시 개수를 바꿔 가며 실측 오탐률을 세고
이론식이 주는 값과 나란히 찍는다.

## 실행

```bash
python bloom_filter.py
```

## 파일

| 파일 | 무엇 |
|---|---|
| `bloom_filter.py` | 블룸 필터 구현과 네 가지 측정 |
| `output.txt` | `blog.py run-example` 이 남긴 수행 기록 |

## 바꿔볼 값

- `SEED` — 난수 시드. 시행마다 실측값이 소수점 아래에서 흔들리는 폭을 볼 수 있다
- `num_probes` — 비멤버 질의 횟수. 줄이면 실측값이 이론값에서 더 벌어진다.
  오탐률이 0.1% 아래로 내려가면 10만 회로도 표본이 모자란다
- `num_items` — 원소 수 n. `m/n` 비율이 같으면 오탐률도 같다는 것을 확인할 수 있다
- `BloomFilter._positions` — 지금은 BLAKE2b 두 번으로 128바이트를 만들어 8바이트씩
  자른다. 시드를 바꿔 k번 부르는 방식으로 되돌리면 결과는 같고 느려진다
