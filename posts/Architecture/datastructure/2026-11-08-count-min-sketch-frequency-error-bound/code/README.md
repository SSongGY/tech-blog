# 예제 코드 — Count-Min Sketch

파이썬 표준 라이브러리만 쓴다. 난수 시드를 고정했으므로 같은 파이썬 버전에서는 같은 결과가 나온다.
스트림 100만 건을 여러 번 넣으므로 수십 초 걸린다.

## 실행

```bash
python count_min.py
```

## 바꿔볼 값

- `zipf_stream()` 의 지수 1.1 을 0.8·1.5 로 바꿔 쏠림 정도에 따라 오차가 어떻게 달라지는지 본다
- `section_zipf()` 의 `272, 5` 를 `2719, 5`(eps=0.001)로 바꿔 오차가 약 1/10 로 주는지 본다
- `section_heavy()` 의 eps 를 phi 와 같은 0.01 로 두면 잘못 보고되는 항목이 얼마나 느는지 본다
