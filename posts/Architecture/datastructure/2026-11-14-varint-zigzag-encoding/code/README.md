# 예제 코드 — varint 와 지그재그 인코딩

파이썬 표준 라이브러리만 쓴다(`random`, `struct`). protobuf 라이브러리는 쓰지 않고, 명세의 예제 값으로 구현을 검산한다. 난수는 시드를 고정했다.

## 실행

```bash
python varint.py
```

## 바꿔 볼 값

- `part5()` 의 분포에 `rng.randint(0, 1 << 27)` 을 넣어 본다 — 2^28 미만이면 varint 가 4바이트를 넘지 않아 fixed32 보다 작거나 같다
- `part6()` 의 시각 범위(하루 86,400,000ms)를 줄이거나 늘리면 차이값의 크기와 바이트 수가 어떻게 바뀌는지 본다
