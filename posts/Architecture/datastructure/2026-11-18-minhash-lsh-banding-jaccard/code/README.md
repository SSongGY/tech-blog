# 예제 코드 — MinHash와 LSH 밴딩

파이썬 표준 라이브러리만 쓴다. 난수 시드는 `SEED = 20261118` 로 고정했다.

## 실행

```bash
python minhash_lsh.py
```

## 바꿔 볼 값

- `part2` 의 `(20, 5)` 를 `(10, 10)` 으로 바꾸면 곡선이 오른쪽으로 옮겨 가 s=0.5 쌍이 거의 후보가 되지 않는다
- `part4` 의 심는 유사도 목록에 0.6 을 넣으면 임계값 근처에서 놓치는 쌍이 늘어난다
- `PRIME` 을 작은 소수(예: 10007)로 바꾸면 원소 id 가 소수보다 커서 해시 값이 겹치고 추정이 흔들린다
