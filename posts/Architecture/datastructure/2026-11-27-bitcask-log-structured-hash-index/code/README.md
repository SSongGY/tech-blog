# 예제 코드 — Bitcask 최소 구현

파이썬 표준 라이브러리만 쓴다. 설치할 것이 없다. Python 3.13.5 에서 돌렸다.

- `bitcask_store.py` — 데이터 파일·keydir·병합·힌트 파일을 구현한 저장소
- `demo.py` — 공간 증폭, get 의 읽기 횟수, 병합, 기동 시 읽는 바이트, 잘린 꼬리 복구, 묘비, keydir 메모리를 잰다

작업 파일은 `code/probe_store/` 에 만들고 끝나면 지운다.

## 실행

```bash
python demo.py
```

## 바꿔 볼 값

- `ROUNDS` 를 1 로 바꾸면 [2] 의 공간 증폭이 1배 근처로 내려간다. 덮어쓴 횟수가 그대로 배수가 된다
- `VALUE_SIZE` 를 키우면 [5] 의 데이터 파일 대 힌트 파일 차이가 커진다. 힌트 항목은 값을 담지 않는다
- `Bitcask(..., max_file_size=...)` 를 줄이면 [2] 의 데이터 파일 수가 늘지만 get 의 읽기 횟수는 그대로 1번이다
- [6] 의 `truncate` 를 자르지 않고 값 한 바이트를 바꾸는 것으로 고치면 CRC 불일치로 같은 자리에서 멈춘다
