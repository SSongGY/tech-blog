# 예제 코드 — CRC-32가 반드시 잡는 오류와 놓치는 오류

파이썬 표준 라이브러리(`zlib`, `random`)만 쓴다. 난수는 시드 `20261121` 로 고정했다.

## 실행

```bash
python crc32_errors.py
```

`[3-3]` 은 신드롬 약 450만 쌍을 사전에 넣으므로 수십 초와 수백 MB 메모리가 든다.

## 바꿔 볼 값

- `show_hd(33, 5)`·`show_hd(34, 5)` 의 바이트 수를 바꿔 HD 가 바뀌는 길이를 찾아본다 (Koopman Table 1 과 비교)
- `[4-1]` 의 `burst_length` 상한을 33 이상으로 올려 본다 — 무작위 표본으로는 놓치는 것이 거의 나오지 않는다. `[4-2]` 처럼 모양을 골라야 한다
- `[5]` 의 `forged_prefix` 를 아무 문자열로 바꿔도 4바이트로 같은 CRC 를 만든다
