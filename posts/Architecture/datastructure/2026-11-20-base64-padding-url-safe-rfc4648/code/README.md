# 예제 코드 — Base64, 패딩과 URL 안전 변형

파이썬 표준 라이브러리 `base64` 만 쓴다. Python 3.13.5 에서 돌렸다. 난수 시드는 고정이다.

## 실행

```bash
python base64_rfc4648.py
```

## 바꿔 볼 값

- `[3]` 의 바이트 — `0xFB 0xFF 0xBF` 대신 `+` 나 `/` 가 하나만 나오는 바이트를 넣어 표준 디코더가 무엇을 버리는지 본다
- `[5]` 의 문자열 — 알파벳 밖 글자를 끝에 두면 기본 디코더와 `validate=True` 가 각각 어떻게 하는지
- `RANDOM_CASES` — 늘려도 `[1]` 의 불일치는 0 이어야 한다
