  'fo'       직접 'Zm8='       표준 'Zm8='       같음 True
  'foo'      직접 'Zm9v'       표준 'Zm9v'       같음 True
  'foob'     직접 'Zm9vYg=='   표준 'Zm9vYg=='   같음 True

[3] URL 안전 알파벳 (RFC 4648 §5)
  바이트 fb ff bf  표준 '+/+/'  URL 안전 '-_-_'
  b64decode (표준 디코더)                       '-_-_'         → b''
  b64decode(validate=True)                 '-_-_'         → Error: Only base64 data is allowed
  urlsafe_b64decode (URL 안전 디코더)           '-_-_'         → b'\xfb\xff\xbf'
  urlsafe_b64decode 에 표준 문자열               '+/+/'         → b'\xfb\xff\xbf'

[4] 패딩을 뺀 문자열 (RFC 4648 §3.2)
  b64decode                                'Zm9vYg'       → Error: Incorrect padding
  b64decode                                'Zm9vYmE'      → Error: Incorrect padding
  b64decode                                'Zm9vYmFy'     → b'foobar'
  '=' 를 (-길이 % 4)개 붙여서                     'Zm9vYg=='     → b'foob'
  '=' 를 (-길이 % 4)개 붙여서                     'Zm9vYmE='     → b'fooba'
  길이 % 4 == 1 은 복원 불가                      'Zm9vY==='     → Error: Invalid base64-encoded string: number of data characters (5) cannot be 1 more than a multiple of 4

[5] 알파벳 밖 글자 (RFC 4648 §3.3)
  b64decode                                'Zm9v\nYmFy'   → b'foobar'
  b64decode(validate=True)                 'Zm9v\nYmFy'   → Error: Only base64 data is allowed
  b64decode                                'Zm9v YmFy'    → b'foobar'
  b64decode(validate=True)                 'Zm9v YmFy'    → Error: Only base64 data is allowed
  b64decode                                'Zm9v*YmFy'    → b'foobar'
  b64decode(validate=True)                 'Zm9v*YmFy'    → Error: Only base64 data is allowed
  b64decode                                'Zm=9vYmFy'    → b'foobar'
  b64decode(validate=True)                 'Zm=9vYmFy'    → Error: Discontinuous padding not allowed

[6] 정규 인코딩 — 패드 비트 (RFC 4648 §3.5)
  (두 번째 글자 6비트 중 위 2비트가 데이터, 아래 4비트가 패드)
  두 번째 글자 'g' = 100000                     'Zg=='         → b'f'
  두 번째 글자 'h' = 100001                     'Zh=='         → b'f'
  두 번째 글자 'i' = 100010                     'Zi=='         → b'f'
  두 번째 글자 'v' = 101111                     'Zv=='         → b'f'
