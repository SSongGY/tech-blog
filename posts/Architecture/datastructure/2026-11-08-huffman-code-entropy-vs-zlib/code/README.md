# 예제 코드 — 허프만 부호와 엔트로피, zlib

파이썬 표준 라이브러리(`heapq`, `zlib`, `this`)만 쓴다. 설치할 것이 없다.

## 실행

```bash
python huffman_vs_zlib.py
```

## 바꿔볼 값

- 2절의 `0.95` 를 `0.6` 으로 낮춰 기호 묶기의 이득이 줄어드는지 본다
- 4절의 반복 횟수 `20` 을 바꿔 DEFLATE 비트/기호가 어디까지 내려가는지 본다
- 4절에 `bytes(range(256)) * 10` 같은 균등 분포 입력을 넣어 허프만이 8비트에 붙는지 본다
