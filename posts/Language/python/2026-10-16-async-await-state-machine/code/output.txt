================================================================

4. 진짜로 중단되는 await
================================================================
  생성 직후 : CORO_CREATED
  첫 send 후: CORO_SUSPENDED
  바깥으로 넘긴 값 : None
  무엇을 기다리는가: coroutine sleep
  멈춘 코드 : really_suspends / 줄 34
  살아 있는 지역 변수: {'first': '지역 변수는 중단 중에도 살아 있다'}
  두 번째 send 로 종료, 반환값: '지역 변수는 중단 중에도 살아 있다'
  최종 상태 : CORO_CLOSED
