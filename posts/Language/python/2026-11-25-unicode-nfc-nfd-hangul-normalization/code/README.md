# 예제 코드 — 유니코드 정규화 NFC와 NFD

파이썬 표준 라이브러리(`unicodedata`, `sqlite3`, `tempfile`)만 쓴다. 설치할 것이 없다.
Python 3.13.5(UCD 15.1.0), Windows 11 NTFS 에서 돌렸다.

## 실행

```bash
python normalization.py
```

[3] 은 운영체제 임시 폴더에 파일 두 개를 만들고, 끝나면 폴더째 지운다.

## 바꿔 볼 값

- [1] 의 단어를 `"é"` 로 바꾸면 한글이 아닌 결합 문자(`e` + U+0301)에서도 같은 일이 생기는지 본다
- [2] 의 `T_COUNT` 를 27 로 바꾸면 분해 불일치가 생긴다. 28 은 받침 27개에 '받침 없음' 하나를 더한 값이다
- [3] 을 macOS(APFS)나 리눅스(ext4)에서 돌리면 폴더 안 파일 수가 달라질 수 있다. 파일 시스템이 이름을 정규화하는지에 달렸다
- [6] 에 `"ﾟ"`, `"㎏"`, `"Ⅳ"` 를 넣어 NFKC 가 무엇을 접는지 더 본다
