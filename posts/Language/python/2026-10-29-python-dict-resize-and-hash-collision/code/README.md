# 딕셔너리 리사이즈와 해시 충돌 실측

항목을 하나씩 넣으며 `sys.getsizeof` 가 뛰는 지점을 찍고, 해시가 전부 같은 키를
넣었을 때 조회 시간이 어떻게 변하는지 잰다. 표준 라이브러리만 쓴다.

## 실행

```bash
python dict_growth.py
```

## 바꿔볼 값

- `STEP_LIMIT` 을 2000 으로 올리면 계단이 더 길게 보인다. 뛰는 지점의 간격이
  일정하지 않다는 것이 눈에 들어온다.
- `TRIAL_SIZES` 에 1000 을 넣으면 해시가 같은 키의 조회 시간이 어디까지 가는지
  볼 수 있다. 다만 실행 시간이 길어진다.
- `ConstantHash.__hash__` 가 `0` 대신 `self.value % 8` 을 돌려주게 바꾸면
  충돌 그룹이 여덟 갈래로 쪼개져 조회 시간이 그만큼 준다.

## 측정값에 대해

4번의 시간은 환경에 따라 흔들린다. 절대값이 아니라 **같은 표 안의 배수**를 본다.
