# 예제 코드 — 기본 EPS와 희석 EPS

가상 회사 사바산업의 기중 신주 발행·자기주식 취득으로 가중평균유통보통주식수를
일할 계산하고, 순이익과 주식 수가 같은 세 회사(가나전자·다라물산·마바화학)의
희석 EPS를 기업회계기준서 제1033호의 순서대로 계산한다. 전환사채는 세후 이자를
분자에 되돌리고, 주식선택권은 자기주식법으로 증분주식을 구한다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python diluted_eps.py
```

## 바꿔볼 값

- `AVG_MARKET_PRICE` 를 8,000 이하로 내리면 선택권이 모두 반희석이 되어 다라물산의 희석 EPS가 기본 EPS와 같아진다.
- `TAX_RATE` 를 올리면 전환사채의 세후 이자가 줄어 같은 표면이자율에서도 희석 쪽으로 기운다.
