# 예제 코드 — PEG 와 성장률 선택

가상 회사 `가나전자` 하나의 EPS 이력과 추정치로 성장률 후보 여섯 가지를 만들고,
같은 PER 24배를 그 여섯으로 각각 나눠 PEG 가 어디까지 갈리는지 본다. 이어서
성장률 단위를 섞었을 때, 기준 연도의 일회성 손익을 조정했을 때 값이 어떻게
바뀌는지를 계산하고, 2단계 배당할인모형이 정당화하는 PEG 가 위험과 성장률
수준에 따라 어떻게 움직이는지를 격자로 찍는다. 파이썬 표준 라이브러리만 쓴다.

`[5]` 는 구현 검산이다. 공개 강의자료에 PEG 1.94 로 적힌 예제 파라미터를 그대로
넣어 같은 값이 나오는지 확인한다.

## 실행

```bash
python peg_growth.py
```

## 바꿔볼 값

- `ONE_OFF_IMPAIRMENT_2022` 를 0 으로 두면 `[4]` 의 두 줄이 같아진다. 기저효과가
  성장률에서 나온다는 것이 그때 사라진다.
- `EPS_HISTORY` 의 2026~2028 추정치를 낮추면 `[2]` 의 미래 기준 성장률만 내려가고
  과거 기준 성장률은 그대로다. 같은 표 안에서 두 갈래가 반대로 움직인다.
- `[6]` 의 `betas` 에 더 큰 값을 넣으면 요구수익률이 오르고 정당한 PEG 가 전 구간
  내려간다. 같은 성장률이라도 위험이 다르면 기준선이 다르다는 것이 보인다.
- `GN`(안정성장률)을 올리면 정당한 PEG 가 전 구간 올라간다. 영구 구간의 분모
  `r - gn` 이 좁아지기 때문이다.
