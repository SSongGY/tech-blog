# 예제 코드 — 사업부를 따로 평가해 더한다

가상 지주회사 가나홀딩스를 두 방식으로 평가한다. 전사 EBITDA 에 배수 하나를
곱하는 방식과, 부문마다 다른 배수를 적용해 합산하는 SOTP 방식이다.
세 부문의 성격이 전부 다르게 설계돼 있어서 두 방식의 결론이 갈린다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python sotp.py
```

## 바꿔볼 값

- `FIN_DEBT` 는 금융 자회사의 차입금이다. 단일 배수 방식은 이것을 연결 순차입금에
  넣어 빼는데, 이 값을 0 으로 두면 두 방식의 지분가치가 가까워진다. 단일 배수가
  깨지는 지점이 금융부문 조달이라는 뜻이다.
- `HQ_COST` 를 0 으로 두면 본사비용 자본화 항목이 사라진다. 부문 가치를 전부
  더해 놓고 본사를 빼먹으면 합계가 얼마나 부풀려지는지 이 값으로 가늠한다.
- `FIN_OWNERSHIP` 을 1.0 으로 올리면 비지배지분이 없어진다. 금융 자회사를
  100% 들고 있을 때와 60% 들고 있을 때 주당가치가 얼마나 벌어지는지 본다.
- `BLENDED_MULTIPLE` 은 단일 배수 방식이 쓰는 "복합기업 평균" 배수다. 이 값을
  어떻게 잡아도 부문 구성이 반영되지 않는다는 점이 `[4]` 표에서 드러난다.
