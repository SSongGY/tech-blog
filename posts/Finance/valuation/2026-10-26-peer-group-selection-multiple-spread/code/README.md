# 예제 코드 — 비교기업을 바꾸면 적정주가가 어디까지 갈리는가

가상 회사 다온소재를 평가 대상으로 두고, 역시 가상인 후보 10개사로 비교군을
짠다. 요건을 걸지 않은 비교군과 「증권의 발행 및 공시 등에 관한 규정 시행세칙」
제7조의 ±30% 폭을 건 비교군이 같은 회사에 얼마나 다른 값을 매기는지 계산한다.
평균·중앙값·절사평균·조화평균도 같은 자료에서 나란히 낸다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python peer_group.py
```

## 바꿔볼 값

- `BAND` 를 0.30 에서 0.50 으로 올리면 통과 회사가 늘고 비교군 평균이 올라간다.
  요건을 느슨하게 할수록 어느 방향으로 움직이는지 본다.
- `CANDIDATES` 의 `사월바이오` 행에서 EV/EBITDA 42.0 을 지우거나 줄이면
  `[2]` 의 "이상치 1사만 뺀 평균"과 전체 평균이 가까워진다. 이상치 하나가
  열 개의 평균을 얼마나 끌고 가는지 이 값으로 가늠한다.
- `T_PRETAX_PS` 와 `T_BPS` 는 평가 대상의 주당 수치다. 이 둘을 바꾸면 허용 폭이
  통째로 옮겨 가므로 통과 회사 명단이 바뀐다. 평가 대상이 달라지면 비교군도
  달라진다는 것이 요건의 뜻이다.
- `trimmed_mean` 의 `trim` 을 2 로 올리면 양 끝에서 두 개씩 떼어 낸다.
