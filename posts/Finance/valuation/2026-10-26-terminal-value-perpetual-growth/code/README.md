# 예제 코드 — 잔존가치와 영구성장률

가상 회사 한들소재의 5년 예측 잉여현금흐름으로 기업가치를 구하고, 잔존가치가 전체에서
차지하는 몫·영구성장률과 할인율의 민감도·출구배수에 거꾸로 깔린 영구성장률·예측 기간을
10년으로 늘렸을 때의 변화를 계산한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python terminal_value.py
```

## 바꿔볼 값

- `TERMINAL_GROWTH` 를 `WACC` 가까이 올리면 잔존가치가 폭주한다. 두 값의 차이가 분모라
  차이가 절반이 되면 잔존가치는 두 배가 된다.
- `FCF` 의 마지막 값만 바꿔도 잔존가치 전체가 그 비율대로 움직인다. 5년차 현금흐름 하나가
  기업가치의 70% 넘는 부분을 결정한다는 뜻이다.
- `TERMINAL_EBITDA` 를 바꾸면 `[4]` 의 내재 영구성장률이 달라진다. 출구배수와 영구성장률
  가운데 어느 쪽을 고정할지는 선택이지만, 둘을 따로 정하면 서로 모순될 수 있다.
- `LATE_FCF` 의 성장률을 2% 로 낮추면 `[5]` 에서 5년 예측과 10년 예측의 EV 가 거의 같아진다.
