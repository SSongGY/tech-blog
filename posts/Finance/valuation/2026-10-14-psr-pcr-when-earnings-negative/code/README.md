# 예제 코드 — PSR 과 PCR

가상 회사 네 곳(`가나전자`·`다라바이오`·`마바커머스`·`사아장터`)의 PER·PSR·PCR 을
계산해, 적자 구간에서 어느 배수가 남고 어느 배수가 같이 깨지는지 본다. 이어서
본인·대리인 수익 인식(K-IFRS 제1115호)이 PSR 분모를 열 배 벌려 놓는 것,
PSR 을 내재 PER 로 되돌리는 데 필요한 마진 가정, 운전자본 증감과 이자 분류 선택이
PCR 분모를 흔드는 것을 계산한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python psr_pcr.py
```

## 바꿔볼 값

- `COMPANIES` 의 `다라바이오` 영업현금흐름을 양수로 바꾸면 PCR 이 성립하고,
  적자 회사 중에서도 현금을 남기는 쪽과 태우는 쪽이 갈린다는 점이 흐려진다.
- `COMMISSION_RATE` 를 올리면 `[2]` 에서 대리인의 매출액이 커져 두 회사의 PSR
  격차가 좁아진다. 수수료율 100% 가 되면 총액 인식과 같아진다.
- `MARGIN_CASES` 에 더 낮은 마진을 넣으면 `[3]` 의 내재 PER 이 급격히 커진다.
  PSR 이 마진의 역수에 비례한다는 것이 눈에 보인다.
- `WORKING_CAPITAL_CASES` 의 폭을 넓히면 `[4]` 의 PCR 변동 폭이 그만큼 커진다.
