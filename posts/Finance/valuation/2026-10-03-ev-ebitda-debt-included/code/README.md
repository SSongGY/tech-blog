# 예제 코드 — EV/EBITDA

PER 이 10배로 같은 가상 회사 하카기계·타파중공업이 차입금과 현금 구성만 달라
EV/EBITDA 가 갈리는 것을 계산한다. 이어서 EBITDA 가 같은 라마소프트·바사제철의
감가상각·설비투자 차이, K-IFRS 제1116호 리스 이후 리스부채를 EV 에 넣느냐에 따른
배수 차이를 본다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python ev_ebitda.py
```

## 바꿔볼 값

- `INTEREST_RATE` 를 올리면 타파중공업의 순이익이 줄어 같은 PER 10배에서 시가총액이 작아지고, EV/EBITDA 와의 차이가 더 벌어진다.
- `print_lease()` 의 리스부채·감가상각·이자 금액은 설명용 가정이다. 실제 금액은 리스 기간과 할인율로 정해진다.
