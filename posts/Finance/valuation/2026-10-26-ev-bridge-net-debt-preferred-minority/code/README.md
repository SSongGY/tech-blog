# 예제 코드 — 시가총액에서 EV 로 건너가는 다리

가상 회사 마루정밀의 연결 숫자로 EV 를 항목별로 조립하고, 구성 항목을 하나씩
빠뜨렸을 때 EV/EBITDA 가 어디까지 움직이는지 계산한다. 마지막에 순현금 회사
새벌소프트를 두어 EV 가 시가총액보다 작아지는 경우를 본다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python ev_bridge.py
```

## 바꿔볼 값

- `NON_CONTROLLING` 을 올리면 EV 가 그만큼 커진다. 종속기업을 많이 거느린 지주회사에서
  이 항목을 빼먹으면 배수가 실제보다 낮게 나온다.
- `LEASE_LIABILITY` 와 `LEASE_EXPENSE` 를 함께 0 으로 두면 리스가 없는 회사가 된다.
  둘 중 하나만 0 으로 두면 분자와 분모의 기준이 어긋나 배수가 반대 방향으로 움직인다.
- `SHORT_TERM_FINANCIAL` 을 키우면 현금성자산의 범위를 어디까지 보느냐가 배수를
  얼마나 흔드는지 커진다.
