# 예제 코드 — 총주주수익률(TSR)

발행주식수·당기순이익·주주환원 총액이 똑같고 **돌려주는 방식만 다른** 가상 회사
두 곳을 5년간 따라간다. `가나전자`는 전액을 현금배당으로, `다라물산`은 전액을
자사주 매입·소각으로 돌려준다. 주가 경로가 어디서 갈리는지, 그 차이가 TSR 에서는
어떻게 되는지를 연차별로 찍는다.

이어서 연도별 수익률을 그냥 더한 값과 배당을 재투자한 누적 TSR 의 차이, 적용
배수(PER)가 움직일 때 두 방식의 TSR 이 갈리는 폭, 배당 원천징수가 재투자 금액을
깎는 몫, 그리고 주주환원율과 TSR 이 다른 지표라는 것을 차례로 계산한다.

파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python tsr_total_return.py
```

## 바꿔볼 값

- `PAYOUT` 을 0 으로 두면 두 회사가 같아진다. 주가수익률도 TSR 도 한 줄로 붙는다.
- `PER_BASE` 를 올리면 다라물산이 자사주를 비싸게 사게 되어 같은 100억 원이 지우는
  주식 수가 줄어든다. `[6]` 의 소각비율이 그만큼 내려간다.
- `DIV_TAX` 를 0 으로 두면 `[7]` 의 두 줄이 같아진다. 세금이 재투자 원금을 깎는
  경로가 거기서 사라진다.
- `YEARS` 를 늘리면 `[5]` 의 단순합산과 재투자 TSR 의 격차가 벌어진다. 복리로 붙는
  몫이라 기간에 비례하지 않는다.
