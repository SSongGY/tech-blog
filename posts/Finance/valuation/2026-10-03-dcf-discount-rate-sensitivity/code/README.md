# 예제 코드 — 현금흐름할인(DCF)

가상 회사 자차물류의 5년 예측 잉여현금흐름과 잔존가치를 할인해 기업가치와 주당가치를
구하고, 할인율·영구성장률을 바꿨을 때 값이 얼마나 움직이는지 민감도 표로 계산한다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python dcf.py
```

## 바꿔볼 값

- `NET_DEBT` 를 늘리면 기업가치 변화율은 그대로인데 주당가치 변화율이 더 커진다. 빚이 많은 회사일수록 할인율 가정에 주당가치가 더 크게 흔들린다.
- `FORECAST_YEARS` 를 늘리면 잔존가치가 기업가치에서 차지하는 비중이 줄어든다. 예측 기간 값은 `forecast()` 가 성장률대로 늘려 만든다.
- `TERMINAL_GROWTH` 를 할인율 이상으로 두면 잔존가치 산식의 분모가 0 이하가 되어 값이 뜻을 잃는다.
