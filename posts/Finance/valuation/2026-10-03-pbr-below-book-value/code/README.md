# 예제 코드 — PBR과 청산가치

순자산·주식수·주가가 같아 PBR 이 둘 다 0.50배인 가상 회사 사아유통·자차섬유의
재무상태표에 항목별 회수율(가정)을 적용해 청산가치를 계산한다. 이어서
PBR = PER × ROE 관계와, K-IFRS 제1036호 손상차손·제1002호 재고자산 평가손실로
장부가를 낮추면 같은 주가에서 PBR 이 어떻게 바뀌는지 본다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python pbr.py
```

## 바꿔볼 값

- `JACHA` 의 회수율을 올려 보면 자차섬유의 주당 청산가치가 주가 5,000원을 넘는 지점이 보인다.
- `LIQUIDATION_COST` 는 설명용 가정이다. 실제 청산 비용은 자산 구성과 절차에 따라 크게 다르다.
