# 예제 코드 — 잔여이익모형(RIM)

가상 회사 `사아정밀` 하나를 두고 잔여이익모형과 배당할인모형을 **같은 가정으로**
돌린다. 두 모형이 같은 값을 내는지 검산하고, 평가액을 구성 요소로 나눠 종료가치가
차지하는 비중이 어떻게 다른지 본다. 이어서 가정을 하나씩 흔들어 같은 변화에 두
모형이 각각 몇 % 움직이는지 재고, 마지막으로 clean surplus 관계가 깨졌을 때
(기타포괄손익이 장부가에 직접 쌓일 때) RIM 이 얼마나 벗어나는지 계산한다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python rim.py
```

## 바꿔볼 값

- `TERMINAL_GROWTH` 를 올리거나 내리면 `[4]` 의 두 열이 다르게 움직인다. 같은
  0.5%p 변화에 DDM 쪽 변동률이 더 크다. 종료가치가 차지하는 비중이 달라서다.
- `TERMINAL_ROE` 를 `COST_OF_EQUITY` 와 같게 두면 종료 잔여이익이 0 이 되고
  RIM 의 종료가치 항이 통째로 사라진다. 그래도 DDM 과는 같은 값이 나온다.
- `ROE_FORECAST` 를 전부 `COST_OF_EQUITY` 로 채우면 `[5]` 처럼 평가액이 기초
  장부가와 같아진다. PBR 1 배가 무엇을 뜻하는지가 여기서 드러난다.
- `PAYOUT_RATIO` 를 바꾸면 DDM 의 연도별 배당이 크게 흔들리는데도 두 모형의
  최종값은 같이 움직인다. 배당 정책이 가치를 만들지 않는다는 뜻이다.
- `OCI_PER_YEAR` 를 0 으로 두면 `[6]` 의 두 모형 차이가 사라진다. 벌어진 차이가
  전부 clean surplus 위반에서 온 것임을 확인할 수 있다.
