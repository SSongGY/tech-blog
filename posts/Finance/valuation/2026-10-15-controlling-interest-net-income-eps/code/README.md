# 예제 코드 — 지배주주지분 순이익과 EPS

가상 지주회사 `자차홀딩스` 하나를 두고 연결 당기순이익이 어떻게 만들어지고
지배기업 소유주 지분과 비지배지분으로 어떻게 갈리는지 계산한다. 같은 주가에
연결 전체를 분자로 쓸 때와 지배주주지분을 분자로 쓸 때 PER·PBR·ROE 가 각각
얼마나 달라지는지 재고, 지분율을 100% 에서 40% 까지 옮겨 가며 그 격차가
어떻게 벌어지는지 본다. 이어서 지분을 추가 취득했을 때 연결 순이익은 그대로인데
지배주주 순이익만 오르는 것과, 종속기업 손실로 비지배지분이 부(-)의 잔액이 되는
경우를 계산한다. 파이썬 표준 라이브러리만 쓴다.

`PRICE` 와 `SHARES` 는 배수를 계산하려고 둔 설명용 값이고 단위에 뜻이 없다.
`[4]` 의 취득 대가는 종속기업 자본의 해당 몫에 30% 를 얹어 준 것으로 가정했다.

## 실행

```bash
python nci.py
```

## 바꿔볼 값

- `OWNERSHIP` 을 1.0 으로 두면 비지배지분이 사라져 `[2]` 의 두 줄이 같아진다.
  연결 기준으로 계산해도 틀리지 않는 유일한 경우다.
- `SUB_NET_INCOME` 을 키우면 `[2]` 의 PER 격차가 벌어진다. 이익의 출처가
  종속기업 쪽에 몰릴수록 연결 기준 계산이 더 크게 틀린다.
- `SUB_EQUITY` 만 키우면 PER 격차는 그대로인데 PBR 격차가 벌어진다. 두 배수가
  서로 다른 비중에 반응한다는 것이 드러난다.
- `[4]` 의 `1.30` 배수를 1.0 으로 두면 취득 대가와 비지배지분 조정액이 같아져
  자본에서 차감되는 금액이 0 이 된다.
- `LOSS_SUB_NI` 의 절댓값을 줄이면 `[5]` 의 비지배지분 잔액이 다시 양수가 된다.
