# 예제 코드 — 배당할인모형(DDM)

가상 회사 둘로 고든 성장모형을 계산한다. 원 논문의 연속 형태와 교과서의 이산 형태가
갈리는 지점, 성장률이 요구수익률에 가까워질 때 값이 발산하는 구간, 자기자본이익률이
요구수익률보다 높은지 낮은지에 따라 배당성향의 효과가 뒤집히는 모습을 확인한다.

의존성은 없다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python gordon_growth.py
```

## 출력

- `[1]` 두 회사의 주당 장부가·자기자본이익률·배당성향과 거기서 나오는 `g = br`
- `[2]` 같은 입력에서 나오는 이산 형태와 연속 형태의 두 값
- `[3]` 원 논문 식 (8)로 요구수익률을 되돌리는 계산
- `[4]` 장부가와 시장가가 같을 때 이익수익률과 `k`가 같아지는 것
- `[5]` 성장률이 요구수익률에 다가갈 때의 발산 구간
- `[6]` 가정을 0.5%p 흔들었을 때의 값 변화
- `[7]` `[8]` 자기자본이익률이 요구수익률보다 높을 때와 낮을 때 배당성향의 효과
- `[9]` 2단계 모형과 종가치가 차지하는 비중

수행 기록은 [`output.txt`](output.txt)에 있다.
