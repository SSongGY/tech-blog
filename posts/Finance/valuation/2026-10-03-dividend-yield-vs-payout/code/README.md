# 예제 코드 — 배당수익률과 배당성향

주당배당금이 같은 가상 회사 가나식품·다라통신·마바유통으로 배당수익률과 배당성향이
각각 무엇을 재는지 계산하고, 주가만 떨어졌을 때 수익률이 오르는 것을 본다. 이어서
가상 회사 사아화학이 순이익이 줄어도 배당을 유지할 때 배당성향이 100%를 넘고,
그 돈이 상법 제462조 배당가능이익 한도 안에서 과거 잉여금에서 나가는 것을 따라간다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python dividend.py
```

## 바꿔볼 값

- `print_over_100()` 의 `legal_reserve` 를 25 보다 작게 두면 이익준비금이 자본금 1/2 에 못 미쳐, 결산기마다 현금배당액의 10분의 1을 더 쌓아야 하므로 배당가능 한도가 그만큼 줄어든다.
- 같은 함수의 순이익 목록을 바꿔 잉여금이 바닥나는 해를 찾아볼 수 있다. 한도가 배당 총액보다 작아지면 그 해에는 같은 배당을 할 수 없다.
