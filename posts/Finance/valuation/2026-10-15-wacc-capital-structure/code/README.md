# 예제 코드 — WACC 와 자본구조

가상 회사 `마바소재` 하나로 자기자본비용(CAPM)과 세후 타인자본비용을 단계별로
만들어 시가 기준 WACC 를 구한다. 이어서 가중치만 장부가로 바꿨을 때의 차이,
부채 비중을 0%에서 70%까지 옮겼을 때 베타·ke·kd·WACC 가 각각 어느 방향으로
움직이는지, 법인세 절세효과를 뺐을 때의 값, 그리고 그 할인율 차이가 현금흐름할인
결과를 얼마나 움직이는지를 계산한다. 파이썬 표준 라이브러리만 쓴다.

`CREDIT_SPREAD` 는 부채 비중별 신용스프레드를 적어 둔 설명용 가정표다. 실제
스프레드는 업종·이자보상배율·신용등급에 따라 정해지므로 이 표의 값 자체에는
뜻이 없고, **부채가 늘수록 스프레드가 가팔라진다**는 모양만 가져왔다.

## 실행

```bash
python wacc.py
```

## 바꿔볼 값

- `CREDIT_SPREAD` 의 뒤쪽 값을 완만하게 바꾸면 `[3]` 의 WACC 곡선이 오른쪽까지
  계속 내려간다. 최저점이 생기는 것이 스프레드가 가팔라지기 때문임이 드러난다.
- `TAX_RATE` 를 0 으로 두면 `[3]` 전체가 올라가고 `[4]` 의 두 줄이 같아진다.
- `UNLEVERED_BETA` 를 올리면 ke 가 전 구간 올라가면서 최저점이 왼쪽으로 옮겨
  간다. 사업 자체의 위험이 클수록 견딜 수 있는 부채가 적다는 뜻이다.
- `BOOK_EQUITY` 를 `MARKET_EQUITY` 와 같게 두면 `[2]` 의 두 줄이 같아진다.
  장부가·시가 차이가 PBR 에서 오는 것이므로, PBR 1배인 회사에서는 이 함정이 없다.
