# 예제 코드 — PER, 이익 대비 주가를 재는 법

가상 회사 가나전자의 주가를 30,000원으로 고정하고 분모만 바꿔 PER 을 계산한다.
확정 연간 이익·최근 4분기 합산·예상 이익, 연결 전체와 지배주주 몫, 기말 주식수와
가중평균 주식수(K-IFRS 제1033호 문단 20), 일회성 이익(다라물산), 이익이 0 근처와
음수일 때를 차례로 본다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python per.py
```

## 바꿔볼 값

- `ISSUE_MONTHS_OUTSTANDING` 을 12 로 두면(1월 1일 발행) 가중평균 주식수가 기말 주식수와 같아져 `[4]` 의 두 줄이 같아진다.
- `print_denominators()` 의 예상 이익 495 는 설명용 가정이다. 값을 바꿔 보면 선행 PER 이 예상치 하나에 얼마나 민감한지 보인다.
