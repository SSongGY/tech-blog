# 예제 코드 — 활동성 비율, 자산을 얼마나 굴리는가

가상 회사 마루식품의 4개 시점 재무상태표와 3개년 매출액으로 총자산·유형자산·재고자산·
매출채권·매입채무 회전율을 한국은행 기업경영분석 산식(매출액 ÷ 기초·기말 평균잔액)으로
계산한다. 회전일수와 현금전환주기, 총자산회전율의 역수를 항목별로 나눈 표,
영업에 묶인 운전자본을 함께 낸다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python activity.py
```

## 바꿔볼 값

- `BALANCES[3]["재고자산"]` 을 150으로 낮추면 `[3]` 의 3년차 재고일수가 줄고 `[4]` 에서 재고자산 몫이 작아진다.
- `BALANCES[3]["매입채무"]` 를 120으로 올리면 지급일수가 늘어 현금전환주기가 1년차 수준으로 돌아간다.
