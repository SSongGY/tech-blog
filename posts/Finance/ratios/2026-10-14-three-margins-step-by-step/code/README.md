# 예제 코드 — 세 가지 마진 — 매출총이익률·영업이익률·순이익률

매출액 1,000과 영업이익 120을 똑같이 맞춘 가상 회사 세 곳으로 매출총이익률·영업이익률·
세전순이익률·순이익률을 계산한다. 매출총이익률과 매출원가 대 매출액의 합이 100이 된다는 것,
매출액을 100으로 놓았을 때 단계마다 빠지는 몫의 크기가 회사마다 다르다는 것,
같은 비용을 매출원가와 판관비 중 어디에 담느냐가 매출총이익률만 움직이고 영업이익률은
건드리지 못한다는 것을 확인한다.

법인세비용은 세전순이익의 22%로 가정했다. 의존성은 없고 표준 라이브러리만 쓴다.

## 실행

```bash
python three_margins.py
```
