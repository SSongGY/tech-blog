# 예제 코드 — 잉여현금흐름(FCF) — 영업현금흐름에서 설비 투자를 뺀 뒤 남는 돈

당기순이익이 120으로 같은 가상 회사 둘(가나전자·다라물산)의 영업활동현금흐름을 간접법으로
쌓고 설비 취득을 빼 FCF 를 구한다. 운전자본 증가와 설비 투자 규모가 다르면 순이익이 같아도
FCF 가 갈리는 것을 보인 뒤, 같은 회사를 세 가지 FCF 정의로 다시 계산해 정의에 따라 숫자가
얼마나 움직이는지, 설비 투자를 유지분과 확장분으로 나누면 무엇이 보이는지를 찍는다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python free_cash_flow.py
```

## 바꿔볼 값

- `다라물산`의 `receivable_change`·`inventory_change`를 10으로 내리면 영업활동현금흐름이 가나전자와 같아지고 FCF 차이는 설비 투자 차이만 남는다.
- `가나전자`의 `interest_in_financing`을 `False`로 바꾸면 영업활동현금흐름이 15 줄고 정의 A 와 C 가 같아진다.
