# 예제 코드 — 비율 분석이 틀리는 세 가지 경우

가상 회사 `한울산업`의 1차연도 거래 한 벌을 두고, 업종이 다른 비교 대상(`초록유통`),
허용된 범위 안의 회계정책 선택(재고 원가결정방법·감가상각방법·리스 면제),
계산 시점의 선택(기말잔액 대 평균잔액, 추정치 변경의 전진적용)이 비율을 어디까지
벌려 놓는지 계산한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python ratio_distortions.py
```

## 바꿔볼 값

- `PURCHASES` 의 단가를 내림차순으로 뒤집으면 매입 단가가 떨어지는 국면이 되고,
  선입선출법과 가중평균법의 매출총이익 대소가 반대로 뒤집힌다.
- `DDB_RATE` 를 `1.5 / USEFUL_LIFE` 로 낮추면 체감잔액법이 정액법에 가까워져
  `[5]` 네 조합의 영업이익률 폭이 좁아진다.
- `LEASE_YEARS` 를 늘리면 리스부채 현재가치가 커져 `[6]` 의 부채비율 차이가 벌어진다.
- `print_timing_average()` 의 `monthly` 를 평탄하게 바꾸면 기말잔액과 12개월
  평균의 차이가 사라진다. 계절성이 없으면 이 착시도 없다.
