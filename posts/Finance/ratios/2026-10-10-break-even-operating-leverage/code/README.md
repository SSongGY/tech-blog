# 예제 코드 — 손익분기점과 영업레버리지 — 고정비 비중이 이익 변동 폭을 키우는 이유

매출 1,000억원·영업이익 100억원이 같은 가상 회사 둘(고정비가 큰 가나전자, 변동비가 큰
다라물산)의 손익분기 매출·안전한계·영업레버리지도(DOL)를 계산하고, 매출이 ±10% 움직일 때
영업이익 변화를 찍는다. 기능별 손익계산서만으로는 고정비가 보이지 않는다는 것, 성격별 주석
(K-IFRS 제1001호 문단 104)과 두 해 숫자로 DOL을 어림할 때 생기는 오차도 함께 계산한다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python operating_leverage.py
```

## 바꿔볼 값

- `COMPANIES`의 `fixed`를 바꾸면 손익분기 매출과 DOL이 함께 움직인다. 고정비를 0으로 두면 DOL은 1이다.
- `GANA_COSTS`에서 임차료·보험료를 종업원급여로 바꾸면 성격별 주석 어림이 실제 고정비와 같아진다.
