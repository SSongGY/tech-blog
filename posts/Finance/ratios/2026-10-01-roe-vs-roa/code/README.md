# 예제 코드 — 수익성 비율, ROE와 ROA

자산 1,000과 영업이익이 똑같고 부채만 다른 가상 회사 타파기계·하나기계의 ROE와 ROA를
계산한다. 부채를 늘려 가며 ROE가 오르는 경로, 영업이익이 이자율 아래로 떨어질 때
순서가 뒤집히는 경로, 이자를 되돌려 더한 기업순이익률(한국은행 기업경영분석)을 본다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python roe_roa.py
```

## 바꿔볼 값

- `INTEREST_RATE` 를 0.08로 올리면 `[3]` 에서 하나기계 ROE가 타파기계 아래로 내려가는 영업이익 구간이 넓어진다.
- `TAX_RATE` 를 0으로 두면 `[5]` 의 기업순이익률이 두 회사에서 같아진다.
