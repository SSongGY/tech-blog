# 예제 코드 — 듀폰 분석, ROE를 세 조각으로 쪼개기

ROE가 똑같이 15%인 가상 회사 가람유통·나래제약·다온건설을 순이익률 × 총자산회전율 ×
재무레버리지로 분해하고, 순이익률을 세부담 × 이자부담 × 영업이익률로 한 번 더 쪼갠다.
같은 영업이익 충격에 세 회사의 ROE가 얼마나 흔들리는지, ROE가 3년 동안 오른 라온전자의
상승분이 어느 요인에서 왔는지를 계산한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python dupont.py
```

## 바꿔볼 값

- `INTEREST_RATE` 를 0.08로 올리면 `[4]` 에서 다온건설의 ROE 감소율이 더 커진다. 이자부담 요인이 더 작아지기 때문이다.
- `show_shock` 의 `drop` 을 0.5로 두면 다온건설만 세전이익이 0 근처로 내려가 ROE가 거의 사라진다.
