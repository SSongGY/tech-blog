# 예제 코드 — 매출원가율과 판관비율 — 이익률이 깎이는 자리 찾기

매출액 1,000 과 영업이익 120 을 똑같이 맞춰 영업이익률을 12.0% 로 고정한 가상 회사
두 곳으로, 같은 이익률에 닿는 두 경로가 매출 변동에 어떻게 다르게 반응하는지 계산한다.
두레상사는 매출원가율 82.0%·판관비율 6.0%, 한별정밀은 매출원가율 55.0%·판관비율 33.0%다.

두 비용을 변동비와 고정비로 갈라 고정비 합계가 83 과 374 로 갈리는 것을 확인하고,
매출이 20% 늘 때와 20% 줄 때 영업이익이 각각 몇 퍼센트 움직이는지, 영업레버리지도가
공헌이익÷영업이익과 일치하는지, 손익분기점 매출액과 안전한계율이 어떻게 갈리는지를 본다.

그다음 영업이익률이 깎인 해를 매출원가율 변화와 판관비율 변화로 나눠 보고,
같은 비용을 판관비에서 매출원가로 옮기면 두 비율만 움직이고 영업비용률과 영업이익률은
그대로라는 것을 확인한다.

금액 단위는 억원이고 변동비 비중(매출원가의 95%·80%, 판관비의 30%·20%)은
설명용 가정값이다. 의존성은 없고 표준 라이브러리만 쓴다.
