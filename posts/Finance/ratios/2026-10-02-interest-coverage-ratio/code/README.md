# 예제 코드 — 이자보상배율, 빚을 감당하는가

가상 회사 넷(가나기계·다라유통·마사건설·바아전자)의 이자보상배율·순이자보상배율을
한국은행 기업경영분석 산식으로 계산한다. 변동금리 상승, 배율 1 미만 3년 지속,
이자수익이 큰 경우를 차례로 본다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python coverage.py
```

## 바꿔볼 값

- `GANA.fixed_share` 를 0 으로 내리면 가나기계도 다라유통처럼 금리 상승에 그대로 노출된다.
- `print_three_years()` 의 `operating_profits` 를 `(55, 60, 65)` 로 바꾸면 부족분이 생기지 않아 차입금이 늘지 않는다.
