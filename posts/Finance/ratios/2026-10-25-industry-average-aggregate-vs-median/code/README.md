# 예제 코드 — 업종 평균과 비교할 때

가상 업종에 속한 다섯 회사로 업종 평균을 합산방식·단순평균·중앙값 세 가지로 구하고,
셋이 갈리는 지점과 그 결과 판정이 뒤집히는 경우를 확인한다.

의존성은 없다. 파이썬 표준 라이브러리의 `statistics`만 쓴다.

## 실행

```bash
python industry_average.py
```

## 출력

- `[1]` 다섯 회사의 재무 수치와 개별 부채비율·영업이익률
- `[2]` 같은 자료에서 나오는 세 개의 업종 평균
- `[3]` 합산방식이 금액 가중평균이라는 것과 지표마다 가중치 변수가 다르다는 것
- `[4]` 한 회사를 세 기준에 견줄 때 판정이 뒤집히는 모습
- `[5]` 분포 안에서 합산 평균이 놓이는 자리
- `[6]` 회사 숫자는 그대로인데 표본이 바뀌어 평균만 움직이는 경우
- `[7]` 겸업 기업이 통째로 한 업종에 들어갈 때 분모에 섞이는 매출

수행 기록은 [`output.txt`](output.txt)에 있다.
