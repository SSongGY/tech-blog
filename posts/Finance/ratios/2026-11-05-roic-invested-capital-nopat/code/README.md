# 예제 코드 — ROIC

가상 회사 `가나전자`와 `다라물산`은 매출 2,000·영업이익 200이 같다. 다른 것은 사업에
묶인 자본(투하자본)이다. 투하자본을 영업 쪽과 재무 쪽에서 각각 세어 같은 값이 나오는지,
ROIC 가 세후영업이익 마진과 투하자본 회전율로 나뉘는지, 차입금 비중을 바꾸면 ROE 는
움직이고 ROIC 는 그대로인지를 계산한다.

세율 22%·이자율 5%·자본비용 8% 는 계산을 위한 가정이다. 금액 단위는 억원이고 모든
숫자는 가상 값이다. 의존성은 없고 표준 라이브러리만 쓴다.

## 실행

```bash
python roic.py
```
