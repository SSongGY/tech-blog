[1] 입력 — 같은 것과 다른 것
  가정: 세율 22%, 차입금 이자율 5%
  항목                              가나전자      다라물산
  매출액                         2000.0    2000.0
  영업이익                         200.0     200.0
  영업유동자산                       500.0     350.0
  영업유동부채                       200.0     150.0
  유형·무형자산                     1200.0     300.0
  차입금                          800.0     100.0
  자본                           900.0     650.0
  비영업 현금                       200.0     250.0

[2] 투하자본 — 영업 쪽에서 센 값과 재무 쪽에서 센 값
  가나전자
    영업 쪽  영업운전자본 300.0 + 고정자산 1200.0 = 1500.0
    재무 쪽  차입금 800.0 + 자본 900.0 - 현금 200.0 = 1500.0
    일치 여부  True
  다라물산
    영업 쪽  영업운전자본 200.0 + 고정자산 300.0 = 500.0
    재무 쪽  차입금 100.0 + 자본 650.0 - 현금 250.0 = 500.0
    일치 여부  True

[3] ROIC 와 두 갈래 분해 (기말 투하자본 기준)
  가나전자
    NOPAT 200.0 x (1 - 0.22) = 156.0
    ROIC = 156.0 / 1500.0 = 10.40%
    분해  NOPAT 마진 7.80% x 투하자본 회전율 1.33회 = 10.40%
    평균 투하자본 1450.0 기준 ROIC = 10.76%
  다라물산
    NOPAT 200.0 x (1 - 0.22) = 156.0
    ROIC = 156.0 / 500.0 = 31.20%
    분해  NOPAT 마진 7.80% x 투하자본 회전율 4.00회 = 31.20%
    평균 투하자본 490.0 기준 ROIC = 31.84%

[4] ROE 와의 대비 — 가나전자 사업은 그대로 두고 차입금 비중만 바꾼다
  투하자본 1500·NOPAT 156.0 은 고정, 차입금 + 자본 = 1700 (현금 200 차감 전)
       차입금      자본      순이익      ROE     ROIC
       0.0  1700.0    156.0    9.18%   10.40%
     400.0  1300.0    140.4   10.80%   10.40%
     800.0   900.0    124.8   13.87%   10.40%
    1200.0   500.0    109.2   21.84%   10.40%

[5] 자본비용과 나란히 놓기 (자본비용은 가정값 8%)
  가나전자  ROIC 10.40% - 자본비용 8.00% = +2.40%p, 투하자본에 곱하면 +36.0
  다라물산  ROIC 31.20% - 자본비용 8.00% = +23.20%p, 투하자본에 곱하면 +116.0

[6] 두 회사의 실제 ROE (기말 자본 기준)
  가나전자  순이익 124.8 / 자본 900.0 = 13.87%
  다라물산  순이익 152.1 / 자본 650.0 = 23.40%
