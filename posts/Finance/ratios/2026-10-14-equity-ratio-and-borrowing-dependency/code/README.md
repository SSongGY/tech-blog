# 예제 코드 — 자기자본비율과 차입금의존도 — 안정성을 보는 다른 각도

총자본 1,000과 매출액 1,200, 영업이익 120을 똑같이 맞춘 가상 회사 세 곳으로
자기자본비율·부채비율·차입금의존도를 계산한다. 자기자본비율과 부채비율이 서로 환산되는
같은 정보라는 것, 그 둘이 같아도 차입금의존도는 15.0%와 52.0%로 갈린다는 것,
매입채무를 단기차입금으로 바꾸면 앞의 두 지표는 그대로고 차입금의존도와 이자비용만
올라간다는 것을 확인한다. 금융비용 대 매출액을 세 지표의 곱으로 분해해 검산한다.

차입금평균이자율은 연 5.0%로 가정했다. 의존성은 없고 표준 라이브러리만 쓴다.

## 실행

```bash
python equity_and_borrowings.py
```
