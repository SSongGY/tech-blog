# 예제 코드 — 안정성 비율, 부채비율과 유동비율

부채비율이 똑같이 200%인 가상 회사 셋(마바제조·사자제조·아자전력)과 가상 은행
차카은행의 부채비율·자기자본비율·차입금의존도·유동비율을 한국은행 기업경영분석 산식으로
계산한다. 업종 집계값은 한국은행 「2024년 1/4분기 기업경영분석」 표에서 옮겼다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python stability.py
```

## 바꿔볼 값

- `SAJA.liability_detail` 에서 선수금을 차입금으로 옮기면(그리고 `borrowings` 를 맞추면) 부채비율은 그대로인데 `[2]` 의 이자비용이 커진다.
- `BANK_ASSETS` 의 위험가중치는 설명용 가정이다. 기업대출을 국공채로 옮기면 부채비율은 그대로인데 `[6]` 의 자본 ÷ 위험가중자산이 올라간다.
