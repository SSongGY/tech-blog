# 예제 코드 — 순차입금과 Net Debt/EBITDA — 빚의 크기를 이익으로 재기

자기자본 400 과 부채총계 600 을 똑같이 맞춰 부채비율을 150.0% 로 고정한 가상 회사
세 곳으로 순차입금과 순차입금배수를 계산한다. 부채비율과 차입금의존도가 같은 두 회사의
배수가 1.00 배와 3.00 배로 갈린다는 것, 순차입금이 똑같이 150 인 두 회사의 배수가
1.00 배와 3.00 배로 갈린다는 것, 배수가 같은 3.00 배라도 순차입금은 450 과 150 으로
세 배 차이가 난다는 것을 차례로 확인한다.

그다음 배수를 상환 연수로 읽을 수 없는 이유를 이자·법인세·자본적지출을 빼고 계산하고,
꺼낼 수 없는 현금을 차감에서 제외하면 배수가 어떻게 올라가는지, 운용리스를
사용권자산으로 인식하면 EBITDA 와 순차입금이 함께 움직인다는 것을 본다.
마지막으로 차입금의 기초·기말 조정표를 K-IFRS 제1007호 문단 44B 의 변동 유형으로 적는다.

금액 단위는 억원이고 차입금평균이자율 5.0%·리스 금액·법인세 납부액은 설명용 가정값이다.
의존성은 없고 표준 라이브러리만 쓴다.

## 실행

```bash
python net_debt_multiple.py
```
