# 예제 코드 — 운전자본 증감 — 이익과 현금흐름을 가장 크게 벌리는 항목

가상 회사 `사름식품`의 매출액만 바꿔 역성장 −20%·정체·성장 +20%·급성장 +50% 네 경우를
만든다. 매출원가율 70%·판관비율 24%·회전일수(매출채권 60일, 재고 70일, 매입채무 30일)는
네 경우가 모두 같으므로 영업이익률은 6.00% 로 고정된다. 그런데도 영업활동 현금흐름은
−12.85 에서 105.66 까지 갈린다.

간접법의 조정 항목과 부호는 K-IFRS 제1007호 문단 20(1)을 따른다. 영업활동 현금흐름이
0 이 되는 성장률을 이분법으로 찾고, 회전일수만 줄이면 같은 급성장에서 현금흐름이 어떻게
뒤집히는지, 재무상태표의 매출채권 차액과 현금흐름표에서 조정할 금액이 왜 다른지를 본다.

금액 단위는 억원이고 회전일수·법인세율 22%·감가상각비율 2.5% 는 설명용 가정값이다.
의존성은 없고 표준 라이브러리만 쓴다.
