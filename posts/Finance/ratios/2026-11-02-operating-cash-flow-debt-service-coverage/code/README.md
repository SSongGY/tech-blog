# 예제 코드 — 영업현금흐름으로 보는 상환 능력

가상 회사 `가나정밀`과 `다라소재`는 매출액 2,000·영업이익 180·이자비용 50·총차입금 1,000이
모두 같다. 그래서 이자보상배율은 둘 다 3.60배로 똑같이 나온다. 다른 것은 감가상각비와
운전자본 증감 둘뿐인데, 이 둘만으로 영업활동 현금흐름이 195와 50으로 갈린다.

분자를 영업이익에서 영업활동 현금흐름으로 바꿨을 때, 그리고 분모에 1년 내 갚아야 할
원금까지 넣었을 때 지표가 어떻게 달라지는지를 계산한다. 마지막 블록은 매출 성장률만
0%·10%·20%로 바꿔, 운전자본이 묶이는 속도가 상환능력 지표를 어떻게 끌어내리는지 본다.

간접법 조정 항목과 부호는 K-IFRS 제1007호 문단 20을, 이자지급을 영업활동으로 분류하는
처리는 같은 기준서 문단 31·33을 따른다. 발생 이자비용과 현금 이자지급액은 같다고 두었다.

금액 단위는 억원이고 모든 숫자는 계산 원리를 보이려고 만든 가상 값이다.
의존성은 없고 표준 라이브러리만 쓴다.

## 실행

```bash
python debt_service_coverage.py
```
