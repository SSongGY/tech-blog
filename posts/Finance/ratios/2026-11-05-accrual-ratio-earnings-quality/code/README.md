# 예제 코드 — 발생액 비율

가상 회사 `마바화학`·`사아식품`·`아자식품`은 당기순이익 120·감가상각비 40·평균총자산
1,000이 모두 같다. 다른 것은 운전자본 증감뿐이다. 간접법으로 영업활동 현금흐름을 구하고,
순이익에서 그 값을 뺀 발생액을 평균총자산으로 나눈다. 사아식품과 아자식품은 발생액이
같지만 원인(매출 성장 / 회수일수 연장)이 다르다는 것을 회수일수로 가른다.

발생액을 `순이익 − 영업활동 현금흐름`으로 구하는 현금흐름표 방식이다. 재무상태표 증감으로
구하는 방식도 있고 둘의 값은 다를 수 있다. 금액 단위는 억원이며 모든 숫자는 가상 값이다.
의존성은 없고 표준 라이브러리만 쓴다.

## 실행

```bash
python accrual_ratio.py
```
