# 예제 코드 — EBITDA 마진 — 편하지만 틀리기 쉬운 지표

매출액 1,000 과 EBITDA 200 을 똑같이 맞춰 EBITDA 마진을 20.0% 로 고정한 가상 회사
세 곳으로, 같은 마진에서 잉여현금흐름이 어디까지 갈리는지를 계산한다.
감가상각비가 120·15·90 으로 다르므로 영업이익률이 8.0%·18.5%·11.0% 로 먼저 갈리고,
자본적지출이 150·20·40 으로 다시 다르므로 잉여현금흐름이 한 번 더 갈린다.

그다음 리스부채 원금 상환이 자본적지출에 잡히지 않는다는 것, 자본적지출이 감가상각비를
덮는지를 배수로 보는 것, 같은 리스 거래를 운용리스로 적었을 때 EBITDA 마진이
어떻게 달라지는지, 감가상각비를 유지 지출의 대용치로 써서 성장 투자를 걷어낸 현금을
구하는 것, 설비를 감가상각비보다 덜 사며 5년을 버티면 EBITDA 마진이 그대로인 동안
순장부금액이 어떻게 줄어드는지를 차례로 확인한다.

금액 단위는 억원이고 이자·법인세 납부액과 리스 금액은 설명용 가정값이다.
운전자본 변동은 0 으로 둔다. 의존성은 없고 표준 라이브러리만 쓴다.
