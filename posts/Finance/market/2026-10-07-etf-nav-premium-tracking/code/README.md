# 예제 코드 — ETF, 순자산가치와 시장가격

가상 ETF 로 1좌당 순자산가치(NAV)를 계산하고, 시장가격이 NAV 와 벌어질 때의 괴리율과
투자자가 더 내거나 덜 낸 금액을 본다. 지정참가회사의 차익거래가 비용보다 큰 괴리에서만
일어나는 것을 계산하고, 보수와 복제 방식이 다른 두 ETF 로 추적차이와 추적오차를 잰다.
파이썬 표준 라이브러리만 쓴다. `[4]` 의 지수 경로는 시드를 고정한 난수라 매번 같다.

## 실행

```bash
python etf_nav_tracking.py
```

## 바꿔볼 값

- `print_arbitrage()` 의 `cost_rate` 를 올리면 손익이 + 로 돌아서는 괴리율이 함께 올라간다.
- `print_tracking()` 의 나 ETF 에서 일간 오차를 `0.0` 으로 두면 추적오차가 0 에 가까워진다.
