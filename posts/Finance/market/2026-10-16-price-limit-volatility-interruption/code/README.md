# 예제 코드 — 가격제한폭과 변동성완화장치

매도호가가 얇게 깔린 가상 종목에 큰 시장가 매수 주문 하나가 들어오는 상황을
체결 단위로 따라간다. 같은 주문·같은 호가창을 두고 장치만 바꿔 가며 돌려서,
어느 장치가 몇 번째 호가 단계에서 걸리는지, 그때까지 몇 주가 체결되는지,
평균 체결가가 어떻게 달라지는지를 찍는다.

- 장치가 하나도 없을 때
- 가격제한폭 ±30% 만 있을 때 — 상한가 밖 호가는 접수 자체가 거부된다
- 동적 VI 만 있을 때 — 직전 체결가 대비 3%(코스피200 구성종목) / 6%(일반·코스닥)
- 정적 VI 10% 만 있을 때 — 직전 단일가격 대비
- 넷을 같이 걸었을 때, 그리고 2분 단일가를 거쳐 재개하기를 반복했을 때

호가창과 주문 수량은 판정 순서를 보이려고 만든 가상 값이다. 호가 단계의 간격도
설명을 위해 임의로 벌려 두었다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python price_guards.py
```

## 바꿔볼 값

- `ASK_BOOK` 의 잔량을 늘리면 같은 주문이 낮은 단계에서 다 소화되어 어떤 장치도
  걸리지 않는다. 장치가 걸리는 조건이 호가가 얇다는 것임이 그때 드러난다.
- `DYNAMIC_GENERAL` 을 `STATIC_VI` 보다 크게 두면 `[6]` 의 첫 발동 장치가
  정적 VI 로 바뀐다. 두 장치의 참조가격이 다르다는 것이 순서를 가른다.
- `PRICE_LIMIT` 을 0.15 로 두면 2015년 6월 이전의 ±15% 가 된다. `[7]` 의 마지막
  체결가가 그만큼 낮은 자리에서 끝난다.
- `repeat=True` 를 `False` 로 바꾸면 첫 발동에서 세운 모습만 본다.
