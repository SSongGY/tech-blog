# 예제 코드 — 증거금률과 반대매매

가상 회사 **가나전자**를 놓고, 같은 예수금이 증거금률에 따라 얼마까지 주문할 수
있는지를 세고, 그 한도까지 샀을 때 결제일(T+2)에 모자라는 돈이 얼마인지,
못 채우면 다음 날 몇 주가 어떤 가격 기준으로 팔리는지를 단계별로 찍는다.

- `[1]` 증거금률 100%·40%·30%·20% 별 주문 가능액과 결제일 부족액
- `[2]` 증거금률 40%로 샀을 때 주가 변동이 내 몫에서 몇 배로 나타나는지
- `[3]` 반대매매 — 수량은 하한가로 세고 체결은 시장가로 나는 구조
- `[4]` 미수동결계좌 지정 뒤 30일간의 매수 한도

주가·예수금·증거금률·연체이자율은 계산 구조를 보이려고 만든 값이다. 실제 종목도
아니고 특정 증권사의 기준도 아니다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python margin_deposit.py
```

## 바꿔볼 값

- `MARGIN_RATES` 에 `0.50` 을 넣으면 `[1]` 의 부족액이 그만큼 줄어든다. 증거금률과
  결제일 부족액이 같은 숫자의 앞뒤라는 것이 그때 보인다.
- `SETTLE_PRICE` 를 `10_000` 으로 올리면 `[3]` 의 하한가가 7,000원이 되어 산정
  수량이 줄어든다. 반대매매 수량이 주가와 반대로 움직인다.
- `leverage(0.40)` 의 인자를 `1.00` 으로 바꾸면 `[2]` 의 배수가 1.0이 된다.
  증거금률 100%에서는 빚이 없으므로 주가 변동이 그대로 내 몫의 변동이다.
- `OVERDUE_RATE` 는 가정값이다. 연체이자율은 증권사와 기간에 따라 다르다.
