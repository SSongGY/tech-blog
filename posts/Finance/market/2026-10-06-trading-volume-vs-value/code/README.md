# 예제 코드 — 거래량과 거래대금

가상 종목 가나전자(주가 2천 원대)와 다라물산(주가 20만 원대)의 하루 체결 내역으로
거래량·거래대금·회전율을 계산한다. 액면분할 전후 거래량과 거래대금의 모양,
상장규정 거래량 요건(반기 월평균거래량이 유동주식수의 1% 미만)의 계산도 찍는다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python volume_vs_value.py
```

## 바꿔볼 값

- 다라물산의 체결가를 전부 20만 원으로 맞추면 종가×거래량과 거래대금의 차이가 0이 된다.
- 마바산업의 6월 거래량을 200,000주로 올리면 반기 월평균이 1%를 넘는다.
