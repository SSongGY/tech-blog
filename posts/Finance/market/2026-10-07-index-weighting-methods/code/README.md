# 예제 코드 — 주가지수는 어떻게 계산되는가

주가와 상장주식수가 서로 다른 가상 종목 가나정밀·다라통신·마바유통으로 주가 가중 지수와
시가총액 가중 지수를 함께 만든다. 같은 하루 등락에 두 지수가 반대로 움직이는 것, 액면분할
때 주가 가중 지수만 제수를 고쳐야 하는 것, 유동비율을 곱하면 비중이 바뀌는 것을 계산한다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python index_weighting.py
```

## 바꿔볼 값

- `print_one_day()` 의 `moves` 에서 가나정밀을 `0.0` 으로 두면 두 지수가 같은 방향으로 움직인다.
- `STOCKS` 의 유동비율을 모두 `1.0` 으로 두면 `[4]` 의 두 비중 열이 같아진다.
