# 예제 코드 — 배당락과 권리락

기준일에서 T+2 결제를 거꾸로 세어 마지막 매수일과 락일을 구하고, 가상 회사
마바식품의 현금배당·주식배당·주주배정 유상증자 각 경우에 락일의 이론 가격을
계산한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python ex_dates.py
```

## 바꿔볼 값

- `SETTLEMENT_LAG` 를 1 로 두면 T+1 결제에서 락일이 기준일 당일로 옮겨 가는 것을 볼 수 있다.
- `HOLIDAYS` 에서 12월 31일을 빼면 연말 기준일의 마지막 매수일이 하루 늦춰진다.
