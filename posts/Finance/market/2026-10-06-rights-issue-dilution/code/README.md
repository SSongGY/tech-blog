# 예제 코드 — 유상증자

가상 회사 가나전자가 신주 200만 주를 주주배정·제3자배정·일반공모로 발행할 때
발행가와 이론권리락주가를 계산하고, 10% 주주 갑이 청약·권리 매각·실권·배정 없음
각 경우에 지분율과 순재산이 어떻게 바뀌는지 본다. 이어서 할인율과 증자비율을
바꿔 가며 기존 1주의 가치 감소율을 표로 뽑고, 주주배정 뒤 비교표시 EPS 조정계수를
계산한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python rights_issue.py
```

## 바꿔볼 값

- `NEW_SHARES` 를 5_000_000 으로 두면 증자비율 50% 가 되어 실권한 주주의 손실이 커진다.
- `issue_prices()` 의 제3자배정 할인율을 0 으로 두면 지분율은 똑같이 줄지만 순재산 증감은 0 이 된다.
