# 채권 기초 — 표면금리·만기수익률·듀레이션

가상 종목 네 개(`가나전자 3년물`·`다라물산 3년물`·`마바중공업 10년물`·
`사아리스 30년물`)를 놓고 현재가치 정의만으로 가격·만기수익률·듀레이션을 계산한다.
할인율을 올리면 가격이 왜 떨어지는지, 가격에서 수익률을 거꾸로 찾는 이분법,
듀레이션이 현금흐름 회수의 무게중심이라는 것, 듀레이션 근사가 남기는 오차를
볼록성이 얼마나 메우는지까지 본다. 실재하는 채권이 아니다.

이표 조건은 국고채를 본떴다 — 액면 10,000원, 매6월후급.

## 실행

```bash
python bond_math.py
```

의존성 없음. 표준 라이브러리만 쓴다.
