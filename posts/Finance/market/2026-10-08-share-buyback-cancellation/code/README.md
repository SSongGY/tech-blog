# 예제 코드 — 자사주 매입과 소각

가상 회사 가나전자(주가가 BPS보다 높음)와 다라물산(주가가 BPS보다 낮음)이
발행주식의 10%를 사들일 때 EPS·BPS·PER·PBR·ROE가 어떻게 바뀌는지 계산한다.
배당가능이익 한도, 매입한 해의 가중평균유통주식수, 보유 중과 소각 후의
상장주식수·시가총액·지분율 차이도 함께 본다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python buyback.py
```

## 바꿔볼 값

- `AFTER_TAX_YIELD` 를 0.10 으로 올리면 매입 현금이 벌던 이익이 커서 EPS 상승 폭이 줄어든다.
- `BUYBACK` 을 늘리면 BPS 변화가 매입 가격과 BPS의 차이만큼 더 커진다.
