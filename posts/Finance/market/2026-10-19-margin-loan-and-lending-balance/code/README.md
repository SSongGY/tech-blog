# 예제 코드 — 신용융자 잔고와 대차 잔고

가상 회사 **가나전자**를 놓고, 돈을 빌려 산 자리(신용융자)와 주식을 빌려 둔
자리(대차)를 나란히 센다. 둘 다 "잔고"라고 부르지만 단위가 다르고, 주가가
움직일 때 보이는 값도 다르다.

- `[1]` 신용융자 600만 원의 주가별 담보비율과 종목군별(140·145·150·160%) 미달 여부
- `[2]` 담보 부족을 현금으로 메울 때와 반대매매로 메울 때의 크기 차이
- `[3]` 포지션을 그대로 둔 채 주가만 움직일 때 두 잔고가 보이는 값
- `[4]` 빌린 주식 중 공매도로 나간 비중을 모를 때 셀 수 있는 것과 없는 것

주가·융자금·담보유지비율은 계산 구조를 보이려고 만든 값이다. `[4]`의 공매도
비중도 가정값이고 실제 비중을 뜻하지 않는다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python borrowed_positions.py
```

## 바꿔볼 값

- `MAINTENANCE` 의 값을 전부 `1.40` 으로 두면 `[1]` 의 네 칸이 같은 자리에서
  바뀐다. 종목군을 나누는 일이 곧 미달 지점을 앞당기는 일임이 그때 보인다.
- `PREV_CLOSE` 를 `9_000` 으로 낮추면 `[2]` 의 하한가가 6,300원이 되어 같은 부족분에
  더 많은 수량이 팔린다. 주가가 낮을수록 반대매매가 커지는 이유다.
- `OWN_CASH` 를 `6_000_000` 으로 올리면 `LOAN` 이 400만 원으로 줄어 `[1]` 의 비율이
  전 구간에서 올라간다. 자기 자금 비중이 곧 버티는 폭이다.
- `LENT_QTY` 는 `[3]`·`[4]` 내내 고정이다. 이 값을 바꿔도 금액이 주가에 연동된다는
  구조 자체는 달라지지 않는다.
