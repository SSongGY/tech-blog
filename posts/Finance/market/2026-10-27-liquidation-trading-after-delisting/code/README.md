# 정리매매 — 거래 조건이 가격에 무엇을 하는가

가상 회사 **가나전자**의 상장폐지가 결정됐다고 두고, 정리매매 기간의 거래 조건이
체결 기회·가격 범위·실수령액에 어떻게 작용하는지 계산한다. 실재하는 종목의 값은
쓰지 않는다.

## 실행

```bash
python liquidation_trading.py
```

의존성은 없다. 표준 라이브러리만 쓴다.

## 내용

| 절 | 무엇을 계산하나 |
|---|---|
| [1] | 09:00~15:30 매 30분 단일가 체결 시각과 7거래일 합계 횟수 |
| [2] | 가격제한폭 ±30%가 걸렸다고 가정했을 때 7거래일로 갈 수 있는 바닥 |
| [3] | 주가가 내려갈수록 호가가격단위 1원이 차지하는 비율 |
| [4] | 평균 체결가별 매도대금·증권거래세·실수령액 |
| [5] | 팔지 않고 상장폐지일을 넘겼을 때 남는 것 |
