# 금리가 바뀌면 무엇이 먼저 움직이는가

가상 회사 둘(`가나소프트`·`다라중공업`)의 현재 기업가치를 같은 금액으로 맞춰 놓고,
현금흐름이 들어오는 시점만 다르게 두어 할인율 1%p 에 가치가 얼마나 갈리는지 본다.
주식 듀레이션(현재가치 가중 평균 회수 시점), 영구성장모형에서 r−g 가 좁혀질 때
민감도가 커지는 정도, 무위험이자율과 리스크프리미엄이 따로 움직이는 경우까지
계산한다. 실재하는 기업이 아니다.

영구현금흐름은 200년까지 명시적으로 펼쳐 더하고, 잘라낸 꼬리가 영구성장모형
닫힌 식과 얼마나 다른지를 출력 1절에서 확인한다.

## 실행

```bash
python discount_rate.py
```

의존성 없음. 표준 라이브러리만 쓴다.
