# 예제 코드 — 액면분할과 무상증자

가상 회사 자차소재의 1:10 액면분할과 카타산업의 1:1 무상증자로 자본 항목이 어떻게
움직이는지, 주주 지분율과 이론 시가총액이 유지되는지 계산한다. 이어서 1주당 0.3주를
배정할 때 생기는 단주와 그 지분율 영향, 무상증자 뒤 비교표시 EPS를 소급해 고치는
이유를 본다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python split_bonus.py
```

## 바꿔볼 값

- `print_bonus_issue()` 의 `ratio` 를 0.5 로 두면 자본금 전입액과 이론 주가가 함께 바뀐다. 자본총계 열은 그대로다.
- `print_fractional_shares()` 의 주주 보유 수를 10 의 배수로 두면 단주가 생기지 않아 지분율이 전후로 같다.
