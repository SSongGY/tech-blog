# 프로그램매매와 차익거래 — 괴리를 재고 잔고가 쌓이는 과정

가상 지수 `가나200`과 그 지수선물을 놓고 세 가지를 계산한다.

1. **이론가격과 괴리** — 보유비용모형으로 선물 이론가격을 구하고,
   시장 선물가격이 그 위·아래·근처에 있을 때 각각 무엇이 성립하는지 판정한다.
   왕복 거래비용을 넘지 못하는 괴리는 차익거래를 부르지 않는다.
2. **만기 보유 손익** — 매수차익·매도차익을 만기까지 들고 갔을 때의 손익을
   항목별로 쪼갠다. 만기 지수를 390과 450 두 가지로 바꿔 넣어도 합계가
   같다는 것을 숫자로 확인한다. 지수 방향에 걸지 않는 거래이기 때문이다.
3. **잔고 경로** — 괴리가 날마다 달라질 때 매수차익잔고가 쌓였다가
   만기에 전부 풀리는 과정을 누적한다. 만기일에 현물 쪽으로 몰리는
   물량이 어디서 나오는지가 여기서 보인다.

이자율·배당·거래비용·계약 단위는 계산을 보이려고 둔 가정값이고 코드 주석에
그렇게 적어 두었다. 프로그램매매·지수차익거래의 구분 기준은 한국거래소
규정포털의 설명을 따랐고, 계산 자체는 규정이 정하는 것이 아니다.

실재하는 지수·종목이 아니다. 지수값과 가격 경로 전부 지어낸 값이다.

## 실행

```bash
python index_arbitrage.py
```
