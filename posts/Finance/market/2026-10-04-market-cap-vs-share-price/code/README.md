# 예제 코드 — 시가총액과 주가

주가가 10배 차이 나는 가상 회사 가나전자·다라바이오로 주가와 시가총액이 서로 다른 것을
재는 것을 계산하고, 같은 회사를 주식 수만 달리 나눴을 때 주가와 EPS가 함께 움직여 PER이
그대로인 것을 본다. 끝으로 자기주식을 가진 가상 회사 마바물산으로 어느 주식 수를
곱하느냐에 따라 시가총액과 PER이 달라지는 것을 확인한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python market_cap.py
```

## 바꿔볼 값

- `print_treasury_shares()` 의 `treasury` 를 0 으로 두면 두 기준의 시가총액이 같아지고, 두 PER 도 같아진다.
- `print_same_company_two_prices()` 의 주식 수 목록에 다른 값을 넣어도 PER 열은 움직이지 않는다.
