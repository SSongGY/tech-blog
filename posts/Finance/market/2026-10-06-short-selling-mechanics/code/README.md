# 예제 코드 — 공매도

가상 종목 가나전자 1,000주를 빌려 10,000원에 팔고 여러 가격에 되사는 경우의 손익,
주가에 따라 유지해야 하는 담보(평가액의 105%), 상환기간에 따른 대차 수수료,
직전가 이하 호가 금지 규칙이 허용하는 가장 낮은 공매도 호가를 계산한다.
대차 수수료율 연 4%는 계산을 보이려고 둔 가정값이다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python short_selling.py
```

## 바꿔볼 값

- `FEE_RATE` 를 0.10 으로 올리면 주가가 그대로여도 90일 손실이 커지는 것을 볼 수 있다.
- `SELL_PRICE` 를 바꾸면 최대 이익(매도대금 − 수수료)이 같이 바뀐다.
