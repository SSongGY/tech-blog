# 시간외거래와 단일가매매 — 정규장 밖에서 가격이 정해지는 방식

가상 종목 `가나전자`의 종가 단일가 호가장(매수 5건·매도 6건)을 놓고,
가격마다 몇 주가 체결되는지 전부 세어 합치가격을 찾는다. 그 가격 하나로
체결했을 때 누가 얼마를 받는지, 같은 호가를 접속매매로 돌리면 접수 순서에
따라 결과가 어떻게 갈리는지, 단일가는 순서를 바꿔도 같은 값이 나오는지까지 본다.

마지막에 체결수량이 같은 가격이 둘 생기는 호가장을 따로 만들어, 체결수량만으로는
가격이 하나로 정해지지 않는 경우를 보인다.

실재하는 종목이 아니다. 호가·수량·접수시각 전부 지어낸 값이다.

## 실행

```bash
python auction_match.py
```

의존성 없음. 표준 라이브러리만 쓴다.
