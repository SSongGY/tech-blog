# 주식에 붙는 세금 — 세전 수익과 세후 수익이 벌어지는 폭

가상 회사 **가나전자**·**다라물산** 주식을 두고 배당소득세·증권거래세·양도소득세가
각각 어느 시점에 얼마를 떼는지 계산한다. 실재하는 종목의 값은 쓰지 않는다.

## 실행

```bash
python stock_taxes.py
```

의존성은 없다. 표준 라이브러리만 쓴다.

## 내용

| 절 | 무엇을 계산하나 |
|---|---|
| [1] | 시장별 증권거래세 부담률과 실수령액 |
| [2] | 같은 세전 수익을 배당으로 받을 때와 시세차익으로 받을 때의 실효세율 |
| [3] | 매매 횟수가 거래세를 통해 10년 누적 잔액에 미치는 폭 |
| [4] | 금융소득 2,000만원 경계와 비교과세 — 전액 합산이라는 오해와의 차이 |
| [5] | 대주주 상장주식 양도소득세 — 기본공제 후 3억원 이하 20%, 초과 25% |

세율의 근거 조문은 `stock_taxes.py` 머리말 주석과 글의 참고 자료에 적어 두었다.
