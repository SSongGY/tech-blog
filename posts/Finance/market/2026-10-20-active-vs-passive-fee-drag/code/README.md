# 액티브와 패시브 — 보수가 장기 수익률을 깎는 정도

가상 상품 세 개(`가나액티브주식형`·`다라인덱스펀드`·`마바지수ETF`)의 보수·비용을
놓고, 비용 전 수익률을 연 7% 로 똑같이 고정한 채 30년까지 잔액을 계산한다.
액티브가 ETF 와 같은 잔액이 되려면 매년 몇 %p 를 더 벌어야 하는지, 알파가 평균 0 인
분포일 때 비용을 뺀 뒤 ETF 를 앞서는 비율이 얼마인지, 회전율이 총보수 밖에서
얼마를 더 가져가는지까지 본다. 실재하는 펀드나 ETF 가 아니다.

## 실행

```bash
python fee_drag.py
```
