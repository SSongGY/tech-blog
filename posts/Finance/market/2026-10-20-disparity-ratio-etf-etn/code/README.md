# 괴리율 — ETF·ETN 가격이 기준가와 벌어질 때

가상 상장지수증권 `가나변동성 ETN` 의 숫자로 전일 지표가치에서 당일 실시간
지표가치를 만들고, 괴리율 하나에 공시·관리의무·지정예고·거래정지 가운데 무엇이
붙는지 판정한다. 13 거래일 경로를 넣어 음수 괴리율을 절댓값으로 세느냐에 따라
투자유의종목 지정 여부가 갈리는 것을 보인다. 실재하는 종목이 아니다.

문턱과 조치는 금융위원회 2026-08-12 보도자료에 적힌 2026-08-19 시행 기준이다.

## 실행

```bash
python disparity_ratio.py
```
