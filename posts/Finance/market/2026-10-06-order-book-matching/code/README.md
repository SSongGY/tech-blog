# 예제 코드 — 호가와 체결

가상 종목 가나전자의 호가창 한 장면을 만들고 지정가·시장가 주문을 차례로 넣어,
가격우선·시간우선 규칙에 따라 어느 주문과 어느 가격에 체결되는지 찍는다.
접속매매(복수가격 개별경쟁매매)만 흉내 낸다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python order_book.py
```

## 바꿔볼 값

- 매도 C 의 시각을 `09:00:05` 로 바꾸면 같은 10,040원에서 C 가 B 보다 먼저 체결된다.
- 주문 K 의 가격을 10,030 으로 올리면 I 하나와만 체결되고 잔량 500주가 매도 호가로 남는다.
