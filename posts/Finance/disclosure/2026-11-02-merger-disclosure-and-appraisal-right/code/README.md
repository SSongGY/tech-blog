# 합병비율·법정 매수가격·매수청구 물량 계산

가상 회사 `가나전자`(존속)와 `다라물산`(소멸)으로 세 가지를 센다.

- 자본시장법 시행령 제176조의7 제3항 제1호의 매수가격 — 2개월·1개월·1주일
  가중산술평균가격을 각각 구하고 셋을 단순평균한다
- 합병비율이 달라질 때 합병 후 지분율
- 매수청구 물량이 늘어날 때 회사가 내는 현금과 남은 주주의 의결권 지분율
