# 예제 코드 — 연결재무제표와 별도재무제표

가상 지주 가나홀딩스(종속기업 가나소재 100%·가나물류 60%, 관계기업 라마바이오 30%)의
별도재무제표와 연결재무제표를 같은 입력으로 계산해 나란히 놓는다. 연결은 줄 단위 합산,
투자-자본 상계, 내부 매출·채권채무 제거, 비지배지분 분리, 관계기업 지분법 순서로 만든다.
끝에서 연결 지배지분이 별도 자본에 취득 후 늘어난 자본의 지배 몫을 더한 값과 같은지 검산한다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python consolidation.py
```

## 바꿔볼 값

- `SUBS` 에서 가나물류의 `liabilities` 를 올리고 `assets` 를 같이 올리면 별도 부채비율은 그대로이고 연결 부채비율만 오른다.
- 가나소재의 `dividend_out` 과 `PARENT["dividend_in"]` 을 0 으로 두면 별도 순이익만 줄고 연결 순이익은 그대로다.
