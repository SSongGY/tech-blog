# 예제 코드 — 지분공시 세 갈래 판정

가상 회사 `가나전자`의 주주 구성과 대표이사 김가나의 한 해 거래 내역 한 벌을
두고, 같은 거래가 대량보유상황보고(5%룰)·임원·주요주주 소유상황보고·거래계획
사전공시 중 어느 의무를 건드리는지 판정한다. 단기매매차익 반환액도 같은
거래로 계산한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python insider_reporting.py
```

## 바꿔볼 값

- `HOLDERS` 의 `기관 마바자산운용` 보유량을 `2_000_000` 으로 올리면 본인
  지분이 정확히 10% 가 되어 주요주주가 되고, `[1]` 에서 소유상황보고 대상으로
  바뀐다. 5%룰 대상 여부는 그대로다.
- `TRADES` 1번의 수량을 `1_000` 으로 올리면 그 한 건이 수량 기준에 걸려
  `[2]` 의 첫 줄부터 보고가 되고, 누적이 쌓이는 모양이 사라진다.
- 7번 매도 수량을 `130_000` 으로 줄이면 `[4]` 합산 금액이 약 47억원이 되어
  두 요건을 모두 채우고 사전공시 의무가 사라진다. 지분율은 원래부터 1% 아래라
  금액 한 쪽만 내려가면 된다.
- 7번 매도 수량을 `250_000` 으로 올리면 보유비율이 1.25%p 움직여 `[3]` 에서
  처음으로 5%룰 변동보고가 뜬다.
- 7번 날짜를 `date(2026, 8, 5)` 로 당기면 5번 매수(6/10)와 6개월 안에 들어와
  `[5]` 에서 짝이 지어진다. 다만 5번 물량은 6번 매도에 이미 소진되므로
  반환액은 그대로다. 6번을 지우면 150,000주 중 400주가 짝지어진다.
