# 예제 코드 — 공시 시한 계산

가상 회사 가나전자(12월 결산)와 다라물산(3월 결산)의 정기보고서 법정 시한을
민법 방식(역에 의한 계산, 말일이 토·공휴일이면 다음 날)으로 계산하고, 거래소
수시공시·조회공시 시한을 매매거래일 기준으로 계산한다. 파이썬 표준 라이브러리만 쓴다.

공휴일은 예제 날짜 범위에 걸리는 것만 `HOLIDAYS` 에 넣었다. 임시공휴일처럼 해마다
새로 정해지는 날은 들어 있지 않다.

## 실행

```bash
python disclosure_deadlines.py
```

## 바꿔볼 값

- `print_periodic()` 의 연도 목록에 2027 을 넣으면 FY2027 사업보고서 시한이 윤년 때문에 3월 30일로 나온다.
- `HOLIDAYS` 에서 2024-05-15 를 지우면 FY2024 1분기보고서 시한이 5월 15일로 돌아간다.
