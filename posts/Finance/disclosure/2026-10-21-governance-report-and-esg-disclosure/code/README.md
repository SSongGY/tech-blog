# 예제 코드 — 서술형 공시에서 비교 가능한 항목만 골라내기

가상 회사 `가나전자`·`다라물산`의 지배구조 핵심지표 15개 응답을 두고 준수율을
계산하고, 같은 준수율이 정반대 모양을 덮어 버리는 것을 영역별 분해로 드러낸다.
전기 대비 변화도 어느 지표가 붙고 빠졌는지까지 쪼갠다. 지속가능성 공시는
아직 대상 판정만 가능하므로 가상 회사 네 곳이 언제부터 의무 대상이 되는지
계산한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python governance_disclosure.py
```

## 바꿔볼 값

- `COMPANIES` 의 `가나전자` 당기 응답에서 감사기구 네 항목을 모두 `True` 로
  바꾸면 준수율이 80% 로 오른다. `[3]` 에서 두 회사의 모양 차이가 사라지는지
  확인해 보면, 준수율이 아니라 영역 분포가 비교의 축이라는 점이 분명해진다.
- `INDICATORS` 의 영역 분류는 가이드라인이 지표마다 명시한 것이 아니라 핵심원칙
  구성(주주 / 이사회 / 감사기구)에 맞춰 묶은 것이다. 묶는 방식을 바꾸면 `[3]`
  의 해석도 달라진다.
- `ESG_CANDIDATES` 에 연결자산총액 `5_000_000_000_000` 짜리 회사를 넣으면
  경계값이 2029년 기준에 정확히 걸리는지 볼 수 있다. 코드는 `>=` 로 판정한다.
- `ESG_SCHEDULE` 의 2028년 기준을 `30_000_000_000_000` 으로 되돌리면 2026년
  2월 의견수렴안 기준이 되고, `[7]` 에서 가나전자가 대상에서 빠진다.
