# XBRL 인스턴스와 보고서 표에서 같은 숫자를 꺼내 보기

가상 회사 `가나전자`의 매출액·영업이익을 두 가지 모양으로 두고 같은 계산을 시킨다.

- `gana_electronics.xml` — XBRL 인스턴스를 구조만 같게 줄인 것. 기간(context)과
  단위(unit)가 값에 붙어 있다
- `xbrl_vs_text.py` — 인스턴스를 표준 라이브러리로 파싱해 사실을 전부 꺼내고,
  두 기간을 골라 증감률을 센다

숫자는 전부 지어낸 값이다. 실제 DART 인스턴스는 K-IFRS 택사노미의 요소 이름을 쓰고
파일 하나에 수천 개의 사실이 들어간다.

## 실행

```bash
python xbrl_vs_text.py
```

의존성 없음. 표준 라이브러리만 쓴다.
