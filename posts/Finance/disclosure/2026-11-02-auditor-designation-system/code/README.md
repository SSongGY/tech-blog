# 감사인 지정 사유 판정과 주기적 지정 타임라인

가상 회사 셋(`가나전자`·`다라물산`·`마바산업`)의 3개년 숫자로 두 가지를 센다.

- 외부감사법 제11조 제1항 제6호 가·나·다목 — 3개 사업연도 연속 영업이익 0 미만,
  영업현금흐름 0 미만, 이자보상배율 1 미만에 걸리는지
- 같은 조 제2항의 주기적 지정 — 자유선임 6년(3년 계약 두 번) 뒤 지정 3년

숫자는 전부 지어낸 값이고 단위는 억 원이다. 실제 기업의 재무제표가 아니다.

## 실행

```bash
python designation_check.py
```

의존성 없음. 표준 라이브러리만 쓴다.
