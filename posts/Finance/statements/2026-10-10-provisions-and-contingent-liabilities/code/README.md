# 예제 코드 — 충당부채와 우발부채 — 아직 나가지 않은 돈을 부채로 잡는 기준

K-IFRS 제1037호로 소송 1건의 인식 여부가 패소 확률에 따라 갈리는 모습, 판매보증의 기댓값,
보증 비율 추정만 다른 가상 회사 가나전자·다라물산의 연도별 보증비용과 충당부채 잔액,
5년 뒤 원상복구 의무의 현재가치와 해마다 붙는 이자비용을 계산한다.
단위는 백만원이고 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python provisions.py
```

## 바꿔볼 값

- `WARRANTY_OUTCOMES`의 확률이나 수리비를 바꾸면 대당 기대 수리비가 바뀐다.
- `print_two_companies`에서 다라물산의 1년차 추정을 3으로 낮추면 2년차에 환입 대신 추가 비용이 생긴다.
