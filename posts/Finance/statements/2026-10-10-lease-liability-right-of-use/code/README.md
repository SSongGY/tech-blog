# 예제 코드 — 리스 회계 — 임차료가 부채로 올라가면 부채비율과 이익이 어떻게 움직이는가

같은 매장을 같은 임차료(연 100억원)로 쓰는 가상 회사 둘을 비교한다. 가나유통은 5년 계약이라
K-IFRS 제1116호에 따라 리스료의 현재가치를 리스부채·사용권자산으로 올리고, 다라마트는
1년 계약을 매년 새로 맺어 단기리스 면제로 임차료를 비용 처리한다. 리스부채 상각표,
연도별 비용 시점 차이, 첫해 부채비율·EBITDA·영업이익·현금흐름 분류, 할인율 민감도를 찍는다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python lease_accounting.py
```

## 바꿔볼 값

- `BORROWING_RATE`를 0.10으로 올리면 리스부채가 줄고 첫해 이자는 늘어 비용이 앞쪽에 더 몰린다.
- `LEASE_YEARS`를 10으로 늘리면 리스부채가 커지고 부채비율 차이도 벌어진다.
