# 예제 코드 — 배당가능이익

상법 제462조 제1항의 공제식을 항목별로 세우고, 제458조의 이익준비금 적립 의무가
한도를 한 번 더 깎는 경로를 계산한다. 자기주식만 다른 두 회사(가나전자·다라물산)와
적립 의무가 많이 남은 회사(마바산업) 셋을 비교한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python distributable_profit.py
```

## 바꿔볼 값

- `DARA` 의 `treasury` 를 바꾸면 이익잉여금 잔액과 배당가능이익의 차이가 그만큼
  따라 움직인다. 공제식에서 자기주식을 빼 주지 않기 때문이다.
- `MABA` 의 `earned_reserve` 를 250 으로 올리면 적립 의무가 사라져 한도의 10/11
  제약이 풀린다.
- `unrealised` 를 0 이 아닌 값으로 두면 제4호 공제가 켜진다. 다만 그 범위는
  상법 시행령에 위임되어 있어 이 글에서 확인하지 못했다.
