환경: Python 3.13.5
가정: 원가 70, 공정가치 100, 5년 매년 말 수취, 시장이자율 10%, 무보증잔존가치 10 (단위: 억원)

[0] 일반 판매로 팔았을 때 (문단 72의 비교 대상)
    매출 100.00 - 원가 70.00 = 매출총이익 30.00

[1] 시장이자율 10%로 리스료를 정한 경우
  시장이자율로 할인
    연 리스료                    24.74
    할인에 쓴 이자율               10%
    리스료 현재가치              93.79
    무보증잔존가치 현재가치       6.21
    매출액 = min(100, 현재가치)  93.79
    매출원가 = 70 - 잔존 현재가치 63.79
    매출총이익                   30.00
    리스순투자                  100.00

[2] 판촉 이자율 2%로 리스료를 정한 경우 — 할인율을 어떻게 고르느냐
  (가) 내건 2%로 할인 — 문단 73이 막는 처리
    연 리스료                    19.29
    할인에 쓴 이자율                2%
    리스료 현재가치              90.94
    무보증잔존가치 현재가치       9.06
    매출액 = min(100, 현재가치)  90.94
    매출원가 = 70 - 잔존 현재가치 60.94
    매출총이익                   30.00
    리스순투자                  100.00

  (나) 시장이자율 10%로 할인 — 문단 73의 처리
    연 리스료                    19.29
    할인에 쓴 이자율               10%
    리스료 현재가치              73.14
    무보증잔존가치 현재가치       6.21
    매출액 = min(100, 현재가치)  73.14
    매출원가 = 70 - 잔존 현재가치 63.79
    매출총이익                    9.35
    리스순투자                   79.35

    개시일 이익 차이 (가)-(나) = 20.65

[3] 판촉 리스의 연도별 이익 — 개시일 매출총이익 + 금융수익 (단위: 억원)
    시점     (가) 2% 처리    (나) 10% 처리
  ----------------------------------
   개시일         30.00          9.35
     1년          2.00          7.93
     2년          1.65          6.80
     3년          1.30          5.55
     4년          0.94          4.18
     5년          0.57          2.66
  ----------------------------------
    합계         36.47         36.47
  5년 말 순투자 잔액: (가) 0.00 / (나) 0.00
  현금 검산: 리스료 합계 96.47 + 잔존가치 10.00 - 원가 70.00 = 36.47

[4] 리스 체결 원가 (문단 74)
    성과수수료 0.50 → 개시일 비용. 순투자에 넣지 않는다
    (나) 처리의 개시일 영업 손익 = 9.35 - 0.50 = 8.85
    리스순투자는 그대로 79.35
