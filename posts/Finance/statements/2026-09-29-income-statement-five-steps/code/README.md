# 예제 코드 — 손익계산서, 매출에서 순이익까지 다섯 단계

매출 200억·당기순이익 10억이 같은 가나전자와 다라물산(둘 다 가상)의 손익을
매출총이익 → 영업이익 → 법인세비용차감전순이익 → 당기순이익 순으로 풀어,
단계마다 무엇을 뺐는지와 매출액 대비 비율을 계산한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python income_steps.py
```

## 바꿔볼 값

- `TAX_RATE`는 가정값이다. 바꿔도 세전이익까지의 단계는 달라지지 않는다.
- 다라물산 `기타수익`을 0으로 두면 `[4]`와 같은 결과가 `[2]`에 나온다.
