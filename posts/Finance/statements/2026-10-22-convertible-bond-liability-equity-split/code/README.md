# 예제 코드 — 전환사채와 신주인수권부사채

가상 회사 가나전자가 발행한 전환사채를 잔여법으로 부채요소와 자본요소로 나누고,
부채요소의 유효이자율법 상각표를 만든다. 같은 1,000억을 일반사채·전환사채·유상증자로
조달했을 때 부채비율과 3년 이자비용이 어떻게 갈리는지, 전환권을 행사할 때와 만기까지
갈 때 재무제표가 어떻게 달라지는지, 신주인수권부사채가 전환사채와 어디서 갈리는지를
계산한다. 금액은 억원이고 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python convertible_bond_split.py
```

## 바꿔볼 값

- `MARKET_RATE`를 `0.04`로 낮추면 부채요소가 커지고 자본요소가 줄어든다. 전환권의 값은
  표면이자율과 시장이자율의 차이에서 나오므로, 둘이 같아지면 자본요소가 0이 된다.
- `COUPON_RATE`를 `0.08`로 올려 시장이자율과 맞추면 자본요소가 사라지고 일반사채와
  같아진다.
- `CONVERSION_PRICE`를 `10_000`으로 낮추면 같은 액면에서 발행되는 신주가 두 배가 된다.
  회계처리 금액은 그대로이고 주식 수만 바뀐다.
