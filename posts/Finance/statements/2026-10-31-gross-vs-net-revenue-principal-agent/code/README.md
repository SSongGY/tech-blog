# 예제 코드 — 총액 인식과 순액 인식, 본인인가 대리인인가

가상 회사 가나플랫폼(중개)과 다라커머스(직매입)가 같은 규모의 거래를 했을 때,
K-IFRS 제1115호의 본인·대리인 판단(문단 B34~B37A)에 따라 매출액이 몇 배로
갈리고 영업이익은 그대로 남는 과정을 계산한다. 거래액을 고정한 채 직매입
비중만 올렸을 때 매출액이 늘어나는 구간도 같은 숫자로 이어 본다.

실재하는 회사가 아니고 숫자도 대비를 보이려고 만든 것이다. 단위는 백만원이다.

## 실행

```bash
python gross_vs_net.py
```
