# 예제 코드 — 확정기여제도와 확정급여제도

가상 회사 셋을 한 해 동안 따라간다. 가나전자는 확정기여제도, 다라물산과 마바화학은
확정급여제도이고 두 회사는 기초 순확정급여부채가 같다. 할인율이 1%p 내려간 해에
당기손익·기타포괄손익·기말 순부채가 어떻게 갈리는지, 할인율이 다시 움직이면 순부채가
얼마나 흔들리는지 계산한다. 금액은 억원이고 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python pension_dc_db.py
```

## 바꿔볼 값

- `RATE_CLOSE`를 `0.05`로 두면 보험수리적손익이 0이 되어 기타포괄손익에 자산 재측정요소만 남는다.
- `ACTUAL_RETURN`을 `0.05`로 올리면 자산 쪽 재측정요소가 0이 된다.
- `DURATION`을 늘리면 같은 할인율 변화에 대한 확정급여채무의 변동이 커진다.
