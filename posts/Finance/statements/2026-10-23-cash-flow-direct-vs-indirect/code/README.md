# 예제 코드 — 현금흐름표 직접법과 간접법

가상 회사 가나전자의 한 해를 두 방법으로 각각 적어 본다. 포괄손익계산서와 재무상태표
변동을 같은 입력으로 두고 간접법과 직접법을 따로 계산해 영업에서 창출된 현금이
같은 값으로 모이는지 확인한다. 매입채무 증가분에 설비 취득 대금이 섞였을 때
영업활동 현금흐름이 얼마나 부풀려지는지도 함께 계산한다. 금액은 억원이고
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python cash_flow_methods.py
```

## 바꿔볼 값

- `D_AR_NET`을 `0`으로 두면 간접법의 운전자본 조정이 작아지면서 당기순이익과
  영업활동 현금흐름의 차이가 줄어든다.
- `SGA_BAD_DEBT`를 바꾸면 직접법의 고객 유입과 그 밖의 영업비용 유출이 같은 폭으로
  함께 움직여 합계는 그대로 남는다. 두 자리를 한쪽만 고치면 두 방법이 어긋난다.
- `PAYABLE_FOR_EQUIPMENT`를 키우면 [5]에서 부풀려지는 금액이 그만큼 커진다.
