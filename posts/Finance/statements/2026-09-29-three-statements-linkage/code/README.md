# 예제 코드 — 재무제표 세 장은 서로 어떻게 이어지는가

가상 회사 가나전자의 한 해 거래 11건을 분개장에 적고, 같은 분개장에서
손익계산서·이익잉여금 변동·현금흐름표(직접법·간접법)·재무상태표를 계산한다.
마지막에 세 장이 이어지는 네 곳을 `assert`로 검산한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python three_statements.py
```

## 바꿔볼 값

- `외상 매출` 금액을 0으로, `현금 매출`을 1,000으로 바꾸면 순이익은 그대로인데
  영업활동 현금흐름이 200 늘어난다.
- `배당금 지급`을 지우면 기말 이익잉여금과 기말 현금이 함께 40씩 커진다.
