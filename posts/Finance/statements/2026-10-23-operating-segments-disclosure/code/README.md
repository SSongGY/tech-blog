# 예제 코드 — 부문별 정보

가상 회사 사아산업의 여덟 개 영업부문 자료를 놓고, K-IFRS 제1108호가 정한
양적기준(문단 13)과 외부수익 75% 기준(문단 15)을 그대로 적용해 어느 부문이
별도 보고 대상인지 가린다. 전사 합계 하나만 볼 때와 부문별로 나눠 볼 때
이익률이 어떻게 달라 보이는지도 함께 계산한다. 금액은 억원이고 파이썬
표준 라이브러리만 쓴다.

## 실행

```bash
python segment_reporting.py
```

## 바꿔볼 값

- 헬스케어의 부문손익 `-120`을 `-50`으로 올리면 손익 기준에 걸리지 않아
  보고부문에서 빠지고, 적자 부문 하나가 '그 밖의 모든 부문'으로 묻힌다.
- 디스플레이·소프트웨어·신사업의 외부수익을 낮추면 1차 보고부문의 외부수익
  비율이 75%를 넘어 문단 15의 추가 식별이 일어나지 않는다.
- `UNALLOCATED_HQ_COST`를 바꾸면 [7]의 조정에서 부문손익 합계와 기업전체
  손익의 차이가 그만큼 벌어진다.
