# 예제 코드 — 재무상태표 — 자산은 어디서 왔는가

설비 100억을 빌린 돈으로 산 가나전자와 주주 돈으로 산 다라물산(둘 다 가상)을 만들고,
거래마다 자산 = 부채 + 자본이 유지되는지 `assert`로 검산한다. 영업이익을 세 가지로
바꿔 가며 두 회사의 순이익과 자본이익률(ROE)을 계산한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python funding_mix.py
```

## 바꿔볼 값

- `INTEREST_RATE`를 0.10으로 올리면 두 회사의 자본이익률이 같아지는 영업이익이 15로 올라간다.
- `apply`에 한쪽만 움직이는 거래(`{"현금": 10}`)를 넣으면 `assert`가 멈춘다.
