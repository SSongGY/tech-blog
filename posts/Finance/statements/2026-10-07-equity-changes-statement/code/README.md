# 예제 코드 — 자본변동표 — 자본은 무엇으로 늘고 무엇으로 줄었는가

기초 자본 1,000이 같은 가상 회사 둘(가나전자·다라물산)의 한 해 거래를 자본 구성요소별로
적용해 자본변동표 모양으로 찍는다. 기말 자본총계는 둘 다 1,100이지만 납입자본과
이익잉여금의 구성이 다르고, 그 차이가 상법 제462조의 배당 한도로 이어지는 것을 계산한다.
끝에서 자기주식을 샀다가 되파는 거래가 당기손익을 거치지 않고 자본만 움직이는 것을 본다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python equity_changes.py
```

## 바꿔볼 값

- `EVENTS["가나전자"]`의 배당을 150으로 올리면 기말 자본이 1,000으로 돌아가고 배당 한도가 그만큼 준다.
- `TREASURY_EVENTS`의 처분가를 25로 내리면 차익 대신 차손 5가 생기는데, 이것도 당기손익이 아니라 자본에서 빠진다.
