# 예제 코드 — 영업·투자·재무 활동, 현금흐름 세 갈래 읽기

자차전자·카타산업·파하물산(모두 가상)의 현금흐름표를 항목부터 쌓아 세 활동 합계를 내고,
세 부호의 조합을 Dickinson(2011)의 생애주기 분류에 대 본다. 마지막에 카타산업이
창고 하나를 판 해에 분류가 어떻게 바뀌는지 계산한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python three_activities.py
```

## 바꿔볼 값

- `NEXT_YEAR`의 창고 처분액을 90으로 줄이면 투자활동 합계가 음수로 돌아와 다시 성숙기로 분류된다.
- 자차전자의 `유상증자`를 빼고 `장기차입`을 `차입금 상환` −20으로 바꾸면 부호가 성숙기(+ − −)가 된다. 그해 현금은 200 줄어드는데도 그렇다.
