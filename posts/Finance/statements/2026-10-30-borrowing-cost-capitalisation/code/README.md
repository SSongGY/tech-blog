# 예제 코드 — 차입원가 자본화, 이자가 비용이 아니라 자산이 되는 구간

가상 회사 가나전자가 2026년에 짓는 제2공장을 적격자산으로 보고, K-IFRS 제1023호에
따라 특정차입금(문단 12)과 일반차입금(문단 14)으로 나누어 자본화할 차입원가를
계산한다. 공사가 두 달 중단됐을 때 자본화액이 얼마나 줄어드는지(문단 20),
그리고 전액 비용 처리한 회사와 11년에 걸쳐 어떻게 갈렸다가 다시 만나는지까지
같은 숫자로 이어 본다.

실재하는 회사가 아니고 숫자도 대비를 보이려고 만든 것이다.

## 실행

```bash
python borrowing_cost.py
```

의존성 없음. 표준 라이브러리만 쓴다.
