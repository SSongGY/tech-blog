# 예제 코드 — 영업권 — 인수 대가가 순자산보다 클 때 남는 숫자와 손상검사

같은 가상 회사(하나소재, 공정가치 순자산 800억원)를 1,000·1,300·700억원에 사들인 가상 회사
셋의 영업권과 염가매수차익을 K-IFRS 제1103호 문단 32·34로 계산한다. 80% 인수 때 비지배지분
측정 방법에 따른 영업권 차이, 1년 뒤 같은 회수가능액에서 갈리는 손상차손, 영업권을 넘는 손상의
배분 순서(제1036호 문단 104), 회복 후에도 환입하지 않는 영업권(문단 124)을 찍는다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python goodwill.py
```

## 바꿔볼 값

- `RECOVERABLE_YEAR1`을 1,000으로 올리면 가나전자는 손상이 없고 다라화학만 300을 인식한다.
- `TARGET_ASSETS`의 공정가치를 장부금액과 같게 두면 순자산이 650이 되어 모든 회사의 영업권이 150씩 커진다.
