# 예제 코드 — 외화환산 — 환율이 바뀌면 재무제표 어디가 움직이는가

K-IFRS 제1021호로 화폐성·비화폐성 항목의 기말 환산 차이, 외화 매출채권과 차입금을
함께 가진 가상 회사 가나전자와 매출채권만 가진 다라물산의 연도별 외환손익,
기능통화가 달러인 해외 자회사를 원화로 환산할 때 생기는 해외사업환산차이를 계산한다.
외화는 천 달러, 원화는 백만원이고 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python fx.py
```

## 바꿔볼 값

- `RATE_PATH`를 모두 같은 값으로 두면 [3]의 외환손익이 전부 0이 된다.
- `SUB_YEARS`의 기말 환율을 거래일 환율과 같게 두면 [4]의 환산차이가 0에 가까워진다.
