# 예제 코드 — 매출채권과 재고자산, 자산인데 위험한 자산

매출·매출원가·영업이익이 똑같은 고노상사와 도로상사(둘 다 가상)의 매출채권·재고자산
회전율과 회전일수를 한국은행 기업경영분석 산식(매출액 ÷ 평균잔액)으로 계산한다.
2년차에 도로상사만 채권과 재고가 크게 불었을 때 영업활동 현금흐름, 손실충당금,
재고 평가손실이 어떻게 갈리는지도 본다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python turnover.py
```

## 바꿔볼 값

- `DORO`의 2년차 말 매출채권을 200으로 낮추면 `[2]`·`[5]`에서 두 회사 채권 쪽 숫자가 같아진다.
- `LOSS_RATES`와 `AGING`은 가정이다. 실제 회사는 과거 회수 경험으로 이 표를 만들고 주석에 공시한다.
