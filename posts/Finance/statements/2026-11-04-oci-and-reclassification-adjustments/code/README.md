# 예제 코드 — 기타포괄손익과 재분류조정

같은 증권을 같은 값에 사서 같은 값에 판 가상 회사 셋이 평가이익 60억원을 당기손익,
채무상품 기타포괄손익, 지분상품 기타포괄손익 세 경로로 적을 때 당기순이익·기타포괄손익·
총포괄이익·자본 구성·ROE 가 2년간 어떻게 갈리는지 계산한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python oci_reclassification.py
```

## 바꿔볼 값

- `FAIR_VALUE_Y1` 을 올리면 세 경로의 차이가 그만큼 커진다. 취득원가보다 낮게 두면
  평가손실이 되어 부호만 뒤집힌 같은 구조가 나온다.
- `OPERATING_INCOME` 을 줄이면 ROE 차이가 상대적으로 커 보인다. 본업 이익이 작을수록
  증권 손익의 경로가 지표를 크게 움직인다.
- `TAX_RATE` 를 0 이 아닌 값으로 두면 세후 금액으로 바뀌지만 세 경로가 같은 자본총계에
  닿는 것은 변하지 않는다.
