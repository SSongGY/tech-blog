# 예제 코드 — 현금흐름표, 이익이 나는데 돈이 없는 이유

매출 성장과 순이익률이 같은 마바상사와 사아유통(둘 다 가상)을 4년간 굴려,
외상 회수일·재고 보유일만 다를 때 영업활동 현금흐름이 어떻게 갈리는지 계산한다.
간접법으로 구한 값을 직접법으로 다시 구해 검산한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python working_capital.py
```

## 바꿔볼 값

- `TERMS`에서 사아유통의 회수일을 30으로 줄이면 두 회사의 현금흐름 차이가 재고분만 남는다.
- `SALES`를 전부 같은 값으로 두면(성장 없음) 운전자본 증가가 0이 되어 영업CF = 순이익 + 감가상각비가 된다.
