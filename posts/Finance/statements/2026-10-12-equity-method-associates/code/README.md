# 예제 코드 — 지분법 — 관계기업 투자가 한 줄로만 보이는 이유

K-IFRS 제1028호로 가상 회사 가나전자가 마바소재 지분 40%를 취득한 뒤의 지분법 장부금액
움직임을 계산하고, 같은 40%를 연결로 처리했다고 가정했을 때의 재무제표와 나란히 비교한다.
관계기업 손실이 장부금액을 넘을 때 인식을 멈추는 규칙도 계산한다.
금액은 백만원이고 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python equity_method.py
```

## 바꿔볼 값

- `OWNERSHIP`을 바꾸면 지분법이익과 비지배지분 몫이 함께 움직이지만, 지배기업 몫 순이익은 두 방식에서 계속 같다.
- `LOSS_PATH`의 손실을 줄이면 [4]의 미인식 누계가 생기지 않는다.
