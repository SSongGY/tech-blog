# 예제 코드 — 유형자산 손상차손, 회수가능액은 둘 중 큰 값이다

가상 회사 가나제철의 압연 설비 한 대를 두고 K-IFRS 제1036호 자산손상의
회수가능액 산정을 따라간다. 순공정가치(문단 6)와 사용가치(문단 30·31)를 각각
계산해 큰 쪽을 회수가능액으로 잡고, 할인율이 바뀌면 둘의 순위가 뒤집히는 구간,
손상 인식 후 감가상각(문단 63), 환입 한도(문단 117)와 영업권의 환입 금지(문단 124)
까지 같은 숫자로 이어 본다.

실재하는 회사가 아니고 숫자도 대비를 보이려고 만든 것이다. 단위는 백만원이다.

## 실행

```bash
python impairment.py
```

의존성 없음. 표준 라이브러리만 쓴다.
