# 예제 코드 — 유동과 비유동을 왜 나누는가

유동비율이 150%로 같은 가나전자와 다라물산(둘 다 가상)을 K-IFRS 제1001호
문단 66·69·70·72 규칙대로 분류하고, 유동 항목이 현금화·결제되는 시점을 달별로
놓아 남는 현금을 계산한다. 거래 없이 만기만 다가와 분류가 바뀌는 경우와 차환 약정
시점에 따라 분류가 갈리는 경우도 함께 본다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python current_split.py
```

## 바꿔볼 값

- 다라물산 `단기차입금`의 개월 수를 3에서 11로 바꾸면 `[2]`의 모자란 달이 사라진다. 유동비율은 그대로 150%다.
- `[4]`의 `defer_right`만 분류를 바꾼다. 약정을 맺은 시점이 기말 뒤라면 `False`로 둔다.
