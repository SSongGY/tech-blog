# 예제 코드 — 어디까지가 현금인가 — 현금성자산과 단기금융상품

K-IFRS 제1007호 '현금흐름표' 문단 6~9·45·48 의 요건을 함수로 옮기고,
같은 금액의 여유자금을 다르게 굴린 가상 두 회사(가나전자·다라물산)의 재무상태표 표시,
현금비율, 현금흐름표 기말 현금을 계산한다. 금액은 백만원이고 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python cash_equivalents.py
```

## 바꿔볼 값

- `HOLDINGS` 의 다라물산 정기예금 만기를 `6` 에서 `3` 으로 바꾸면 두 회사의
  현금비율과 기말 현금이 같아진다. 돈이 아니라 만기가 표시를 가른다는 것이 보인다.
- `RESTRICTED_DEMAND_DEPOSIT` 을 `0` 으로 두면 [3] 의 두 현금비율이 같아진다.
