# 예제 코드 — 회계정책 변경·전기오류 수정·회계추정치 변경

기업회계기준서 제1008호가 세 갈래를 다르게 처리하는 것을 가상 회사 아자상사의 2년치
손익으로 계산한다. 정책 변경(재고 단위원가 선입선출 → 가중평균)은 소급적용으로 비교기간
손익과 기초 이익잉여금을 고치고, 전기오류(비용 누락)는 소급재작성으로 비용을 원래
기간으로 돌려보내며, 추정치 변경(내용연수 연장)은 전진적용이라 비교기간을 손대지
않는다. 각 경우에 순이익 성장률이 어떻게 달라지는지 본다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python restatement_three_ways.py
```

## 바꿔볼 값

- `INVENTORY_WAVG` 의 2년 말 값을 더 낮추면 당기 매출원가 조정이 커져 소급적용 후
  성장률이 더 낮아진다. 두 방법의 재고 차이가 같은 속도로 커지면 성장률은 거의
  움직이지 않는다. 차이의 **변화**가 손익을 움직이기 때문이다.
- `OMITTED_EXPENSE` 를 키우면 비교기간과 당기의 순이익이 반대 방향으로 같은 크기만큼
  움직인다. 두 해 합계는 항상 같다.
- `NEW_REMAINING_LIFE` 를 줄이면 당기 감가상각비가 변경 전보다 커질 수도 있다. 어느
  쪽이든 1년차 줄은 그대로다.
