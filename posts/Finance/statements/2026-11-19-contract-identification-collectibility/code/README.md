# 예제 코드 — 계약의 식별

가상 회사 자차소재가 고객 넷과 맺은 같은 조건의 1년 공급 계약에 기업회계기준서 제1115호 문단 9~16 을 적용한다. 계약 개시시점에 다섯 조건을 충족하는지(문단 9), 양쪽 모두 무보상 해지할 수 있어 계약이 없는 것으로 보는지(문단 12), 중간에 회수 가능성을 재검토하는지(문단 13), 조건을 못 채운 계약에서 받은 현금을 언제까지 부채로 두는지(문단 15·16)를 분기별로 계산한다. 표준 라이브러리만 쓴다.

## 실행

```bash
python contract_identification.py
```
