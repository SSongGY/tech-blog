# 예제 코드 — 감가상각, 현금이 나가지 않는 비용

같은 설비(원가 1,000, 잔존가치 100, 내용연수 5년)를 산 거너정밀과 더러정밀(둘 다 가상)이
정액법과 정률법으로 감가상각할 때 연도별 비용·장부금액·영업이익·영업활동 현금흐름을 계산한다.
2년차 말에 설비를 팔면 처분손익이 어떻게 갈리는지도 본다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python depreciation.py
```

## 바꿔볼 값

- `RESIDUAL`을 0에 가깝게 줄이면 정률법 상각률이 1에 가까워진다. 이 식은 잔존가치가 0이면 쓸 수 없다.
- `SALE_PRICE`를 바꿔도 `[5]` 마지막 줄의 두 회사 값은 늘 같다. 처분손익이 감가상각 차이를 되돌리기 때문이다.
