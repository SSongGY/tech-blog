# 예제 코드 — 투자부동산의 원가모형과 공정가치모형

기업회계기준서 제1040호 문단 30 이 고르게 하는 두 모형으로 같은 임대 건물을 5년간
따라간다. 원가모형은 감가상각비가 매년 같은 금액으로 손익에 들어가고, 공정가치모형은
공정가치 변동분이 그해 손익에 들어간다(문단 35). 영업현금흐름은 두 모형이 같다는 것,
누적 순이익의 차이가 장부금액의 차이와 항상 같다는 것, 부채비율과 ROE 가 그래서
갈린다는 것을 계산한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python investment_property_models.py
```

## 바꿔볼 값

- `SAHA` 의 `fair_values` 를 계속 오르는 경로로 바꾸면 공정가치모형의 순이익이 해마다
  원가모형보다 크다. 내리는 해를 넣으면 그해 순이익이 원가모형 아래로 떨어진다.
- `life` 를 줄이면 원가모형의 감가상각비가 커져 원가모형 순이익이 낮아진다. 공정가치
  모형에는 영향이 없다.
- `liabilities` 를 올리면 부채비율의 절대 수준이 올라가지만 두 모형의 차이가 생기는
  이유는 같다. 분모인 자본총계가 장부금액 차이만큼 다르기 때문이다.
