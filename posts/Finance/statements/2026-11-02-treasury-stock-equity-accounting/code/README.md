# 예제 코드 — 자기주식의 회계

가상 회사 가나전자가 자기주식을 취득하고, 비싸게 한 번 싸게 한 번 처분하고,
남은 몫을 소각할 때 자본의 어느 줄이 얼마나 움직이는지 따라간다. 손익계산서는
네 거래 모두 건드리지 않는데 EPS·ROE·BPS 는 바뀐다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python treasury_stock.py
```

## 바꿔볼 값

- `FEE_RATE` 를 0 으로 두면 자본거래 거래원가가 빠져 취득원가가 액면 그대로
  15,000원이 된다. 처분손익이 그만큼 달라진다.
- `dispose` 의 처분 가격을 바꾸면 자본잉여금(자기주식처분이익)과
  자본조정(자기주식처분손실) 중 어느 쪽에 닿는지가 갈린다.
- `retire` 가 줄이는 항목을 `이익잉여금` 에서 `자본금` 으로 바꿔 보면
  상법 제343조 제1항 단서의 소각과 자본금 감소 절차의 소각이 어떻게 다른지 보인다.
