# 예제 코드 — 매출채권 손실충당금, 기대신용손실을 어떻게 잡는가

가상 회사 가나전자·다라물산의 매출채권을 K-IFRS 제1109호 간편법(문단 5.5.15)에 따라
충당금 설정률표(문단 B5.5.35)로 계산한다. 과거 손실 실적에서 충당률을 뽑고,
전망 정보로 조정하고, 연령 구간별 잔액에 곱해 전체기간 기대신용손실을 구한 뒤,
그 금액이 손익계산서와 현금흐름표에서 각각 어떻게 움직이는지까지 이어 본다.

실재하는 회사가 아니고 숫자도 대비를 보이려고 만든 것이다.

## 실행

```bash
python expected_credit_loss.py
```

의존성 없음. 표준 라이브러리만 쓴다.
