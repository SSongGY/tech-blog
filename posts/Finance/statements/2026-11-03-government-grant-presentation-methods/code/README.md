# 예제 코드 — 자산관련 정부보조금의 두 가지 표시

기업회계기준서 제1020호 문단 24~27 이 인정하는 이연수익법과 자산차감법으로 같은
보조금을 5년간 따라간다. 당기손익 효과가 같다는 것, 총자산과 총부채가 매년 같은
금액만큼 벌어져 자본총계는 변하지 않는다는 것, 부채비율·총자산회전율·EBITDA 가
그래서 갈린다는 것을 계산한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python government_grant_presentation.py
```

## 바꿔볼 값

- `MABA` 의 `grant` 를 올리면 두 방법의 재무상태표 차이가 그만큼 커진다. 보조금이
  취득원가에 가까울수록 자산차감법 쪽 설비 장부금액이 0 에 가까워진다.
- `life` 를 늘리면 차이가 더 오래 남는다. 내용연수가 끝나는 해에 두 방법이 다시
  만나는 것은 변하지 않는다.
- `tax_rate` 를 0 이 아닌 값으로 두면 세후 순이익이 줄지만 두 방법의 값은 여전히
  같다. 과세소득이 같기 때문이다.
