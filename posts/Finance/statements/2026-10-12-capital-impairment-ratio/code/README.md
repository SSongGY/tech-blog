# 예제 코드 — 자본잠식

자본잠식률을 한국거래소 정기결산 유의사항의 식으로 계산한다. 납입액이 같고 액면만 다른
두 가상 회사에 같은 손실을 쌓아 잠식률이 갈리는 과정, 무상감자·유상증자로 잠식을 푸는
경우의 숫자, 연결 기준에서 비지배지분을 빼는 효과를 찍는다. 금액은 억원이고 파이썬
표준 라이브러리만 쓴다.

## 실행

```bash
python capital_impairment.py
```

## 바꿔볼 값

- `COMPANIES`에서 다라물산의 `par_value`를 `5000`으로, `share_premium`을 `0`으로 바꾸면 두 회사의 결과가 같아진다.
- `NET_LOSSES`의 마지막 값을 `-5`로 두면 4년차에도 완전잠식에 이르지 않는다.
