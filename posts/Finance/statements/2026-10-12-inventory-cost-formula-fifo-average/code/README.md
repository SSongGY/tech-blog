# 예제 코드 — 재고자산 평가 — 선입선출과 가중평균이 이익을 가르는 자리

K-IFRS 제1002호의 원가 공식 두 가지를 같은 매입·판매 내역에 적용한다.
가상 회사 가나전자는 선입선출법, 다라물산은 총평균법을 쓴다. 3년 동안의 매출원가·
매출총이익·기말재고를 비교하고, 3년차 말 판매가 하락에 따른 저가법 평가손실을 계산한다.
단위는 백만원이고 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python inventory.py
```

## 바꿔볼 값

- `YEARS`의 매입 단가를 모두 같게 두면 두 방법의 결과가 같아진다.
- `NRV_SELLING_PRICE`를 20 이상으로 올리면 두 회사 모두 평가손실이 없다.
