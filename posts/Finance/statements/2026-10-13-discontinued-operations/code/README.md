# 예제 코드 — 중단영업 — 접기로 한 사업은 어떻게 표시되는가

K-IFRS 제1105호 '매각예정비유동자산과 중단영업'의 매각예정 분류 요건(문단 6~8),
순공정가치 측정(문단 15), 감가상각 중단(문단 25), 중단영업의 정의(문단 32),
단일금액 표시(문단 33), 비교표시 재작성(문단 34), 분류 취소(문단 36)를
가상 회사 마바중공업의 두 해 손익에 적용해 재작성 전후를 나란히 계산한다.
금액은 백만원이고 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python discontinued_operations.py
```

## 바꿔볼 값

- `FAIR_VALUE_LESS_COSTS_TO_SELL` 을 `CARRYING_AMOUNT` 보다 크게 두면 손상차손이
  0 이 되어 [5] 의 중단영업손익이 영업손익만 남는다.
- `SEGMENTS` 의 설비사업부 20X1년 영업이익을 양수로 바꾸면 [6] 의 계속영업 영업이익률이
  재작성 전보다 낮아진다. 접는 사업이 늘 적자인 것은 아니다.
