# 예제 코드 — 유형자산 원가모형과 재평가모형

같은 건물을 가진 가상 회사 둘을 따라간다. 가나전자는 원가모형, 다라물산은 2년차 말에
재평가모형으로 공정가치를 반영한다. 재평가 직후 부채비율, 그 뒤의 감가상각비와 영업이익,
처분할 때의 처분이익이 어떻게 갈리는지 계산하고, 토지로 평가증과 평가감의 비대칭을 보인다.
금액은 억원이고 파이썬 표준 라이브러리만 쓴다. 법인세 효과는 넣지 않았다.

## 실행

```bash
python revaluation_model.py
```

## 바꿔볼 값

- `FAIR_VALUE`를 `600`으로 내리면 재평가가 평가감이 되어 2년차 손익으로 바로 들어간다.
- `SALE_PRICE`를 바꿔도 두 회사의 처분이익 차이는 그대로다. 차이는 처분 직전 장부금액에서만 나온다.
- `section_5`의 경로를 바꿔 손익과 기타포괄손익이 어디서 갈리는지 확인할 수 있다.
