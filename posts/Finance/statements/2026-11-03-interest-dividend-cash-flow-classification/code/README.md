# 예제 코드 — 이자와 배당금의 현금흐름 분류

기업회계기준서 제1007호 문단 33·34 가 허용하는 두 가지 분류 조합으로 같은 회사의
현금흐름표를 두 번 작성한다. 세 활동의 금액은 갈리고 합계는 같다는 것, 영업활동
현금흐름을 쓰는 지표가 그만큼 따라 움직인다는 것, 정책이 다른 두 회사를 그대로
비교하면 순위가 뒤집힌다는 것을 계산한다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python interest_dividend_classification.py
```

## 바꿔볼 값

- `GANA` 의 `interest_paid` 를 올리면 두 작성 방식의 영업활동현금흐름 차이가 그만큼
  벌어진다. 차입이 많은 회사일수록 분류 선택이 크게 보인다.
- `NATURE_SPLIT` 의 `dividend_paid_to` 를 `"영업"` 으로 바꾸면 문단 34 의 대체 방법이
  켜진다. 영업활동현금흐름이 배당금지급만큼 더 줄어든다.
- `DARA` 의 `core_operating` 을 190 보다 낮추면 `[4]` 에서 공시 숫자와 환산 숫자의
  순위가 어긋나는 폭이 더 커진다.
