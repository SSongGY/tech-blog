# 예제 코드 — 이연법인세 — 회계이익과 과세소득이 다를 때 생기는 자산과 부채

가상 회사 가나전자의 설비 300억원을 회계는 정액법(100·100·100), 세무는 앞에 많이 상각하는
방법(150·100·50)으로 상각할 때 연도별 장부금액·세무기준액·일시적차이와 이연법인세부채를
K-IFRS 제1012호로 계산한다. 법인세비용이 당기법인세와 이연법인세의 합이라는 것, 영구적차이가
끼면 유효세율이 달라지는 것, 제품보증충당부채에서 생기는 이연법인세자산을 미래 과세소득 전망에
따라 인식하는 회사와 못 하는 회사의 차이를 찍는다. 세율은 20% 단일세율로 가정한다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python deferred_tax.py
```

## 바꿔볼 값

- `TAX_DEPRECIATION`을 `[100, 100, 100]`으로 두면 일시적차이가 생기지 않아 이연법인세가 0이다.
- `TAX_RATE`를 바꾸면 이연법인세부채 금액이 비례해 바뀐다. 실제로는 차이가 풀릴 기간의 세율을 쓴다(문단 47).
