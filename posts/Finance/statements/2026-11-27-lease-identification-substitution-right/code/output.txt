[1] 계약 조건별 판단
  A 차량번호 명시, 노선은 가나유통이 정함
    - 자산이 특정됨 (B13)
    - 공급자 대체권 없음
    - 경제적 효익의 대부분을 얻음 (B21)
    - 운행 노선·시간을 고객이 정함 → 사용 지시권 있음 (B24⑴)
    => 리스를 포함한다
  B 다라운송이 차고지의 같은 차종으로 언제든 교체
    - 자산이 특정됨 (B13)
    - 대체 효익 8 > 원가 2 → 실질적 대체권 (B14)
    => 리스가 아니다 (용역)
  C 교체는 3년 차부터만 가능
    - 자산이 특정됨 (B13)
    - 대체권이 특정일 이후에만 생김 → 실질적이지 않음 (B15)
    - 경제적 효익의 대부분을 얻음 (B21)
    - 운행 노선·시간을 고객이 정함 → 사용 지시권 있음 (B24⑴)
    => 리스를 포함한다
  D 차량번호 명시, 노선·시간은 다라운송이 정함
    - 자산이 특정됨 (B13)
    - 공급자 대체권 없음
    - 경제적 효익의 대부분을 얻음 (B21)
    - 운행 노선·시간을 공급자가 정함 → 사용 지시권 없음 (B24)
    => 리스가 아니다 (용역)
