# 예제 코드 — 수익 인식 5단계 — 묶어 판 상품의 매출은 언제 얼마씩 잡히는가

가상 회사 가나전자가 장비(개별 판매가격 900)와 3년 유지보수(연 100)를 960에 묶어 팔 때,
K-IFRS 제1115호의 5단계로 거래가격을 배분하고 연도별 매출·계약부채를 계산한다.
할인을 비례 배분할 때와 특정 수행의무에 붙일 때의 차이, 계약 건수가 늘 때 계약부채가
쌓이는 모양도 찍는다. 단위는 백만원이고 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python revenue_recognition.py
```

## 바꿔볼 값

- `CONTRACT_PRICE`를 1200으로 두면 할인이 없어져 배분액이 개별 판매가격과 같아진다.
- `MAINTENANCE_YEARS`를 늘리면 1년차 매출이 줄고 계약부채가 더 오래 남는다.
