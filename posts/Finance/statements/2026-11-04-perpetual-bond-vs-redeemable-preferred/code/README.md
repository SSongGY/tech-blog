# 예제 코드 — 영구채와 상환우선주

같은 500억원을 영구채(자본으로 분류)와 상환우선주(부채로 분류)로 조달한 가상 회사 둘의
재무상태표·손익 경로·부채비율·이자보상배율·ROE·보통주 EPS 를 계산한다. 분배금 25억원이
한쪽은 자본에서 직접 빠지고 다른 쪽은 이자비용이 되는 차이가 어느 지표를 움직이고 어느
지표를 움직이지 않는지 본다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python hybrid_liability_vs_equity.py
```

## 바꿔볼 값

- `COUPON` 을 올리면 당기순이익 차이와 이자보상배율 차이가 그만큼 커진다. 보통주 귀속
  순이익과 EPS 가 같다는 것은 변하지 않는다.
- `RAISED` 를 바꾸면 `[4]` 표의 한 줄을 고른 것과 같다. 조달 금액이 클수록 부채비율
  격차가 벌어진다.
- `TAX_RATE` 를 0 이 아닌 값으로 두면 두 회사의 세후 금액이 달라진다. 분배금을 비용으로
  뺀 쪽의 과세소득이 작아지기 때문인데, 실제 손금 인정 여부는 세법이 정하므로 이 모형이
  답하지 않는다.
