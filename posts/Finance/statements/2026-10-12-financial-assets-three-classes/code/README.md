# 예제 코드 — 금융자산 세 분류 — 상각후원가·FVOCI·FVPL

K-IFRS 제1109호의 분류 판단 순서를 함수로 옮기고, 같은 채권과 같은 주식을
상각후원가(AC)·기타포괄손익-공정가치(FVOCI)·당기손익-공정가치(FVPL)로 각각 분류했을 때
해마다의 당기손익과 기타포괄손익을 계산한다. 금액은 백만원이고 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python financial_assets.py
```

## 바꿔볼 값

- `MARKET_YIELDS`를 모두 `0.05`로 두면 공정가치가 액면에 머물러 세 분류의 손익이 같아진다.
- `SHARE_FAIR_VALUES`의 처분가를 취득원가보다 높이면 [3]의 당기손익 차이 방향이 뒤집힌다.
