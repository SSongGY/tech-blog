# 예제 코드 — 영업이익과 당기순이익이 크게 벌어질 때

매출 500억·영업이익 40억이 같은 가나전자와 다라물산(둘 다 가상)의 영업이익 아래 항목을
풀어, 가나전자만 당기순이익이 적자가 되는 경로를 계산한다. 이자비용, 달러 차입금의
외화환산손실, 영업권 손상차손, 지분법손실을 반복 여부와 현금 유출 여부로 나누고,
환율이 바뀌면 다음 해 순이익이 어떻게 달라지는지 본다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python income_gap.py
```

## 바꿔볼 값

- `RATE_CLOSE`를 `RATE_OPEN`과 같게 두면 외화환산손실이 0이 된다.
- `USD_DEBT`를 0으로 두면 환율이 얼마로 바뀌어도 `[4]`의 순이익이 같다.
- `TAX_RATE`는 가정값이다. 바꿔도 세전이익까지는 달라지지 않는다.
