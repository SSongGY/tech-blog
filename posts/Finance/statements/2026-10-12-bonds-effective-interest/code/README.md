# 예제 코드 — 차입금과 사채

같은 조건의 사채를 시장이자율 4%·5%·6%에서 발행했을 때의 발행가액과, 유효이자율법
상각표를 계산한다. 사채발행비가 유효이자율을 얼마나 올리는지, 은행 차입금과 비교하면
순서가 어떻게 바뀌는지, 만기가 다가오면 유동부채로 옮기는 시점을 찍는다. 금액은 억원이고
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python bond_effective_interest.py
```

## 바꿔볼 값

- `MARKET_RATES`의 할인발행 금리를 `0.08`로 올리면 할인액과 해마다의 상각액이 커진다.
- `issuance_costs()`의 `costs`를 `5`로 줄이면 회사채의 유효이자율이 은행 차입금보다 낮아진다.
