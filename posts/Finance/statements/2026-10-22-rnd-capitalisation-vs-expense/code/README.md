# 예제 코드 — 연구개발비 자산화와 비용 처리

같은 프로젝트에 같은 금액을 쓰는 가상 회사 둘을 7년 따라간다. 가나전자는 전액 비용으로
처리하고 다라물산은 지출의 60%를 개발비로 자산화했을 때, 연도별 영업이익·자산총계·
부채비율·ROA가 어떻게 갈리는지, 프로젝트 수명 전체로 보면 왜 같아지는지, 개발이
실패하면 무엇이 달라지는지를 계산한다. 금액은 억원이고 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python rnd_capitalisation.py
```

## 바꿔볼 값

- `CAPITALISE_RATIO`를 `1.0`으로 올리면 개발 기간의 영업이익이 그대로 400이 되어
  연구개발비가 손익계산서에서 완전히 사라진다. 그만큼 상각 부담이 뒤로 몰린다.
- `AMORT_YEARS`를 `10`으로 늘리면 해마다의 상각비가 절반으로 줄어 영업이익이 올라가지만,
  `HORIZON`을 넘겨 상각이 끝나지 않으므로 7년 합계가 더는 같아지지 않는다.
- `DEV_YEARS`를 `3`으로 늘리면 자산화 금액과 상각비가 함께 커진다.
