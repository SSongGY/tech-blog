# 대기행렬 시뮬레이션 예제

파이썬 표준 라이브러리만 쓴다. 설치할 것이 없다.

## 실행

```bash
python queueing.py
```

8가지 설정을 각각 40만 건씩 돌리므로 20~40초 걸린다.
시드를 고정했으므로 몇 번을 돌려도 같은 숫자가 나온다.

## 바꿔 볼 값

| 값 | 기본 | 바꾸면 |
|---|---|---|
| `REQUESTS` | 400000 | 줄이면 이용률 95% 구간에서 이론값과의 차이가 커진다. 혼잡할수록 수렴이 느리다 |
| `WARMUP` | 40000 | 빈 큐에서 출발한 초기 구간을 버리는 양. 0으로 두면 평균이 낮게 나온다 |
| `MEAN_SERVICE_MS` | 10.0 | 전부 비례해서 움직인다. 이용률이 정하는 것은 **배수**이지 절대값이 아니다 |
| `SEED` | 20261015 | 바꾸면 숫자가 조금 달라진다. 이론값과의 거리가 어느 정도 흔들리는지 보는 용도 |
| `hyperexponential` 의 95/5 | 5ms / 105ms | 느린 쪽 비중을 올리면 평균은 같게 두고도 C²를 더 키울 수 있다 |
