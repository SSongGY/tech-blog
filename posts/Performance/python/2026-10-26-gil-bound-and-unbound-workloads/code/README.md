# GIL 확장 곡선 측정 예제

순수 계산 · 파일 입출력 · sleep 세 작업을 스레드와 프로세스로 각각 1·2·4개 돌려
벽시계 시간을 재고, 마지막으로 작업 크기를 키워 가며 프로세스 전환 비용이 언제
회수되는지를 찾는다. 표준 라이브러리만 쓴다.

## 실행

```bash
python gil_scaling.py
```

## 바꿔볼 값

- `REPEATS` — 기본 3회. 늘리면 흔들림이 줄지만 전체 시간이 비례해 늘어난다.
- `CPU_LOOPS` — 한 작업의 계산량. 코어가 느린 장비면 줄인다.
- `IO_BYTES` / `IO_ROUNDS` — 파일 입출력 작업의 크기. `os.fsync` 를 빼면
  디스크가 아니라 페이지 캐시를 재게 되어 스레드 확장이 더 좋아진다.
- `crossover()` 의 루프 수 목록 — 교차점이 이 사이에 없으면 범위를 넓힌다.

## 주의

`ProcessPoolExecutor` 를 쓰므로 `if __name__ == "__main__":` 보호가 필요하다.
윈도우와 macOS 기본값인 spawn 방식에서는 자식이 이 파일을 다시 import 하기 때문이다.
