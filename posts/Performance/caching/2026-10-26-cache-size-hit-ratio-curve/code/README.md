# 캐시 크기 대 적중률 곡선

표준 라이브러리만 쓴다. 지프 분포 접근 기록을 만들어 캐시 크기를 두 배씩
늘려 가며 LRU 적중률과 같은 크기의 상한(인기 상위 k개 고정)을 잰다.
시드가 고정돼 있어 몇 번을 돌려도 같은 숫자가 나온다.

## 실행

```bash
python hit_ratio_curve.py
```

## 바꿔 볼 값

| 상수 | 기본값 | 바꾸면 보이는 것 |
|---|---|---|
| `ALPHAS` | `(1.0, 0.7, 0.0)` | 분포가 평평해질수록 곡선이 직선에 가까워진다 |
| `KEY_COUNT` | `10_000` | 키 공간이 커지면 같은 적중률에 필요한 캐시 비율이 줄어든다 |
| `TRACE_LEN` | `200_000` | 짧으면 큰 캐시에서 LRU 가 상한에 못 미친다 (예열 구간 비중) |
| `CACHE_SIZES` | 10~3200 | 두 배씩 늘릴 때의 증가폭을 보려는 배치다 |
