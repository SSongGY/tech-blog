난수 시드 20261027 · 원소 수 32,768 · 시간은 5회 중 가장 빠른 값

====================================================================
1. 입력 모양별 비교 횟수와 시간 — 원소 32,768개
====================================================================
  입력 모양                               비교 횟수    n log2 n 대비         가장 빠른 회차
  ------------------------------------------------------------------------
  무작위                               450,413         91.6%           2.91ms
  오름차순                               32,767          6.7%           0.06ms
  내림차순                               32,767          6.7%           0.09ms
  거의 오름차순 (1% 흐트러짐)                  50,588         10.3%           0.18ms
  1024개씩 정렬된 블록 32개                 196,599         40.0%           1.09ms

  n log2 n = 491,520 (비교 횟수의 대략적인 상한)
  n - 1    = 32,767 (이미 정렬된 입력의 하한)

====================================================================
2. 덩어리 크기를 바꾸면 — 런이 길수록 병합 단계가 준다
====================================================================
  모형: 런을 찾는 데 n-1 번, 병합 단계마다 n 번 — (n-1) + n x log2(덩어리 수)

        덩어리 크기      덩어리 수        비교 횟수          모형값         차이
  --------------------------------------------------------------
            16      2,048      419,866      393,215    +26,651
            32      1,024      359,702      360,447       -745
            64        512      327,307      327,679       -372
           256        128      262,057      262,143        -86
         1,024         32      196,603      196,607         -4
         4,096          8      131,067      131,071         -4
        32,768          1       32,767       32,767         +0

  덩어리가 16 일 때만 모형보다 크게 벗어난다 — minrun 이 32 라서
  짧은 런은 이진 삽입 정렬로 32 까지 늘리고, 그 비용이 더해지기 때문이다

====================================================================
3. 안정 정렬이라 두 단계로 나눠 정렬할 수 있다
====================================================================
  원본 순서: ['A', 'B', 'C', 'D', 'E']
  이름 → 점수 내림차순 순으로 두 번 정렬:
     95  D  (나팀)
     90  A  (가팀)
     90  B  (나팀)
     90  E  (가팀)
     70  C  (가팀)
  점수가 같은 90점 묶음의 순서: ['A', 'B', 'E']  ← 앞 단계의 이름 순서가 그대로 남는다

====================================================================
4. key 함수는 몇 번 불리는가
====================================================================
  원소 32,768개를 key 로 정렬 → key 호출 32,768회
  비교 횟수 상한 n log2 n = 491,520 와 비교하면 훨씬 적다
  key 는 원소마다 한 번만 계산해 두고, 그 값끼리 비교하기 때문이다

====================================================================
5. key 대신 비교 함수를 쓰면 호출 횟수가 달라진다
====================================================================
  key=  로 정렬   → 함수 호출    32,768회 ·     4.9ms
  cmp_to_key 로 정렬 → 함수 호출   450,479회 ·    33.0ms
  호출 횟수 비 13.7배 — 비교 함수는 비교할 때마다 불린다
