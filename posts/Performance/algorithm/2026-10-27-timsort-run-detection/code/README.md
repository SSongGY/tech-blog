# Timsort 의 런 탐지 — 측정 예제

입력의 모양을 바꿔 가며 파이썬 `list.sort()` 의 비교 횟수와 시간을 잰다.
비교 횟수는 `__lt__` 호출을 직접 세므로 장비가 달라도 같은 값이 나온다.
표준 라이브러리만 쓴다.

## 실행

```bash
python timsort_runs.py
```

## 파일

| 파일 | 무엇 |
|---|---|
| `timsort_runs.py` | 입력 모양·덩어리 크기·안정성·key 호출 수를 차례로 잰다 |
| `output.txt` | `blog.py run-example` 이 남긴 실행 기록 |

## 바꿔 볼 값

- `N` — 원소 수. 2의 거듭제곱이면 병합이 고르게 갈라진다
- `step_block_size` 의 크기 목록 — 런 길이가 비교 횟수를 어디까지 줄이는지 본다
- `make_inputs` 의 `N // 100` — 흐트러뜨리는 비율. 1%를 5%로 올려 본다
