# 벤치마크가 거짓말하는 다섯 가지 방식 — 예제 코드

파이썬 표준 라이브러리만 쓴다. 따로 설치할 것이 없다.

## 실행

```bash
python main.py
```

## 파일

| 파일 | 무엇 |
|---|---|
| `main.py` | 측정 단계마다 하나씩, 다섯 가지 왜곡을 실제로 만들어 보인다 |
| `output.txt` | `blog.py run-example` 이 남긴 실행 기록. 손으로 고치지 않는다 |

**절대 시간은 기계마다 다르다.** 글에 실은 숫자도 이 환경의 값이다. 다만 각 항목의
**배수와 대소 관계**는 같은 방향으로 나와야 한다. 반대로 나오면 그 항목의 설명이
이 환경에만 맞는 것이므로 글이 틀린 것이다.

## 바꿔 볼 값

- `REPEAT` — 반복 횟수. 줄이면 거짓말 5번(대푯값)의 흔들림이 커진다.
- `lie1` 의 `300_000` — 정렬 대상 크기. 작게 잡으면 두 입력의 차이가 줄어든다.
- `lie3` 의 `1_000_000` — 분할 상환 횟수. 1,000 정도로 줄이면 타이머 비용이
  분할 상환분에도 섞이기 시작한다.
- `lie4` 의 `re.purge()` 를 빼면 첫 회와 둘째 회의 차이가 사라진다.
