# 예제 코드 — 압축 알고리즘 고르기 — gzip·bzip2·lzma 를 같은 데이터로 대조

표준 라이브러리(`gzip`·`bz2`·`lzma`·`zlib`)만 쓴다. 한 번 도는 데 1분 안팎 걸린다.

## 실행

```bash
python compare_codecs.py
```

## 바꿔볼 값

- `LOG_LINES`·`JSON_RECORDS` — 입력 크기. bzip2 는 블록 크기(수준 × 100k) 안에서 압축하므로 입력이 작으면 수준 차이가 안 보인다
- `REPEAT` — 반복 횟수. 시간 값이 흔들리면 늘린다
- `make_log()` 의 사용자 수(`5000`)·경로 목록 — 값의 종류가 늘면 압축률이 어떻게 떨어지는지 본다

크기는 입력과 라이브러리 버전이 같으면 똑같이 나온다. 시간은 기계마다 다르다.
