# 예제 코드 — cut, paste, tr

외부 의존성 없다. 스크립트가 `ps` 출력 모양의 표, CSV, TSV, CRLF 파일, 한글 한 줄 같은 작은 샘플
파일을 직접 만들고, `cut`·`paste`·`tr`의 옵션을 하나씩 돌린 뒤 전부 지운다.

## 실행

```bash
bash cut_paste_tr.sh
```

확인 환경: GNU coreutils 8.32 / bash 5.3.9 (Git Bash on Windows 11).

## 각 장이 보는 것

| 장 | 확인하는 것 |
|---|---|
| 1 | `cut -d' '`가 공백 한 칸마다 칸을 나눠, 여러 칸 공백에서 빈 필드가 나오는 것. 구분자는 한 글자만 된다 |
| 2 | `tr -s ' '`로 줄인 뒤 자르는 방법과, 줄 앞 공백이 남아 필드 번호가 하나 밀리는 것 |
| 3 | 필드 범위, 적은 순서와 무관하게 입력 순서로 나오는 것, `--complement`, `--output-delimiter` |
| 4 | 구분자가 없는 줄을 그대로 내보내는 기본 동작과 `-s` |
| 5 | 기본 구분자가 탭이라는 것 |
| 6 | 따옴표 안의 쉼표도 자르는 것 |
| 7 | 이 판의 `-c`가 `-b`와 같이 바이트를 세는 것 |
| 8 | `-z` |
| 9 | `paste`의 병렬·직렬 붙이기, 구분자 목록 순환, `-`로 표준 입력을 여러 번 읽기 |
| 10~11 | `tr`의 치환·집합 늘이기·`-t`·`-d`·`-s`·`-c`와 CRLF 제거 |
| 12 | `tr`이 파일 인자를 받지 않는 것 |
| 13 | `tr`이 한글을 바이트 단위로 바꿔 글자를 깨뜨리는 것 |

## 바꿔 볼 값

- `ps.txt`의 첫 칸 앞 공백을 지우면 2장의 `tr -s ' ' | cut -f2`가 USER 칸을 낸다.
- 3장의 `-f3,1`을 `-f1,3`으로 바꿔도 출력이 같다. 칸 순서를 바꾸려면 `awk`를 쓴다.
- 10장의 `tr abc x`에서 `x`를 `xy`로 늘리면 `c`가 무엇으로 바뀌는지 본다.
