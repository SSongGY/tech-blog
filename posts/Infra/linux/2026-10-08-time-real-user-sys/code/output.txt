==== 6-B. TIMEFORMAT — 자릿수·형식·CPU 점유율 ====
real 0.534  user 0.483  sys 0.046  cpu 99.00%
소수 0자리: 0 | 1자리: 0.3 | 3자리: 0.282 | 긴 형식: 0m0.282s | 긴 형식 3자리: 0m0.282s
%R 는 퍼센트 기호를 그대로: %R -> 0.133
(TIMEFORMAT 을 빈 문자열로 두면 줄 바꿈만 찍힌다 — 아래 빈 줄)
