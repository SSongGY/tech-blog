# 예제 코드 — time으로 재는 세 가지

`time_demo.sh`가 bash 예약어 `time`으로 네 종류의 작업(CPU 계산, 잠들기, 시스템 콜 반복,
병렬 두 프로세스)을 재고, `TIMEFORMAT`의 서식 지시자, `-p`, 파이프라인·함수·내장 명령 재기,
`times` 내장, 기다리지 않은 백그라운드 자식이 집계에서 빠지는 것을 확인한다.
작업은 파이썬 표준 라이브러리로 만들고 외부 의존성은 없다. 한 번 도는 데 30초쯤 걸린다.

필요한 것: bash 5.x, python 3.

## 실행

```bash
bash time_demo.sh
```

## 바꿔볼 값

- `CPU_LOOPS`를 두 배로 올리면 `user`가 따라 두 배가 되고 `sys`는 그대로인지 본다.
- `SYSCALL_COUNT`를 줄이면 `sys`가 줄고 `user`는 거의 그대로인지 본다.
- 4번에서 백그라운드 프로세스를 셋으로 늘리면 `%P`가 200%를 넘는지 본다.
- `TIMEFORMAT`의 `%3lR`을 `%0R`·`%lR`로 바꿔 자릿수와 분·초 표기가 어떻게 달라지는지 본다.
