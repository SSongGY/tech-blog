# 예제 코드 — split과 csplit

외부 의존성 없다. 스크립트가 임시 폴더에 2,500줄 접근 로그(`app.log`)와 날짜마다 머리줄이 붙은
14줄 로그(`days.log`)를 만들고, `split`·`csplit`의 옵션을 하나씩 돌린 뒤 폴더째 지운다.

## 실행

```bash
bash split_csplit.sh
```

확인 환경: GNU coreutils 8.32 / bash 5.3.9 (Git Bash on Windows 11). 실행 기록은 `output.txt`.

## 각 장이 보는 것

| 장 | 확인하는 것 |
|---|---|
| 0 | 입력 파일 두 개의 크기와 내용 |
| 1 | 기본값: 1000줄씩, 접두어 `x`, 접미사 `aa` |
| 2 | `-l`, 접두어 인자, `-d`, `-a`, `--additional-suffix`, `--numeric-suffixes=FROM`, `-x` |
| 3 | `-b`가 줄 가운데를 자르고 `-C`가 줄 끝에서 끊는 것 |
| 4 | `-C`보다 긴 줄은 결국 잘리는 것 |
| 5 | `-n N`, `-n l/N`, `-n r/N`, `-n l/K/N` |
| 6 | 조각 수가 줄 수보다 많을 때 빈 파일과 `-e` |
| 7 | `-a 1`로 접미사가 모자라면 26개까지 쓰고 실패하는 것 |
| 8 | `-a` 없이 쓰면 접미사가 `zaaa`로 늘어나고 glob 순서가 유지되는 것 |
| 9 | `--filter`로 조각마다 gzip |
| 10 | `-t`로 줄 대신 다른 구분자 |
| 11 | 표준 입력 `-`와 `--verbose` |
| 12 | `cat`으로 다시 합쳐 해시가 같은지 |
| 13 | `csplit`의 줄 번호·정규식·`{*}` |
| 14 | `-s`, `-f`, `-n`, `-b` |
| 15 | `%REGEXP%`로 앞부분 버리기, `--suppress-matched` |
| 16 | `+N`·`-N` 오프셋 |
| 17 | 맞는 줄로 시작하는 파일의 빈 첫 조각과 `-z` |
| 18 | 못 찾으면 만든 조각을 지우는 것과 `-k` |
| 19 | 7·8·18장의 경계값: 정확히 26조각, 정확히 650조각, 반복 `{2}` |

## 바꿔 볼 값

- 7장의 조각 크기 `-l 100`을 `-l 120`으로 키우면 3000줄이 25조각에 들어가 실패하지 않는다.
- 3장의 `64K`를 `64KB`로 바꾸면 1000 단위(64000바이트)로 자른다.
