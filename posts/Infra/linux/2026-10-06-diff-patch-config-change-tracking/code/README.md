# 예제 코드 — diff와 patch로 설정 변경을 추적하기

외부 의존성 없다. 스크립트가 `diff_work/` 폴더를 만들어 설정 파일(`app.conf.orig`과 고친 `app.conf`),
공백·CRLF·바이너리 변형, 디렉터리 두 벌을 쓰고, diff 출력 형식·무시 옵션·디렉터리 비교와
patch 적용·되돌리기·offset·fuzz·거부·백업을 하나씩 돌린 뒤 폴더째 지운다.
`diff -u` 머리줄의 수정 시각은 `touch -d`로 고정해 돌릴 때마다 같은 출력이 나온다.

## 실행

```bash
bash diff_patch_options.sh
```

확인 환경: GNU diffutils 3.12 / GNU patch 2.7.6 / bash 5.3.9 (Git Bash on Windows 11).

## 각 장이 보는 것

| 장 | 확인하는 것 |
|---|---|
| 2~5 | 출력 형식: 기본·`-u`·`-U`·`-c`·`-y` |
| 6 | `-q`·`-s`와 종료 코드 0·1·2 |
| 7 | `--label`로 머리줄 이름 바꾸기 |
| 8~9 | 공백·대소문자·빈 줄·정규식 줄 무시, CRLF |
| 10 | `-F`로 바뀐 곳이 속한 절 이름 찍기 |
| 11 | 디렉터리 비교 `-r`·`-N`·`-x`·`--from-file` |
| 12~15 | `-e`·`-n`, 줄 서식, `-D`, 바이너리, 탭, `-d` |
| 16~17 | patch 미리보기·적용·되돌리기, 이미 적용된 패치 |
| 18 | offset·fuzz·`-F0`·`.rej`·`--merge` |
| 19~21 | `-o`, 백업, 디렉터리 패치 `-p`·`-d`·`-E`, `-l` |

## 바꿔 볼 값

- 3장은 `-U0`에서만 덩어리가 셋으로 갈리고 `-U1`부터는 하나다. `app.conf`에서 바뀐 줄 사이를 더 벌리면(예: `cache.*` 줄을 몇 줄 더 넣으면) `-U1`에서도 갈린다.
- 18장 `fuzzy.conf`에서 첫 줄 대신 마지막 줄(`log.dir`)을 바꿔 본다. 매뉴얼대로라면 뒤 문맥 한 줄을 빼고 fuzz 1로 붙어야 한다.
- 20장의 `-p1`을 `-p0`으로 바꾸면 `conf_new/app.conf`라는 경로를 `live` 아래에서 찾다가 실패한다.
