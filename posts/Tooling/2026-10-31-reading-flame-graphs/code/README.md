# 예제 코드 — 플레임 그래프를 제대로 읽는 법

호출 구조를 알고 있는 프로그램을 표본 수집기 아래에서 돌려, 접힌 스택과
플레임 그래프를 직접 만든다. 외부 프로파일러 없이 표준 라이브러리만 쓴다.

## 실행

```bash
python run_profile.py
```

## 파일

| 파일 | 무엇 |
|---|---|
| `workload.py` | 프로파일 대상. 깊은 쪽이 싸고 얕은 쪽이 비싸게 일부러 어긋나게 짰다 |
| `flamekit.py` | 표본 수집기, 접힌 스택 변환, 플레임 그래프 SVG 생성기 |
| `run_profile.py` | 셋을 이어 돌리고 숫자 표와 `../fig/sample-flame.svg` 를 낸다 |
| `output.txt` | 돌린 기록. `blog.py run-example` 이 만든다 |

## 바꿔 볼 값

- `flamekit.INTERVAL`(`run_profile.py` 에 있다)을 키우면 표본이 줄고 **폭이
  흔들린다.** 플레임 그래프를 믿을 수 있는 표본 수가 어느 정도인지 바로 보인다
- `workload.VALIDATE_DEPTH` 를 키우면 탑이 높아진다. 높이만 커지고 폭은 그대로라는
  점을 확인한다
- `workload.CHECKSUM_ROUNDS` 를 줄이면 가장 넓던 평지가 좁아진다.
  어느 칸이 줄었는지 보면 폭이 무엇을 뜻하는지가 분명해진다
- `flamekit.PALETTE` 를 전부 같은 색으로 바꿔도 읽는 데 지장이 없다.
  원래 플레임 그래프의 색도 인접한 칸을 구분하기 위한 것이지 뜻이 있는 값이 아니다
