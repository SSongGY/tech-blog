# 변분 양자 알고리즘 계산

본문 "계산으로 확인한 것"의 근거다. 외부 의존성 없는 상태벡터 시뮬레이션이며 난수 시드를 고정했다.
양자 장치가 아니라 고전 컴퓨터에서 기댓값을 정확히 계산하므로 측정 잡음·하드웨어 잡음은 없다.

- `[1]` 매개변수 이동 규칙이 해석적 미분과 같은 값을 주는지
- `[2]` 비용 함수·안사츠·기울기·최적화기 네 요소로 하이브리드 루프를 돌려 비용이 줄어드는지, 회로를 몇 번 돌렸는지
- `[3]` 무작위 초기화에서 기울기 분산이 큐비트 수에 따라 어떻게 줄어드는지 — 전역 비용과 국소 비용, 얕은 회로와 깊은 회로

## 실행

```bash
python vqa_sim.py
```
