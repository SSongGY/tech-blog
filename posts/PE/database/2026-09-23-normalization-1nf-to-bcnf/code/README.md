# 예제 코드 — 정규화 1NF부터 BCNF까지

함수 종속 집합에서 속성 폐포와 후보키를 계산해 2NF·3NF·BCNF 위반을 찾고,
같은 릴레이션을 SQLite에 만들어 갱신·삭제 이상이 실제로 일어나는지 행 수로 확인한다.
외부 의존성 없이 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python normal_forms.py
```

## 속성 기호

`S` 학번 · `C` 과목코드 · `N` 학생이름 · `D` 학과 · `O` 학과사무실 · `P` 담당교수 · `G` 성적

## 바꿔볼 값

- `ENROLL_FDS`에서 `D -> O`를 지우면 3NF 위반이 사라진다. 이행 함수 종속이
  어느 FD에서 오는지 보는 자리다.
- `TEACH_FDS`의 `P -> C`를 지우면 후보키가 `SC` 하나가 되고 BCNF 위반도 사라진다.
- `check_lossless`에 다른 분해를 넣어 본다. 예를 들어 `SN` / `DO`로 나누면
  공통 속성이 없어 손실 분해로 판정된다.
