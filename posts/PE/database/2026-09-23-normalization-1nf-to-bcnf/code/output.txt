--- 정규화 전 수강 (CDGNOPS) ---
  FD  C -> P
  FD  D -> O
  FD  S -> N
  FD  S -> D
  FD  CS -> G
  후보키   ['CS']
  기본속성 CS · 비기본속성 DGNOP
  2NF 위반(부분 함수 종속)      ['C -> P', 'S -> N', 'S -> D']
  3NF 위반(이행 함수 종속)      ['D -> O']
  BCNF 위반(결정자가 비 슈퍼키) ['C -> P', 'D -> O', 'S -> N', 'S -> D']

=== 2NF 분해 — 부분 함수 종속 제거 ===
  DNOS / CGPS  공통 S -> 폐포 DNOS  [무손실]
  CP / CGS  공통 C -> 폐포 CP  [무손실]
  종속성 보존: 모두 보존

--- 학생 (DNOS) ---
  후보키   ['S']
  기본속성 S · 비기본속성 DNO
  2NF 위반(부분 함수 종속)      없음
  3NF 위반(이행 함수 종속)      ['D -> O']
  BCNF 위반(결정자가 비 슈퍼키) ['D -> O']

--- 강의 (CPS) ---
  FD  P -> C
  FD  CS -> P
  후보키   ['CS', 'PS']
  기본속성 CPS · 비기본속성 (없음)
  2NF 위반(부분 함수 종속)      없음
  3NF 위반(이행 함수 종속)      없음
  BCNF 위반(결정자가 비 슈퍼키) ['P -> C']

=== BCNF 분해 ===
  CP / PS  공통 P -> 폐포 CP  [무손실]
  종속성 보존: 깨진 FD ['CS -> P']
