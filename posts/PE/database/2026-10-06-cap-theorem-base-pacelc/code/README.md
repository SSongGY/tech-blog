# 예제 코드 — CAP 정리와 정족수

외부 의존성 없이 파이썬 표준 라이브러리만 쓴다. 출력은 세 부분이다.

1. 복제본 3개에서 쓰기·읽기 정족수(W, R)의 모든 조합을 전수 조사해, 읽기 집합이 쓰기 집합과 겹치지 않는 조합이 몇 개인지 센다
2. 서버 둘 사이가 끊긴 상태에서 한쪽에 쓰고 다른 쪽에서 읽을 때, CP 정책과 AP 정책의 응답을 비교한다
3. 메시지가 늦게 오는 실행과 사라진 실행을, 시간 제한까지 p2가 본 기록으로 나란히 놓는다

## 실행

```bash
python cap_simulation.py
```

## 바꿔볼 값

- `REPLICA_COUNT`를 5로 바꾸면 W+R>N 경계가 어디로 옮겨 가는지 본다.
- 3부의 `delay`를 2로 줄이면 메시지가 시간 제한 안에 도착해 두 기록이 갈린다.
