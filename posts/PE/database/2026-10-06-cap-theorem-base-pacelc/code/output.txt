==== 2부. 분할 중 쓰기와 읽기 ====

[CP] 분할 중 p1 에 v1 쓰기 → 응답 없음 (오류 반환)  (p1=v0, p2=v0)
[CP] 분할 중 p2 읽기 → 응답 없음 (오류 반환)
[CP] 완료된 쓰기 뒤에 옛 값을 읽었는가 → False
[CP] 분할 해소 후 p2 읽기 → v0

[AP] 분할 중 p1 에 v1 쓰기 → ok  (p1=v1, p2=v0)
[AP] 분할 중 p2 읽기 → v0
[AP] 완료된 쓰기 뒤에 옛 값을 읽었는가 → True
[AP] 분할 해소 후 p2 읽기 → v1

==== 3부. 늦은 메시지와 잃어버린 메시지 ====

  메시지가 사라진 실행       : t0:- t1:- t2:- t3:-
  두 기록이 같은가           : True
