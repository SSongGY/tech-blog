# 예제 코드 — 트랜잭션 ACID와 2단계 커밋(2PC)

참여자 셋(출금 은행·입금 은행·포인트)이 각자 SQLite 파일 DB를 갖고, 조정자가 2PC를 돌린다.
조정자가 멈추는 지점을 다섯 가지로 바꿔 가며 참여자가 협력 종료 프로토콜로 결정을 얻는지,
막힌 동안 그 DB에 다른 세션이 붙으면 무엇을 겪는지 찍는다. 메시지 전달은 함수 호출로 대신한다.
DB 파일은 임시 폴더에 만들고 끝나면 지운다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python two_phase_commit.py
```

## 바꿔볼 값

- `run_coordinator` 의 `stop_at` 비교에서 `i == 1` 을 `i == 0` 으로 바꾸면 S3 이 아무에게도 COMMIT 을 보내지 못한 경우가 되어 S5 와 같아진다.
- `Participant.on_vote_req` 가 P3 에서 `NO` 를 돌려주게 하면 S4·S5 의 막힘이 사라진다. P3 이 결정(철회)을 알고 있기 때문이다.
- `probe_locks` 의 `timeout=0` 을 `timeout=3` 으로 바꾸면 쓰기가 3초 기다린 뒤 같은 에러로 끝난다.
