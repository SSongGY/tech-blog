== S1 장애 없음 ==
  조정자 멈춤 지점: 없음 / 조정자 DT 로그: ['start-2PC', 'commit']
  [멈춘 직후]
    P1 출금 은행   DT 로그=['yes', 'commit'] 상태=결정: 커밋   커밋된 balance=400000
    P2 입금 은행   DT 로그=['yes', 'commit'] 상태=결정: 커밋   커밋된 balance=600000
    P3 포인트     DT 로그=['yes', 'commit'] 상태=결정: 커밋   커밋된 balance=500100
  [끝]
    P1 출금 은행   DT 로그=['yes', 'commit'] 상태=결정: 커밋   커밋된 balance=400000
    P2 입금 은행   DT 로그=['yes', 'commit'] 상태=결정: 커밋   커밋된 balance=600000
    P3 포인트     DT 로그=['yes', 'commit'] 상태=결정: 커밋   커밋된 balance=500100

== S2 조정자가 VOTE-REQ 를 P3 에 보내기 전에 멈춤 ==
  조정자 멈춤 지점: VOTE-REQ 일부만 보낸 뒤 / 조정자 DT 로그: ['start-2PC']
  [멈춘 직후]
    P1 출금 은행   DT 로그=['yes']           상태=불확실      커밋된 balance=500000
    P2 입금 은행   DT 로그=['yes']           상태=불확실      커밋된 balance=500000
    P3 포인트     DT 로그=[]                상태=투표 전     커밋된 balance=500000
  [협력 종료 프로토콜]
    P1 출금 은행 이 물음 -> P2 입금 은행=응답 없음(불확실), P3 포인트=ABORT
    P2 입금 은행 이 물음 -> P1 출금 은행=ABORT, P3 포인트=ABORT
  [끝]
    P1 출금 은행   DT 로그=['yes', 'abort']  상태=결정: 철회   커밋된 balance=500000
    P2 입금 은행   DT 로그=['yes', 'abort']  상태=결정: 철회   커밋된 balance=500000
    P3 포인트     DT 로그=['abort']         상태=결정: 철회   커밋된 balance=500000

== S3 조정자가 P1 에게만 COMMIT 을 보내고 멈춤 ==
  조정자 멈춤 지점: P1 에게만 COMMIT 을 보낸 뒤 / 조정자 DT 로그: ['start-2PC', 'commit']
  [멈춘 직후]
    P1 출금 은행   DT 로그=['yes', 'commit'] 상태=결정: 커밋   커밋된 balance=400000
    P2 입금 은행   DT 로그=['yes']           상태=불확실      커밋된 balance=500000
    P3 포인트     DT 로그=['yes']           상태=불확실      커밋된 balance=500000
  [협력 종료 프로토콜]
    P2 입금 은행 이 물음 -> P1 출금 은행=COMMIT, P3 포인트=응답 없음(불확실)
    P3 포인트 이 물음 -> P1 출금 은행=COMMIT, P2 입금 은행=COMMIT
  [끝]
    P1 출금 은행   DT 로그=['yes', 'commit'] 상태=결정: 커밋   커밋된 balance=400000
    P2 입금 은행   DT 로그=['yes', 'commit'] 상태=결정: 커밋   커밋된 balance=600000
    P3 포인트     DT 로그=['yes', 'commit'] 상태=결정: 커밋   커밋된 balance=500100

== S4 조정자가 YES 를 다 받고 결정을 기록하기 전에 멈춤 ==
  조정자 멈춤 지점: YES 를 다 받고 결정 기록 전 / 조정자 DT 로그: ['start-2PC']
  [멈춘 직후]
    P1 출금 은행   DT 로그=['yes']           상태=불확실      커밋된 balance=500000
    P2 입금 은행   DT 로그=['yes']           상태=불확실      커밋된 balance=500000
    P3 포인트     DT 로그=['yes']           상태=불확실      커밋된 balance=500000
  [협력 종료 프로토콜]
    P1 출금 은행 이 물음 -> P2 입금 은행=응답 없음(불확실), P3 포인트=응답 없음(불확실)
    P1 출금 은행: 막힘 — 조정자가 돌아올 때까지 기다린다
    P2 입금 은행 이 물음 -> P1 출금 은행=응답 없음(불확실), P3 포인트=응답 없음(불확실)
    P2 입금 은행: 막힘 — 조정자가 돌아올 때까지 기다린다
    P3 포인트 이 물음 -> P1 출금 은행=응답 없음(불확실), P2 입금 은행=응답 없음(불확실)
    P3 포인트: 막힘 — 조정자가 돌아올 때까지 기다린다
  [막힌 동안 P1 출금 은행 의 DB]
    다른 세션 읽기  : balance=500000 (준비 전 값)
    다른 세션 쓰기  : 실패 -> database is locked
  [조정자 복구]
    조정자 복구: DT 로그 ['start-2PC'] -> ABORT
  [끝]
    P1 출금 은행   DT 로그=['yes', 'abort']  상태=결정: 철회   커밋된 balance=500000
    P2 입금 은행   DT 로그=['yes', 'abort']  상태=결정: 철회   커밋된 balance=500000
    P3 포인트     DT 로그=['yes', 'abort']  상태=결정: 철회   커밋된 balance=500000

  조정자 멈춤 지점: commit 기록 직후, 전송 전 / 조정자 DT 로그: ['start-2PC', 'commit']

    P1 출금 은행 이 물음 -> P2 입금 은행=응답 없음(불확실), P3 포인트=응답 없음(불확실)
    P1 출금 은행: 막힘 — 조정자가 돌아올 때까지 기다린다
    P2 입금 은행 이 물음 -> P1 출금 은행=응답 없음(불확실), P3 포인트=응답 없음(불확실)

    P3 포인트 이 물음 -> P1 출금 은행=응답 없음(불확실), P2 입금 은행=응답 없음(불확실)
    P3 포인트: 막힘 — 조정자가 돌아올 때까지 기다린다
  [막힌 동안 P1 출금 은행 의 DB]
    다른 세션 읽기  : balance=500000 (준비 전 값)
