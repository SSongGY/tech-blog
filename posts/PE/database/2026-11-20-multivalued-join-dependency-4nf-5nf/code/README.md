# 예제 코드 — 다치 종속과 조인 종속

파이썬 표준 라이브러리만 쓴다. Python 3.13.5 에서 돌렸다. 난수 시드는 고정이다.

## 실행

```bash
python dependencies.py
```

## 바꿔 볼 값

- `RANDOM_TRIALS` — 무작위 릴레이션 수. 늘려도 [2] 의 불일치와 [3] 의 결론 깨짐은 0 이어야 한다
- `section_5nf()` 의 `rows` — 튜플을 하나 더하거나 빼서 3-분해 조인 종속이 언제 깨지는지 본다
- `section_4nf()` 의 `tied` — 강사와 교재를 묶는 방식을 바꾸면 가짜 행 수가 달라진다
