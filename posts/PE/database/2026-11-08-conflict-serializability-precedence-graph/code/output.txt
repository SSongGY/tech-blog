== S1 교차 실행 ==
  스케줄        : r1(A) w1(A) r2(A) w2(A) r1(B) w1(B) r2(B) w2(B)
  간선 T1->T2   : r1(A)<w2(A), w1(A)<r2(A), w1(A)<w2(A), r1(B)<w2(B), w1(B)<r2(B), w1(B)<w2(B)
  선행 그래프   : 사이클 없음, 직렬 순서 T1->T2
  전수(충돌)    : ['T1->T2']
  전수(뷰)      : ['T1->T2']
  2PL 생성 가능 : 예, 락 포인트 T1@-0.5, T2@5.5

== S2 갱신 분실 ==
  스케줄        : r1(A) r2(A) w1(A) w2(A)
  간선 T1->T2   : r1(A)<w2(A), w1(A)<w2(A)
  간선 T2->T1   : r2(A)<w1(A)
  선행 그래프   : 사이클 있음
  전수(충돌)    : 없음
  전수(뷰)      : 없음
  2PL 생성 가능 : 아니오

== S3 맹목 쓰기 ==
  스케줄        : r1(Q) w2(Q) w1(Q) w3(Q)
  간선 T1->T2   : r1(Q)<w2(Q)
  간선 T1->T3   : r1(Q)<w3(Q), w1(Q)<w3(Q)
  간선 T2->T1   : w2(Q)<w1(Q)
  간선 T2->T3   : w2(Q)<w3(Q)
  선행 그래프   : 사이클 있음
  전수(충돌)    : 없음
  전수(뷰)      : ['T1->T2->T3']
  2PL 생성 가능 : 아니오

== S4 2PL 불가 ==
  스케줄        : r1(X) w2(X) w3(Y) r1(Y)
  간선 T1->T2   : r1(X)<w2(X)
  간선 T3->T1   : w3(Y)<r1(Y)
  선행 그래프   : 사이클 없음, 직렬 순서 T3->T1->T2
  전수(충돌)    : ['T3->T1->T2']
  전수(뷰)      : ['T3->T1->T2']
  2PL 생성 가능 : 아니오
