-- S 가 작다: S 의 서로 다른 조인 값 200개
  R 의 행 중 S 와 짝이 있는 행: 46 / 10000
  방식                               전송(B)
  A 전체 전송                        1000000
  B 반결합                             5400  (π(S) 800 + R⋉S 4600)
  C 비트 배열                          25924  (비트 1024 + R' 249행, 거짓 양성 203행)
  반결합이 이득인가: True
