# 예제 코드 — BST·AVL·레드-블랙 트리 높이와 회전 비교

파이썬 3.10 이상 표준 라이브러리만 쓴다. 설치할 것이 없다.

## 실행

```bash
python balanced_bst.py
```

## 바꿔볼 값

- 3절의 `(1_000, 100_000)` 에 `1_000_000` 을 더하면 높이 상한과의 거리가 더 벌어진다 (수십 초 걸린다)
- 2절의 `range(1, 8)` 을 `range(7, 0, -1)` 로 바꾸면 왼쪽 경우(LL, Case 1~3 의 대칭)가 나온다
- 난수 씨앗 `20261110` 을 바꿔 무작위 입력 결과가 얼마나 흔들리는지 본다
