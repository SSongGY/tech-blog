# 예제 코드 — 캐시 사상 방식

파이썬 표준 라이브러리만 쓴다. 캐시는 세트마다 LRU 로 교체하는 모형이며, 실제 CPU 의 교체 정책·프리페치는 넣지 않았다.

## 실행

```bash
python cache_mapping.py
```

## 바꿔볼 값

- `TRACE` 에 다른 블록 번호 접근열을 넣고 직접·2-way·완전 연관의 실패 횟수를 비교한다
- `section_stride()` 의 간격 4096 을 2048·8192 로 바꿔 몇 개부터 8-way 가 무너지는지 본다
- `split_bits()` 에 시험 문제의 캐시 크기·라인 크기·연관도를 넣어 태그·인덱스·오프셋 비트를 구한다
