# 예제 코드 — 5단계 파이프라인 해저드 사이클 계산기

파이썬 3.10 이상 표준 라이브러리만 쓴다. 설치할 것이 없다.

## 실행

```bash
python pipeline_sim.py
```

## 바꿔볼 값

- `Config(... unified_memory=True)` 를 4절 분기 예제에도 걸어 구조 해저드와 제어 해저드가 겹칠 때를 본다
- 6절 반복 횟수 `100` 을 `10` 으로 줄여 시작·끝 비용(k−1)이 CPI 에 얼마나 섞이는지 본다
- `schedule()` 에서 분기 예측을 '감'으로 바꾸려면 `taken` 조건을 뒤집는다
