# 예제 코드 — 시스톨릭 어레이

표준 라이브러리만 쓴다. 가중치 고정 시스톨릭 어레이를 사이클 단위로 모사해
결과를 직접 계산한 행렬 곱과 대조하고, 사이클 수·PE 활용률·메모리 읽기 횟수를 센다.

## 실행

```bash
python systolic_array.py
```

## 파일

| 파일 | 무엇 |
|---|---|
| `systolic_array.py` | 본문에 실은 숫자를 그대로 내는 모사기 |
| `output.txt` | `blog.py run-example` 이 남긴 수행 기록 |

## 바꿔볼 값

- `main()` 의 `a`, `b` — 입력 행렬. 행 수 M 을 늘리면 PE 활용률이 1에 가까워진다
- 6절의 `k_big`, `n_big` — 배열 크기. 키우면 채우는 데 드는 사이클이 길어져
  M 이 작을 때의 활용률이 더 떨어진다
