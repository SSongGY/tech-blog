# 예제 코드 — CPU 스케줄링 평균 대기시간 계산

파이썬 표준 라이브러리만 쓴다. 시간은 정수 단위로 한 칸씩 흉내 내므로 결과가 매번 같다.

## 실행

```bash
python scheduling.py
```

## 바꿔볼 값

- `round_robin()`의 동률 규칙: 할당량이 끝난 프로세스를 같은 시각 도착한 프로세스보다 **앞에** 세우면
  도착 시각이 겹치는 작업 묶음에서 간트 차트가 달라진다.
- 3절의 우선순위 `(3, 1, 4, 2)`를 바꾸면 Priority 행만 달라진다.
- 5절의 `alpha`를 `0`이나 `1`로 바꾸면 예측이 처음 값에 고정되거나 직전 실행 시간만 따라간다.
