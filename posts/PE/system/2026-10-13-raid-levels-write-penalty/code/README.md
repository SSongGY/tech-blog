# 계산 코드 — RAID 레벨별 쓰기 비용

디스크를 바이트열 목록으로 흉내 내고, 블록 하나를 고쳐 쓸 때 읽기·쓰기가 몇 번 일어나는지
레벨별로 센다. RAID 5·6은 패리티를 실제로 계산해 고쳐 쓴 뒤에도 패리티가 맞는지 확인하고,
디스크 1개(RAID 5)·2개(RAID 6) 고장에서 잃은 블록을 복구해 원래 값과 비교한다.
RAID 6의 Q 패리티와 두 디스크 복구 식은 H. Peter Anvin, "The mathematics of RAID-6"(2011-12-20판)을 따른다.
외부 의존성 없이 파이썬 표준 라이브러리만 쓴다. 난수 시드는 42로 고정했다.

## 실행

```bash
python raid_write_penalty.py
```

## 바꿔볼 값

- `main()`의 `n_data`를 8로 바꾸면 1번의 RAID 5 가산 방식 읽기 횟수가 몇이 되는지 본다.
- 6번의 `(x, y)` 목록에 `(2, 2)`를 넣으면 왜 식 (16)의 분모가 0이 되는지 본다.
- 8번의 `disks`를 12로 바꿔 효율과 처리량 비율이 어떻게 달라지는지 본다.
