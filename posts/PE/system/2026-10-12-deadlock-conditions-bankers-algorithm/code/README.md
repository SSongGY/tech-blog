# 예제 코드 — 은행원 알고리즘과 교착 탐지 검산

Silberschatz *Operating System Concepts* 10th ed. 8장 슬라이드의 예제 두 개를 그대로 넣고
안전 알고리즘·자원 요청 알고리즘·탐지 알고리즘을 돌린다. 외부 의존성 없이 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python bankers_algorithm.py
```

## 바꿔볼 값

- `AVAILABLE`를 `(2, 3, 2)`로 줄이면 5번의 안전 순서가 몇 개로 줄어드는지 본다.
- 6번의 마지막 요청 `(1, 2, 1)`을 `(0, 2, 0)`으로 바꿔 P1의 요청이 승인되는지 본다.
- 7번의 `modest[3]`을 `(0, 2, 0)`으로 키우면 교착이 생기는지 본다.
