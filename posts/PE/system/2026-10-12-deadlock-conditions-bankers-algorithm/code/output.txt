== 6. 자원 요청 알고리즘 — 슬라이드 8.35

-- P1 가 (1 0 2) 를 요청
   1단계: Request <= Need(1 2 2) 통과
   2단계: Request <= Available(3 3 2) 통과
   3단계: 가상 할당 -> Available = 2 3 0
   안전 -> 할당. 안전 순서 <P1, P3, P0, P2, P4>

-- P4 가 (3 3 0) 를 요청
   1단계: Request <= Need(4 3 1) 통과
   2단계: Request > Available(2 3 0) -> 대기

-- P0 가 (0 2 0) 를 요청
   1단계: Request <= Need(7 4 3) 통과
   2단계: Request <= Available(2 3 0) 통과
   3단계: 가상 할당 -> Available = 2 1 0
   불안전 -> 대기, 이전 상태로 복원 (끝까지 갈 수 있는 프로세스: 없음)

-- P1 가 (1 2 1) 를 요청
   1단계: Request > Need(0 2 0) -> 오류 (최대 요구 초과)
