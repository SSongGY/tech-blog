# 예제 코드 — 연속 메모리 할당의 배치 기법

파이썬 표준 라이브러리만 쓴다. 난수는 시드를 고정했다.

## 실행

```bash
python placement.py
```

## 바꿔 볼 값

- `part2_3_4()` 의 `requests_kb` 순서를 바꿔 본다 — 같은 요청이라도 순서에 따라 최초 적합이 성공하기도 한다
- `part5()` 의 요청 크기 범위를 `1~100` 으로 줄이면 메모리에 비해 블록이 작아져 빈 블록 비율이 어떻게 바뀌는지 본다
- `part5()` 의 해제 확률 `0.5` 를 낮추면 메모리가 더 꽉 찬 상태에서 기법을 비교할 수 있다
