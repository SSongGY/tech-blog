# 예제 코드 — 페이지 교체 알고리즘과 벨레이디의 이상현상

OPT·FIFO·LRU·Clock(두 번째 기회) 네 알고리즘을 참조열 단위로 흉내 내어 페이지 부재 횟수를 센다.
교재 예제 두 개(Silberschatz 10판 10장 슬라이드, OSTEP 22장)의 값을 다시 계산하고,
벨레이디 참조열로 FIFO 의 이상현상과 "프레임 내용 포함 관계" 가 깨지는 지점을 찾는다.
파이썬 표준 라이브러리만 쓴다. 무작위 실험은 seed 42 로 고정했다.

## 실행

```bash
python page_replacement.py
```

## 바꿔볼 값

- `BELADY_REFS` 의 마지막 5를 1로 바꾸면 FIFO 3개·4개의 부재 횟수가 어떻게 되는지 본다.
- `simulate_opt` 의 동률 규칙(`max` 가 먼저 들어온 쪽을 고름)을 바꿔도 부재 횟수가 같은지 본다.
- 6번의 참조열 길이를 12 에서 20 으로 늘리면 FIFO 이상현상 비율이 오르는지 내리는지 본다.
