# 예제 코드 — 논리 시계 — 램포트 시계와 벡터 시계로 사건 순서 정하기

표준 라이브러리만 쓴다. 난수가 없어 매번 같은 결과가 나온다.

## 실행

```bash
python logical_clocks.py
```

## 바꿔 볼 값

- `SCENARIO` 에 프로세스나 메시지를 더하면 시계 값과 동시 쌍 수가 어떻게 바뀌는지 본다
- 수신 규칙의 `max(lamport[p], t_lamport) + 1` 에서 `+ 1` 을 빼면 Clock Condition 이 깨지는지 확인한다
- 벡터 수신 규칙에서 성분별 최댓값을 빼면 정리 10 검산의 "정답과 다른 쌍"이 몇 개가 되는지 본다
