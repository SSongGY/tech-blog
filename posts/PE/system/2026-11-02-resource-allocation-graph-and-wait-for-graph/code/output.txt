==============================================================
1. 단일 인스턴스 — 자원 할당 그래프를 대기 그래프로 줄인다
==============================================================
  자원 할당 그래프
    할당 간선  R1 -> P2
    할당 간선  R2 -> P3
    할당 간선  R3 -> P1
    요청 간선  P1 -> R1
    요청 간선  P2 -> R2
    요청 간선  P3 -> R3

  대기 그래프 (자원 노드를 들어낸 결과)
    P1 -> P2
    P2 -> P3
    P3 -> P1

  사이클: P1 -> P2 -> P3 -> P1
  판정: 교착  (단일 인스턴스에서는 사이클이 곧 교착이다)

  P3 가 R3 요청을 거둔 경우
    P1 -> P2
    P2 -> P3
  사이클: 없음
  판정: 교착 아님

==============================================================

    P1   0   0   3
    P2   0   0   3
    P3   0   0   2

  환원 순서: (없음)
  교착 프로세스: ['P1', 'P2']
  P3 는 아무것도 못 받고 영원히 기다리지만 Allocation 이 0 이라
  1단계에서 Finish=true 로 들어가므로 교착 목록에 오르지 않는다.
