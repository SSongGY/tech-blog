# 자원 할당 그래프와 대기 그래프 — 검산 코드

교재가 결론만 적어 둔 네 가지를 직접 돌려 확인한다.

1. 단일 인스턴스 자원 할당 그래프를 대기 그래프로 줄이고 사이클을 찾는다
2. 다중 인스턴스 탐지 알고리즘으로 T0 스냅샷이 교착이 아님을 보인다
3. 요청 하나가 늘어난 뒤 교착이 되는 것을 보인다
4. 초기화 단계에서 `Allocation_i == 0` 인 프로세스를 Finish=true 로 두는 한 줄이
   무엇을 가리는지 보인다

의존성은 없다. 표준 라이브러리만 쓴다.

python detect.py
