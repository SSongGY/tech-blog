# 예제 코드 — MLOps 파이프라인과 모델 드리프트 대응

드리프트의 발생원 세 가지를 같은 모델에 각각 먹여, **입력 분포 감시(PSI)** 와
**정확도 감시**가 어느 쪽을 잡고 어느 쪽을 놓치는지 숫자로 본다.

## 실행

```bash
python drift_sources.py
```

의존성 없음. 난수는 시드를 고정했으므로 몇 번을 돌려도 같은 값이 나온다.

## 바꿔 볼 값

| 값 | 보이는 것 |
|---|---|
| `sample(rng, 1.2, 0.0)` 의 `1.2` | 입력 이동 폭에 따라 PSI 가 어떻게 커지는지 |
| `CONCEPT_T1` | 경계를 조금만 틀면 정확도가 어디까지 버티는지 |
| `BIN_COUNT` | 구간을 잘게 나눌수록 PSI 가 커지는 성질 |
