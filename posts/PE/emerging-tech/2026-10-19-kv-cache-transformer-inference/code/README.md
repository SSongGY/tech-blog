# KV 캐시 크기 계산

KV 캐시가 차지하는 바이트 수를 구성 요소별로 계산한다. 모델 가중치나 GPU가
필요 없고, 구조 상수(레이어 수·헤드 수·헤드 차원)와 문맥 길이·배치·정밀도만으로
값이 정해지므로 어느 환경에서든 같은 숫자가 나온다.

- `kv_cache_size.py` — 문맥 길이별·배치별·정밀도별 캐시 크기와,
  GQA·MQA의 축소 비율이 헤드 수 비와 같은지 검산한다.

표에 쓰인 레이어 수 80, 질의 헤드 64, 헤드 차원 128은 **가정한 구성**이다.
특정 제품의 공개 값이 아니라 70B 급 디코더의 형태를 본뜬 숫자다.

## 실행

```bash
python kv_cache_size.py
```

의존성 없음. 표준 라이브러리만 쓴다.
