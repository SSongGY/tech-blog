# 검산 코드 — 블록체인 합의 알고리즘 — PoW, PoS, PBFT

두 가지 계산을 파이썬 표준 라이브러리로 다시 한다.

| 장 | 무엇을 보는가 |
|---|---|
| 1 | 비트코인 백서 11절 공식으로 공격자 따라잡기 확률 P(q=0.1, z=0..10)를 계산해 백서 표와 대조 |
| 2 | P < 0.1% 가 되는 최소 확인 블록 수 z 를 q 별로 계산해 백서 표와 대조 |
| 3 | 확인 블록 6개일 때 공격자 해시 비율별 P |
| 4 | PBFT 의 n = 3f + 1, prepared·committed-local·클라이언트 응답 정족수, n = 3f 로는 조건이 깨지는 것 |
| 5 | PBFT 정상 경로 3단계에서 요청 하나당 복제본 간 메시지 수가 n 에 따라 늘어나는 모양 |

## 실행

```bash
python consensus_math.py
```

## 바꿔볼 값

- 3장의 `6`을 다른 확인 블록 수로 바꿔 본다.
- 2장의 기준 `0.001`을 `0.0001`로 바꾸면 필요한 z 가 얼마나 늘어나는지 본다.
