# 예제 코드 — 머신러닝 모델 평가 지표

거래 20건(사기 5건, 정상 15건)에 고정된 점수를 매겨 두고, 임계값 0.3·0.5·0.7·0.9에서
혼동행렬과 정확도·정밀도·재현율·특이도·F1·F2·F0.5·균형 정확도·MCC를 계산한다.
전부 '정상'이라고 답하는 모델의 지표와, 양성·음성 쌍을 세어 구한 ROC AUC도 찍는다.
난수를 쓰지 않으므로 몇 번을 돌려도 같은 값이 나온다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python confusion_metrics.py
```

## 바꿔볼 값

- `TRANSACTIONS`의 T02 점수 `0.91`을 `0.80`으로 낮추고 임계값 0.9의 정밀도가 어떻게 바뀌는지 본다.
- 정상 거래를 15건에서 150건(점수 0.02 근처)으로 늘리고 정확도와 MCC가 각각 얼마나 움직이는지 비교한다.
- `THRESHOLDS`에 `0.45`, `0.62`처럼 양성 점수와 같은 값을 넣어 `>=` 비교가 경계에서 어떻게 갈리는지 본다.
