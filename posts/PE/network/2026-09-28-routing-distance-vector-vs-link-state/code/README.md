# 예제 코드 — 거리벡터와 링크상태의 수렴

링크 하나가 끊겼을 때 거리벡터(분산 Bellman-Ford)와 링크상태(LSA 전파 + Dijkstra)가
몇 라운드 만에 바로잡히는지 센다. 외부 의존성 없이 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python routing_convergence.py
```

## 모델

- **동기 라운드**: 한 라운드에 모든 라우터가 이웃에게 한 번씩 알리고, 받은 것으로 다시 계산한다.
  RIP의 30초 주기·180초 만료·triggered update는 넣지 않았다. 실제 시간이 아니라 **라운드 수**를 비교한다.
- **거리벡터**: 이웃이 알린 거리 + 링크 비용의 최솟값. 16을 무한으로 친다(RFC 2453).
  `none` / `split-horizon` / `poisoned-reverse` 세 방식을 비교한다.
- **링크상태**: 끊긴 링크 양 끝이 새 LSA를 만들고, LSA는 한 라운드에 한 홉씩 퍼진다.
  LSA를 받은 라우터만 새 토폴로지로 Dijkstra를 다시 돌린다.

## 바꿔볼 값

- `INFINITY`를 32로 올리면 1-none과 2-split-horizon의 라운드 수가 늘어난다. 무한 카운팅이 무한값에서만
  멈춘다는 것을 보는 자리다.
- 선형 망을 `A - B - C - D`로 늘려 본다. 링크상태의 라운드 수는 끊긴 곳에서 가장 먼 라우터까지의 홉 수를 따른다.
