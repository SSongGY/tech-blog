# 예제 코드 — IPv6 전환 기술이 쓰는 주소 계산

RFC 6052(NAT64/DNS64의 IPv4 내장 IPv6 주소), RFC 3056(6to4 프리픽스), RFC 4213(구성 터널 MTU)에 적힌
규칙으로 주소와 MTU를 계산하고, RFC 6052의 예시 표와 같은 값이 나오는지 검산한다.
패킷을 실제로 주고받는 실험이 아니라 **규칙의 계산**이다. 외부 의존성 없이 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python transition_addresses.py
```

## 바꿔볼 값

- 4번에 `100.64.0.1`(통신사 공유 주소 대역)을 넣어 DNS64가 합성하는지 본다. `ipaddress`가 전역 주소로 보는지가 갈린다.
- `embed_ipv4`에서 u 옥텟을 건너뛰는 두 줄을 지우면 1번 표에서 어느 길이가 불일치로 바뀌는지 센다.
- 6번의 경로 MTU에 1280을 넣으면 동적 터널 MTU가 IPv6 최소 MTU(1280)보다 작아지는 것을 확인한다.
