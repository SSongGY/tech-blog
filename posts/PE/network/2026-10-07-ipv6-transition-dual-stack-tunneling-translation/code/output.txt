== 1. RFC 6052 §2.4 표 검산 — IPv4 192.0.2.33 을 프리픽스 길이별로 넣는다
  /32  2001:db8:c000:221::              RFC 일치 · 역변환 192.0.2.33
  /40  2001:db8:1c0:2:21::              RFC 일치 · 역변환 192.0.2.33
  /48  2001:db8:122:c000:2:2100::       RFC 일치 · 역변환 192.0.2.33
  /56  2001:db8:122:3c0:0:221::         RFC 일치 · 역변환 192.0.2.33
  /64  2001:db8:122:344:c0:2:2100:0     RFC 일치 · 역변환 192.0.2.33
  /96  2001:db8:122:344::c000:221       RFC 일치 · 역변환 192.0.2.33

== 2. u 옥텟(비트 64~71)이 실제로 0인가 — 9번째 바이트
  /32  9번째 바이트 = 0x00
  /40  9번째 바이트 = 0x00
  /48  9번째 바이트 = 0x00
  /56  9번째 바이트 = 0x00
  /64  9번째 바이트 = 0x00
  /96  9번째 바이트 = 0x00

== 3. 허용되지 않는 길이
  RFC 6052 가 허용하지 않는 길이: /44

== 4. DNS64 합성 — 잘 알려진 프리픽스 64:ff9b::/96
  192.0.2.33 -> 합성하지 않음 (전역 주소가 아니다, RFC 6052 §3.1)
  8.8.8.8 -> 64:ff9b::808:808
  10.1.2.3 -> 합성하지 않음 (전역 주소가 아니다, RFC 6052 §3.1)
  192.168.0.10 -> 합성하지 않음 (전역 주소가 아니다, RFC 6052 §3.1)

== 5. 6to4 사이트 프리픽스 — 2002:V4ADDR::/48
  8.8.8.8        -> 2002:808:808::/48  (첫 주소 2002:808:808::1, 표준 라이브러리 sixtofour = 8.8.8.8)
  1.1.1.1        -> 2002:101:101::/48  (첫 주소 2002:101:101::1, 표준 라이브러리 sixtofour = 1.1.1.1)

== 6. 구성 터널 MTU — RFC 4213 §3.2
  IPv4 경로 MTU 1500 -> 동적 터널 MTU 1480
  IPv4 경로 MTU 1492 -> 동적 터널 MTU 1472
  IPv4 경로 MTU 1400 -> 동적 터널 MTU 1380
  정적 터널 MTU 허용 범위 1280~1480, 권고값 1280
