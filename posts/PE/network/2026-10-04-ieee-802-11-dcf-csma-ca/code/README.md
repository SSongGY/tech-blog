# 예제 코드 — 802.11 DCF·EDCA의 IFS·백오프·충돌 확률 계산

RFC 8325가 정리한 5 GHz 대역의 DCF·EDCA 파라미터로 IFS와 경쟁 창을 계산하고,
Bianchi(2000)의 포화 상태 모델 식 (7)·(9)를 풀어 단말 수에 따른 충돌 확률을 구한다.
같은 값을 슬롯 단위 시뮬레이션으로도 돌려 모델과 맞춰 본다. 외부 의존성 없이 표준 라이브러리만 쓴다.

## 실행

```bash
python dcf_calc.py
```

## 모델

- **포화 상태**: 모든 단말이 늘 보낼 프레임을 갖고 있다. 채널 오류·숨은 단말·캡처는 없다.
- 시뮬레이션은 Bianchi 모델과 같은 이산 시간 척도를 쓴다. 한 "슬롯"은 빈 슬롯이거나 송신 한 번이다.
  누군가 보내는 슬롯에서는 나머지 단말의 카운터를 줄이지 않는다(동결).
- 재시도 한도는 넣지 않았다. CW가 CWmax에 닿으면 그 값을 계속 쓴다.
- AC_VO의 CWmin 3 → CWmax 7처럼 창이 작은 접근 범주를 같은 범주끼리만 경쟁시켰다.
  범주가 섞인 경쟁(AIFS 차이 포함)은 모델에 없다.
