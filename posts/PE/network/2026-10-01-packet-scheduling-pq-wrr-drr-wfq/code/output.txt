== 1. 패킷 길이가 다른 두 흐름, 가중치 1:1 ==
  A: 1500B 패킷, B: 100B 패킷. 링크가 30,000B 를 보낼 때까지의 몫
  PQ (A 우선)                A  30000B (100.0%)  B      0B (  0.0%)
  PQ (B 우선)                A      0B (  0.0%)  B  30000B (100.0%)
  WRR 1:1 (패킷 수)           A  28500B ( 94.1%)  B   1800B (  5.9%)
  DRR Quantum 1500:1500    A  15000B ( 50.0%)  B  15000B ( 50.0%)
  WFQ φ 1:1                A  15000B ( 50.0%)  B  15000B ( 50.0%)
  WRR 이론값: A:B = Max/Min = 15:1 → A 93.8%

== 2. 같은 길이(1000B), 목표 비율 A:B:C = 3:2:1 ==
  WRR 3:2:1                A  30000B ( 50.0%)  B  20000B ( 33.3%)  C  10000B ( 16.7%)
  DRR Quantum 3000:2000:1000 A  30000B ( 50.0%)  B  20000B ( 33.3%)  C  10000B ( 16.7%)
  WFQ φ 3:2:1              A  30000B ( 50.0%)  B  20000B ( 33.3%)  C  10000B ( 16.7%)

== 2-1. 같은 목표 3:2:1 인데 C 만 패킷이 3000B ==
  WRR 3:2:1                A  24000B ( 40.0%)  B  15000B ( 25.0%)  C  21000B ( 35.0%)
  DRR Quantum 3000:2000:1000 A  33000B ( 53.2%)  B  20000B ( 32.3%)  C   9000B ( 14.5%)
  WFQ φ 3:2:1              A  31000B ( 51.7%)  B  20000B ( 33.3%)  C   9000B ( 15.0%)
