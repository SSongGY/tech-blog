# 계산 코드 — QUIC 규칙 검산

외부 의존성 없다. 파이썬 표준 라이브러리만 쓴다. 패킷을 주고받는 실험이 아니라
RFC에 적힌 규칙을 코드로 옮겨 RFC의 예시와 맞는지 확인하는 계산이다.

## 실행

```bash
python quic_calc.py
```

확인 환경: Python 3.13.5 / Windows 11. 실행 기록은 `output.txt`.

## 각 장이 보는 것

| 장 | 확인하는 것 |
|---|---|
| 1 | RFC 9000 §16 가변 길이 정수 — 부록 A.1 예시 4개를 디코딩하고 다시 인코딩해 비교. 같은 값을 긴 형식으로 적어도 같은 값으로 읽히는 것 |
| 2 | RFC 9000 §2.1 — 스트림 ID 0~11의 하위 2비트로 시작 주체·방향을 가른다 |
| 3 | RFC 9114 §1의 머리 막힘 문장을 규칙으로 옮긴 모형 — 패킷 하나가 사라졌을 때 멈추는 스트림 수 |
| 4 | RFC가 적은 왕복 수(TCP 1 + TLS 1.3 1, QUIC 1, 0-RTT 0)에 RTT를 곱한 표 |

## 바꿔 볼 값

- 3장의 `lost=2`를 `lost=6`으로 바꾸면 TCP 쪽도 멈추는 스트림이 C 하나로 준다 — 마지막 패킷이라 뒤에 막힐 것이 없기 때문이다.
- 1장의 `RFC_SAMPLES`에 다른 바이트열을 넣으면 길이가 첫 바이트의 상위 2비트로만 정해지는 것이 보인다.
