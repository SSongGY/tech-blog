# 예제 코드 — 로드 밸런싱 분배 알고리즘 계산

라운드 로빈·가중 라운드 로빈·최소 연결·해시(mod N, 링 일관된 해시, Maglev 해시)·출발지 IP 고정을
같은 요청 흐름에 적용해 분배 결과를 센다. 망을 흉내 낸 측정이 아니라 **알고리즘의 계산**이다.
난수는 시드를 고정했고 키 해시는 SHA-1이라 어디서 돌려도 같은 숫자가 나온다.
외부 의존성 없이 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python lb_algorithms.py
```

## 바꿔볼 값

- 2번의 긴 요청 비율 `0.7`을 `0.95`(거의 다 짧은 요청)로 바꾸면 라운드 로빈과 최소 연결의 차이가 얼마나 줄어드는지 본다.
- 3번 `HashRing(points=160)`을 `points=1`로 바꾸면 서버별 키 분포가 얼마나 치우치는지, 이동 비율은 그대로인지 본다.
- 3번 Maglev `table_size`를 `65537`에서 `655373`으로 올리면 조회표 칸이 바뀌는 비율이 어떻게 달라지는지 본다(둘 다 소수).
- 4번 NAT 비율 `0.3`을 `0.05`로 낮추면 IP 해시의 치우침이 라운드 로빈에 얼마나 가까워지는지 본다.
