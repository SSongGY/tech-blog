# 예제 코드 — 네 가지 다중 접속 방식의 자원 단위 계산

FDMA·TDMA·CDMA·OFDMA가 자원을 나누는 단위와 그 대가(보호 대역, 슬롯 대기, 코드 직교성,
순환 전치)를 3GPP 규격의 숫자로 계산한다. 외부 의존성 없이 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python multiple_access_calc.py
```

## 모델

- FDMA·TDMA는 GSM(TS 45.005·45.002), CDMA는 W-CDMA(TS 25.213), OFDMA는 LTE(TS 36.211·36.300)
  규격의 숫자를 그대로 넣었다.
- OVSF 코드는 TS 25.213의 코드 트리 생성 규칙으로 만들었다.
- 마지막 절은 부반송파 64개짜리 작은 OFDM 심볼을 직접 DFT로 만들어, 반사파가 있는 채널을
  통과시킨 뒤 순환 전치가 있을 때와 없을 때 복원 오차를 비교한다. 잡음은 넣지 않았다.
  LTE의 실제 크기(2048점)가 아니라 원리 확인용이다.
- PAPR 비교는 64점 IFFT 중 연속 부반송파 16개를 한 단말에 주고, QPSK를 그대로 실을 때(OFDMA)와
  16점 DFT로 먼저 펼쳐 실을 때(SC-FDMA)를 `random.Random(11)`로 400심볼씩 돌렸다. 펄스 성형은 없다.
