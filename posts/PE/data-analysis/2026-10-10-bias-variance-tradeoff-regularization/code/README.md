# 편향-분산 분해와 규제

같은 모형을 학습 표본만 바꿔 200번 맞추고, 평가 격자 위에서 기대 시험 오차를
편향²·분산·잡음으로 나눈다. 외부 의존성은 없고 시드를 고정했다.

- `[1]` 분해식 합계가 새 잡음으로 직접 잰 시험 MSE 와 맞는지
- `[2]` 다항식 차수(모형 용량)를 올릴 때 편향²과 분산
- `[3]` L2 규제 강도별 편향²·분산·계수 크기
- `[4]` L1 규제 강도별 편향²·분산·0이 된 계수 수
- `[5]` 경사 하강을 일찍 멈출 때 (걸음 수별)
- `[6]` 드롭아웃을 주변화한 목적식 (유지 확률 p 별)
- `[7]` 학습 표본마다 5-겹 교차검증으로 L2 강도를 고른 결과
- `[8]` 학습 표본 수를 늘릴 때

## 실행

```bash
python bias_variance.py
```
