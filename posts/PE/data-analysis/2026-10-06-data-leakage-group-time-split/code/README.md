# 예제 코드 — 데이터 누수 세 갈래 재현

정답과 특징 사이에 진짜 관계가 없거나 약한 데이터를 만들고, 분할만 바꿔 평가 점수가
얼마나 부풀려지는지 잰다.

1. 같은 환자의 기록이 학습·평가에 갈라 들어가는 **묶음 누수** — 행 단위 분할 vs 환자 단위 분할
2. 분할 전에 전체 데이터로 특징을 고르는 **전처리 누수** — 폴드 밖 선택 vs 폴드 안 선택
3. 시계열을 섞어 나누는 **시간 누수** — 무작위 분할 vs 시간 순서 분할

시드 10개의 평균을 낸다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python leakage_demo.py
```

## 바꿔볼 값

- `RECORDS_PER_PATIENT`를 1로 두면 실험1의 두 분할이 같은 결과로 수렴한다. 묶음이 없으면 누수도 없다.
- `FEATURES`를 줄이면 실험2의 부풀림이 작아진다. 고를 후보가 많을수록 우연히 맞는 특징이 많다.
