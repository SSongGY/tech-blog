# 협업 필터링 세 접근 비교

같은 6×5 평점 행렬 하나에 사용자 기반·아이템 기반·행렬 분해를 적용해
u1 의 i5 평점을 각각 예측한다. 표준 라이브러리만 쓴다.

- 사용자 기반 상관계수와 평균 편차 가중평균 — GroupLens (CSCW 1994)
- 아이템 유사도 코사인 / 상관 / 조정 코사인, 가중합 예측 — Sarwar et al. (WWW10 2001)
- 편향 포함 행렬 분해를 SGD 로 학습 — Koren et al. (IEEE Computer 2009)

SGD 는 난수 초기화를 쓰므로 `seed=20261025` 로 고정했다. 시드를 바꾸면
잠재요인의 부호와 축이 달라지지만 예측값은 비슷한 자리에 모인다.

## 실행

```bash
python cf_compare.py
```
