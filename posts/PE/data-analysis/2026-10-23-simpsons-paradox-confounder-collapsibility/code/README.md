# 심슨의 역설 계산

표준 라이브러리만 쓴다. 들어가는 숫자는 모두 발표된 표에서 그대로 옮겼고,
계산만 이 스크립트가 한다.

- `CARDS` / `TREATMENT` — Simpson(1951) Table 2·4의 52장 분할표
- `BERKELEY` — Bickel·Hammel·O'Connell(1975)이 쓴 1973년 버클리 상위 6개 학과
  지원·합격 수. 학과별 지원자 수와 합격률, 전체 합계(남 2,691명 중 1,198명 44.5%,
  여 1,835명 중 557명 30.4%)가 발표된 값과 맞는지 출력으로 대조할 수 있다

## 실행

```bash
python simpsons_paradox.py
```
