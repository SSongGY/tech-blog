# 신규성 탐지 계산 예제

1차원 가상 데이터로 정상 모델(평균·표준편차)을 만들고, 학습 데이터 오염과 신규 패턴 편입이
판정을 어떻게 바꾸는지 계산한다. 표준 라이브러리만 쓴다. 난수 시드는 고정돼 있다.

## 실행

```bash
python novelty_demo.py
```

## 바꿔 볼 값

- `K` — 임곗값 배수. 키우면 오경보가 줄고 놓치는 것이 는다
- `CONFIRM_COUNT` — 신규 판정이 몇 건 모여야 새 정상으로 편입할지
- `contaminated_train` 의 오염 건수(50)를 늘려 2)의 임계 범위가 얼마나 벌어지는지 본다
