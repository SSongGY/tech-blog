== 0. 거래 데이터 (최소 지지 개수 3) ==
  100: f a c d g i m p
  200: a b c f l m o
  300: b f h j o
  400: b c k s p
  500: a f c e l p m n
  서로 다른 항목 17개 -> 공집합을 뺀 모든 항목집합 2^17-1 = 131,071개

== 1. Apriori: 회차마다 join -> prune -> DB 한 번 훑어 세기 ==
1회차: 항목 17개를 세어 L1 6개 -> {a}:3 {b}:3 {c}:4 {f}:4 {m}:3 {p}:3
2회차: join 15개, prune 0개, 센 후보 15개 -> L2 7개
        {a,c}:3 {a,f}:3 {a,m}:3 {c,f}:3 {c,m}:3 {c,p}:3 {f,m}:3
3회차: join 6개, prune 2개 {c,f,p} {c,m,p}, 센 후보 4개 -> L3 4개
        {a,c,f}:3 {a,c,m}:3 {a,f,m}:3 {c,f,m}:3
4회차: join 1개, prune 0개, 센 후보 1개 -> L4 1개
        {a,c,f,m}:3
5회차: join 0개, prune 후 0개 -> 종료 (DB 를 읽지 않는다)
DB 스캔 4회, 지지도를 센 집합 37개, 빈발 항목집합 18개

== 2. prune 단계 예: 논문 §2.1.1 의 L3 ==
L3 = {1,2,3} {1,2,4} {1,3,4} {1,3,5} {2,3,4}
join 결과 = {1,2,3,4} {1,3,4,5}
prune 결과 = {1,2,3,4}  ({1,4,5} 가 L3 에 없어 {1,3,4,5} 삭제)

== 3. FP-growth: DB 두 번 훑어 FP-tree 를 만들고 트리만 채굴 ==
빈도순 항목: f c a b m p
FP-tree (노드 11개, 거래 5건의 빈발 항목 총 20개):
  f:4
    c:3
      a:3
        m:2
          p:2
        b:1
          m:1
    b:1
  c:1
    b:1
      p:1
접미사별 조건부 패턴 기반 -> 그 안의 빈발 항목
  p: fcam:2; cb:1             -> c:3
  m: fca:2; fcab:1            -> a:3 c:3 f:3
  b: fca:1; f:1; c:1          -> 없음
  a: fc:3                     -> c:3 f:3
  c: f:3                      -> f:3
  f: (없음)                     -> 없음
DB 스캔 2회, 빈발 항목집합 18개

== 4. 두 결과 비교 ==
항목집합과 지지 개수가 모두 같은가: True
  1-항목집합 6개: {a}:3 {b}:3 {c}:4 {f}:4 {m}:3 {p}:3
  2-항목집합 7개: {a,c}:3 {a,f}:3 {a,m}:3 {c,f}:3 {c,m}:3 {c,p}:3 {f,m}:3
  3-항목집합 4개: {a,c,f}:3 {a,c,m}:3 {a,f,m}:3 {c,f,m}:3
  4-항목집합 1개: {a,c,f,m}:3
