# 가설 검정 — α·β·검정력·표본 크기 계산

모표준편차를 아는 z 검정을 가정하고, NIST/SEMATECH e-Handbook §7.2.2.2의
표본 크기 공식으로 α·β·검정력·표본 크기의 관계를 계산한다. 같은 값을 난수
모의실험(시드 고정)으로 다시 세어 공식과 맞는지 본다. 표준 라이브러리만 쓴다.

## 실행

```bash
python power_and_errors.py
```

## 바꿔 볼 값

- 2번의 `n=16` — 표본을 늘리면 같은 α에서 β가 줄어든다.
- 4번의 `effect` 목록 — δ/σ를 절반으로 줄일 때마다 N이 네 배가 되는지 본다.
- 6번의 `m` 목록 — 검정 수를 늘리면 α를 그대로 둔 쪽의 거짓 양성이 1−(1−α)^m을 따라간다.
- 7번의 `looks` — 같은 총 표본을 더 잘게 나눠 볼수록 거짓 양성이 커진다.
