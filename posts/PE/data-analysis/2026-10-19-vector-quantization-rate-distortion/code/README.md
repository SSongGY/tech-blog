# 양자화 왜곡과 율-왜곡 한계의 격차

표준정규분포를 원천으로 두고, 양자화기가 내는 왜곡이 율-왜곡 함수가 정한
한계에서 얼마나 떨어져 있는지 직접 계산한다.

- `quantization_gap.py`
  - **A** 로이드-맥스 고정률 스칼라 양자화기 — 1~8비트의 왜곡과 한계 대비 격차.
    2레벨은 닫힌 형태 `1 − 2/π` 와, 고해상도 격차는 이론값 `10log₁₀(√3π/2)` 와 대조한다
  - **B** 균일 양자화기 + 엔트로피 부호화 — 격차가 1.53 dB로 수렴하는지 확인
  - **C** 정사각 격자와 육각 격자의 정규화 2차 모멘트 — 닫힌 형태와 격자 합을 대조
  - **D** 상관된 두 성분을 KLT로 돌렸을 때의 왜곡 비
  - **E** 곱 양자화의 코드북 항목 수

난수를 쓰지 않는다. 적분은 닫힌 형태(`erf`)나 균등 격자 합으로 하므로 어느
환경에서든 같은 값이 나온다.

## 실행

```bash
python quantization_gap.py
```

의존성 없음. 표준 라이브러리만 쓴다.
