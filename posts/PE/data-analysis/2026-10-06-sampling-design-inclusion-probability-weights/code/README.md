# 예제 코드 — 표본설계 다섯 가지의 정확한 기댓값과 분산

모집단 12개(층 A 9개, 층 B 3개)에서 표본 4개를 뽑는 설계를 단순무작위·층화
비례배분·층화 불균등배분·집락·할당으로 바꿔 가며, 가능한 표본을 **전부 나열해**
추정량의 기댓값·편향·표준편차를 정확히 계산한다. 난수를 쓰지 않으므로 결과가
돌릴 때마다 같다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python sampling_designs.py
```

## 바꿔볼 값

- `CLUSTERS`를 값이 섞이도록 다시 묶으면(예: `("a1", "b1")`) 집락추출의 표준편차가
  줄어든다. 집락 안이 이질적일수록 집락추출이 효율적이다.
- `stratified(2, 2)`를 `stratified(1, 3)`으로 바꾸면 가중치를 무시했을 때의 편향이
  더 커진다.
