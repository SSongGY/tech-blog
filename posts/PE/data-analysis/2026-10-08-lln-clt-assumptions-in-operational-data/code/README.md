# 극한 정리의 전제가 깨질 때

표본평균의 오차를 `σ/√n` 으로 잡는 계산이 전제가 깨지면 어떻게 틀어지는지 확인한다.
외부 의존성은 없고 시드를 고정했다.

- `[1]` 독립·동일분포 지수분포에서 `평균 ± 1.96·s/√n` 구간이 참 평균을 덮는 비율 (기준선)
- `[2]` 자기상관이 있는 AR(1) 데이터에서 분산 팽창 계수, 유효 표본 수, 단순 구간과 배치 평균 구간의 적중률
- `[3]` 분산이 무한한 파레토(α = 1.5)에서도 누적 평균은 참 평균으로 가는지
- `[4]` 같은 파레토에서 단순 구간의 적중률이 n 을 늘려도 0.95 로 가지 않는지 (α = 3 과 비교)
- `[5]` 지수분포 표준화 평균과 정규분포의 최대 거리를 얼랑 분포로 정확히 계산해 베리-에센 상한과 비교
