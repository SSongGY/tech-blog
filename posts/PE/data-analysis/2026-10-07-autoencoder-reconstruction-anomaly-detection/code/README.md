# 예제 코드 — 오토인코더 재구성 오차로 이상 찾기

네 지표가 두 잠재 변수로 정해지는 정상 데이터를 만들고, 값은 모두 정상 범위 안인데
지표 사이의 관계만 깨진 이상 데이터를 섞는다. 4-8-2-8-4 오토인코더를 표준 라이브러리로
직접 구현해 두 가지를 확인한다.

1. 지표별 범위 검사가 놓치는 이상을 재구성 오차가 잡는가
2. 학습 데이터에 같은 이상이 섞이면(오염) 재구성 오차와 탐지율이 어떻게 바뀌는가

임계값은 정상 검증 데이터 오차의 99백분위로만 정한다. 이상 레이블은 평가에만 쓴다.

## 실행

```bash
python autoencoder_demo.py
```

## 바꿔볼 값

- `CODE_DIM` 을 4로 올리면 병목이 사라져 항등 함수에 가까워지고, 이상도 잘 복원된다.
- 오염용 이상 개수(`contamination`)를 늘리거나 줄여 탐지율 변화를 본다.
