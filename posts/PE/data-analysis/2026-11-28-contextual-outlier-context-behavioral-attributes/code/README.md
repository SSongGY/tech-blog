# 맥락 단위에 따른 맥락 아웃라이어 검출 결과

표준 라이브러리만 쓴다. 외부 패키지가 필요 없다.

## 실행

```bash
python context_granularity.py
```

## 무엇을 하는가

- 가상 시간대별 요청 수 56일 x 24시간을 만든다 (하루 곡선 + 주말 70% + 표준편차 5 노이즈)
- 맥락 정의 5가지(전역, 시각, 시각 x 평일/주말, 시각 x 요일, 시각 x 요일 x 전후 4주)로 묶어
  맥락마다 수정 Z 점수를 계산하고 |Z| > 3.5 를 아웃라이어로 본다
- seed 7 로 한 번 돌려 심은 맥락 아웃라이어(20일차 03시, 값 120)의 Z 와 그 외 검출 수를 찍는다
- 심은 점 없이 seed 1~200 을 돌려 맥락 정의별 평균 오탐 수를 찍는다
