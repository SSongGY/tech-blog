# 예제 코드 — 부트스트랩 재표집 절차와 신뢰구간 세 가지 검산

본문이 주장하는 네 가지를 직접 계산해 확인한다. 식은 Efron & Narasimhan(2020)의
(2.2)·(2.9)·(3.11)·(3.12)를 그대로 옮겼다.

- 복원추출 B회의 복제값이 흩어진 정도가 표준오차 추정이 된다
- `B`를 키울 때 표준오차와 구간 끝점 중 무엇이 먼저 안정되는가
- 같은 복제값에서 표준·백분위수·BCa 구간의 끝점이 어떻게 갈리는가
- 중앙값에서 잭나이프는 멈추고 부트스트랩은 도는 이유

## 요구 사항

- Python 3.9 이상 (표준 라이브러리만 사용, 추가 설치 없음)

## 실행

```bash
python bootstrap_probe.py
```

`[2]`가 `B` 사다리 다섯 단계를 각각 20번씩 돌리므로 1분 안팎이 걸린다.

## 출력 구성

| 섹션 | 내용 |
|---|---|
| `[1]` | 표본평균과 불편분산의 부트스트랩 SE·잭나이프 SE·이론값 비교 |
| `[2]` | `B`를 50~20,000으로 올리며 SE 추정과 구간 끝점의 흔들림을 잰다 |
| `[3]` | 같은 복제값에서 표준·백분위수·BCa 구간의 끝점, `z0`와 `a` |
| `[4]` | 중앙값에서 잭나이프 복제값과 부트스트랩 복제값의 서로 다른 값 개수 |

## 계산 조건

- 난수 씨앗은 `SEED = 20260922` 고정. 몇 번을 돌려도 같은 값이 나온다
- 모집단을 `Exp(1)`로 둔 것은 **치우친 분포라야 백분위수와 BCa가 갈리고**,
  동시에 참값(모평균 1, 모분산 1, 중앙값 `ln 2`, 중앙값의 점근 표준오차 `1/√n`)을
  손으로 적을 수 있어 추정값이 맞는지 확인되기 때문이다
- 표본 크기 `SAMPLE_SIZE = 25`, 기본 복제 수 `B_DEFAULT = 4000`
- 백분위수는 정렬된 `B`개 중 `⌈q·B⌉`번째로 정의했다. 보간하는 정의를 쓰면
  끝점이 소수점 아래에서 조금 달라지지만 흐름은 같다

## 값을 바꿔가며 확인할 것

- `SAMPLE_SIZE`를 100으로 올리면 `[3]`의 세 구간이 서로 가까워진다.
  `n`이 커질수록 표집분포가 정규에 가까워져 보정할 것이 줄기 때문이다
- `[4]`의 `SAMPLE_SIZE`를 키워도 잭나이프 복제값의 서로 다른 값 개수는 거의 늘지 않는다.
  이것이 잭나이프가 중앙값에서 수렴하지 않는 이유다
- `MEAN`을 바꿔도 `[3]`의 `z0`·`a`는 거의 그대로다. 척도만 바뀌고 치우침은 같기 때문이다
