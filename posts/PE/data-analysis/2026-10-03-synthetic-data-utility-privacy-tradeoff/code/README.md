# 예제 코드 — 합성데이터 위험도 세 가지와 유용성의 상충

본문이 주장하는 세 가지를 같은 원본에 대해 계산해 확인한다.
위험도 산출 절차는 개인정보보호위원회 「합성데이터 생성·활용 안내서」(2024-12)
부록2, 임계값 산정 절차는 부록4를 그대로 옮겼다.

- 원본을 닮을수록 유용성 차이는 0에 가까워지고 위험도는 올라간다
- 구별 위험도가 0이어도 추론 위험도는 높을 수 있다
- 추론 위험도의 기준점은 0이 아니라 '같은 모집단에서 새로 뽑은 표본'이 내는 값이다

## 요구 사항

- Python 3.10 이상 (`statistics.correlation` 사용, 표준 라이브러리만)

## 실행

```bash
python synth_risk.py
```

## 출력 구성

| 섹션 | 내용 |
|---|---|
| `[1]` | 원본 앞 5건과 각 레코드의 준식별자(연령대·직업·성별)·민감정보(소득 구간) |
| `[2]` | 합성 방식 네 가지의 구별·연결(CAP)·추론 위험도와 유용성 차이 두 가지 |
| `[3]` | 원본을 50:50으로 나눠 반복 측정한 추론 위험도 분포와 95% 분위수 |
| `[4]` | 과적합 세트에서 원본과 같은 레코드만 지웠을 때 지표가 어떻게 바뀌는가 |

## 계산 조건

- 난수 씨앗 `SEED = 20261003` 고정. 몇 번을 돌려도 같은 값이 나온다
- 원본은 가상 모집단에서 300건을 뽑는다. 소득은 직업별 기본값에 나이 효과와 잡음을 더해
  만들었으므로 나이–소득 상관이 있다
- 합성 방식 네 가지는 생성 모델을 흉내 낸 것이다
  - `과적합`: 40%는 원본을 그대로, 나머지는 소득만 0.1 흔든 레코드
  - `새 표본`: 같은 모집단에서 새로 300건. 모집단을 완벽히 배운 모델의 출력에 해당한다
  - `주변분포만`: 원본의 열을 각각 따로 섞었다. 열 하나의 분포는 같고 열 사이 관계는 없다
  - `균등 잡음`: 각 열을 범위 안에서 균등하게 뽑았다
- 거리는 가워 거리(수치형은 원본 범위로 나눈 차이, 범주형은 불일치 0/1의 평균)
- CAP은 준식별자가 같은 합성 레코드가 하나라도 있는 원본 레코드에 대해서만 평균을 낸다.
  `CAP>0.7`은 원본 전체 중 CAP이 0.7을 넘는 레코드의 비율이다
