# A/B 테스트 — 표본 크기, z 검정, SRM, 중간 확인

의존성 없이 표준 라이브러리만 쓴다. `random.binomialvariate` 때문에 Python 3.12 이상이 필요하다.

## 실행

```bash
python ab_test.py
```

## 무엇을 확인하는가

- 기준 전환율과 최소 검출 효과로 군당 표본 수를 구하고, 어림식 16σ²/Δ²의 16이 어디서 오는지
- NIST/SEMATECH 핸드북의 두 비율 z 통계량으로 결과를 판정하는 과정
- 설계한 50:50과 실제 유입 수가 어긋날 때 카이제곱으로 SRM을 잡아내는 기준
- 차이가 없는 A/A 실험에서 중간 결과를 계속 들여다보면 거짓 양성이 α보다 커진다는 것
