# 유전 알고리즘 검산

0/1 배낭 문제(물건 10개, 용량 40)로 답안에 실은 내용을 확인한다.

- 1부: 개체 6개로 한 세대(평가 → 룰렛 선택 → 1점 교차 → 비트 변이)를 따라간다
- 2부: 룰렛만 쓴 기본형, 엘리트 보존, 토너먼트 선택, 지역 탐색 결합(메메틱)을
  50번씩 돌려 최적해 도달 횟수와 평가 횟수를 비교한다

최적해는 2^10 = 1,024개 후보를 전부 평가해 구한다. 의존성 없음, 표준 라이브러리만 쓴다.
난수 시드를 고정했으므로 같은 Python 버전에서는 같은 출력이 나온다.

## 실행

```bash
python ga.py
```
