== 1. 예제 트리 ==
삽입 순서: [50, 30, 70, 20, 40, 60, 80, 35]
구조    : 50(30(20, 40(35, .)), 70(60, 80))
중위 순회: [20, 30, 35, 40, 50, 60, 70, 80]
높이    : 3

== 2. 탐색 경로 ==
찾는 키 35: 경로 [50, 30, 40, 35], 비교 4회, 성공
찾는 키 65: 경로 [50, 70, 60], 비교 3회, 실패

== 3. 삭제 세 경우 ==
20 삭제(자식 0개) -> 50(30(., 40(35, .)), 70(60, 80))
  중위 순회: [30, 35, 40, 50, 60, 70, 80]
40 삭제(자식 1개) -> 50(30(., 35), 70(60, 80))
  중위 순회: [30, 35, 50, 60, 70, 80]
50 삭제(자식 2개) -> 60(30(., 35), 70(., 80))
  중위 순회: [30, 35, 60, 70, 80]

== 4. 입력 순서와 높이 (N=15) ==
정렬 순서 입력 높이: 14
균형 순서 입력 높이: 3

== 5. 무작위 입력의 평균 비교 횟수 ==
N=  1000: 측정 11.98회, 2 ln N = 13.82, lg N = 9.97, 높이 23
N= 10000: 측정 17.71회, 2 ln N = 18.42, lg N = 13.29, 높이 28
