# 아웃라이어 세 유형과 노이즈 — 검출 기준별 검산

답안 Ⅲ절과 Ⅳ절에 실은 결과를 직접 계산한다. 파이썬 표준 라이브러리만 쓴다.

- `outlier_types.py` — 가상의 시간대별 요청 수(14일 x 24시간)에 노이즈를 섞고
  전역·맥락·군집 아웃라이어를 하나씩 심은 뒤, 세 가지 기준으로 검출한다
  1. 전역 기준 — 전체 데이터의 중앙값·MAD 로 계산한 수정 Z 점수
  2. 맥락 기준 — 시간대(맥락 속성)로 묶어 그 안에서 계산한 수정 Z 점수
  3. 군집 기준 — 6시간 창의 표준편차가 노이즈 수준보다 훨씬 작은 구간
  4. 같은 검출을 노이즈 제거(이웃 3점 중앙값 필터) 뒤에 다시 돌린다

수정 Z 점수와 임계값 3.5는 NIST/SEMATECH *e-Handbook of Statistical Methods*
§1.3.5.17 Detection of Outliers 를 따른다. 데이터는 전부 가상이다.

## 실행

```bash
python outlier_types.py
```
