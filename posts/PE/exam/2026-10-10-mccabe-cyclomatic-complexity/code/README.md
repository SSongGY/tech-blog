# 맥케이브 순환복잡도 검산

답안에 쓴 계산법 세 가지가 같은 값을 내는지, 기본 경로 수가 V(G) 와 같은지 확인한다.
외부 의존성은 없다.

- `[1]` 제어 흐름 그래프에서 `E - N + 2P`
- `[2]` 이진 판단 노드 수 `p + 1`
- `[3]` 소스의 판단 구문(if·for·while·and·or 등)을 세는 방법, and 를 빼면 무엇이 달라지는지
- `[4]` 진입-종료 경로의 간선 벡터 랭크가 V(G) 와 같은지, 그 기본 경로 집합
- `[5]` if 문을 이어 붙일 때 V(G) 는 선형, 전체 경로 수는 지수로 느는지

## 실행

python cyclomatic.py
