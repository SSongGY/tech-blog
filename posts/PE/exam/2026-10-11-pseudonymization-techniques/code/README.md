# 가명처리 '대체' 기법 검산

답안 Ⅲ의 고려사항을 확인한다. 외부 의존성은 없고 키와 난수 시드를 고정했다. 전화번호는 전부 가상이다.

- `[1]` 키 없는 해시로 만든 가명이 후보 열거로 되돌아가는지, 얼마나 걸리는지
- `[2]` 키 있는 해시(HMAC)는 키 없이 같은 열거를 해도 되돌아가지 않는지
- `[3]` 제공처마다 같은 키를 쓰면 두 가명정보가 가명만으로 결합되는지
- `[4]` 토큰화에서 토큰이 원래 값과 무관하게 발급되고 매핑표로만 연결되는지

## 실행

```bash
python hash_pseudonym.py
```
