# 예제 코드 — CPM 주공정과 PERT 납기 확률

8개 활동으로 된 정보시스템 구축 일정에서 전진·후진 계산으로 ES·EF·LS·LF와
총 여유(TF)·자유 여유(FF)를 구하고, 활동을 지연시켜 여유가 뜻하는 바를 확인한다.
이어서 PERT 공식으로 납기 확률을 계산하고, 모든 경로를 함께 굴리는 몬테카를로
결과와 비교해 병합 편향(merge bias)을 드러낸다. 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python cpm_pert.py
```

## 바꿔볼 값

- `ACTIVITIES`에서 `D`의 비관값 `24`를 `12`로 줄이면 몬테카를로 결과가 PERT 공식에
  가까워진다. 비주공정 경로가 주공정을 앞지르는 일이 줄기 때문이다.
- `DEADLINE`을 바꿔 PERT 공식과 몬테카를로의 차이가 어디서 커지는지 본다.
