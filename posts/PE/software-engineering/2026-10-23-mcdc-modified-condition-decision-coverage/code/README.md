# MC/DC 독립 영향 쌍 검산

`Z = (A or B) and (C or D)` 의 진리표 16행을 전부 전개해

- 조건별 유일 원인(unique-cause) 독립 영향 쌍
- 마스킹(masking) 방식에서만 추가로 성립하는 쌍
- 두 방식 각각의 최소 테스트 집합 크기
- 2입력 and·or·xor 의 최소 테스트 집합 가짓수

를 계산한다. NASA/TM-2001-210876 부록 B 표 1 과 본문 2.3.5 절의 값과 맞춰 보기 위한 것이다.

## 실행

```bash
python mcdc.py
```

의존성 없음. Python 3.13.5 에서 확인했다.
