# 예제 코드 — 분류 트리 조합표와 커버리지 기준별 케이스 수

파이썬 표준 라이브러리(`itertools`)만 쓴다. 설치할 것이 없다.

## 실행

```bash
python ctm_combinations.py
```

## 바꿔 볼 값

- `TREE` 의 `회원 등급` 에 `"VIP"` 를 더하면 전체 조합과 pairwise 케이스 수가 각각 얼마나 늘어나는지 본다
- `is_feasible` 의 의존 규칙을 지우면 양립 불가 조합이 후보로 돌아오고, 탐욕 선택이 그 조합을 고르는지 확인한다
- `greedy_pairwise` 는 최소 해를 보장하지 않는다. 출력의 "하한" 과 "탐욕 선택" 의 차이가 그 간격이다
