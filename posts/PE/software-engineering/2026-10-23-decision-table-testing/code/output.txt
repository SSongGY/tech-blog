[예 1 · API 요청] 전체 결정 테이블 — 조건 3개, 열 8개 (2^3)
                 1    2    3    4    5    6    7    8
토큰 유효        T    T    T    T    F    F    F    F
한도 이내        T    T    F    F    T    T    F    F
리소스 존재      T    F    T    F    T    F    T    F
액션           200  404  429  429  401  401  401  401
  실현 가능한 열 8개 / 전체 8개 → 100% 커버리지의 분모는 8

[예 1 · API 요청] 병합 후 — 열 4개 (조건 순서: 토큰 유효, 한도 이내, 리소스 존재)
    T    T    T  →  200
    F    –    –  →  401
    T    T    F  →  404
    T    F    –  →  429

[예 2 · 요금 구분] 전체 결정 테이블 — 조건 2개, 열 4개 (2^2)
                  1    2    3    4
만 19세 미만    N/A    T    F    F
만 65세 이상    N/A    F    T    F
액션            N/A 학생 경로 일반
  실현 가능한 열 3개 / 전체 4개 → 100% 커버리지의 분모는 3

[예 2 · 요금 구분] 병합 후 — 열 3개 (조건 순서: 만 19세 미만, 만 65세 이상)
    F    T  →  경로
    F    F  →  일반
    T    F  →  학생

[조합 폭발] 조건 n개의 전체 결정 테이블 열 수 = 2^n
  n =  3 →         8 열
  n =  5 →        32 열
  n = 10 →     1,024 열
  n = 15 →    32,768 열
