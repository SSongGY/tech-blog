# 예제 코드 — BM25 항 가중치의 성질 검산

Robertson & Zaragoza(2009)의 식 (3.3)·(3.12)·(3.15)를 그대로 옮겨, 본문에서 주장하는
세 가지를 직접 계산해 확인한다.

- tf 가 아무리 커져도 항 가중치가 `w_IDF` 를 넘지 못한다 (포화)
- `k1` 이 포화가 시작되는 속도를 정한다
- `b` 가 문서 길이를 얼마나 반영할지 정한다

덤으로 `n_i` 가 말뭉치의 절반을 넘을 때 IDF 부호가 뒤집히는 지점도 같이 찍는다.

## 요구 사항

- Python 3.9 이상 (표준 라이브러리만 사용, 추가 설치 없음)

## 실행

```bash
python bm25_probe.py
```

## 출력 구성

| 섹션 | 내용 |
|---|---|
| `[1]` | tf 를 1에서 10,000까지 키우며 포화 한계와 선형 `tf*idf` 를 나란히 비교 |
| `[2]` | `k1` 을 0부터 10까지 바꿔 포화 한계 대비 비율을 표시 |
| `[3]` | 문서 길이를 avdl의 0.1배~10배로 바꿔가며 `b` 네 값의 차이를 비교 |
| `[4]` | `n_i` 를 키우며 IDF 부호가 뒤집히는 지점 확인 |

## 계산 조건

- 말뭉치 크기 `COLLECTION_SIZE = 1,000,000`, 평균 문서 길이 `AVG_DOC_LENGTH = 300`
- 기본 매개변수는 `K1_DEFAULT = 1.2`, `B_DEFAULT = 0.75`
- 관련성 판정이 없다고 가정하므로 RSJ 가중치는 IDF 형태(식 3.3)로 환원된다
- 난수를 쓰지 않으므로 몇 번을 돌려도 같은 값이 나온다

## 값을 바꿔가며 확인할 것

- `K1_DEFAULT = 0.0` 으로 두면 tf 가 1이든 100이든 가중치가 같아진다 — 사실상 불리언 검색이다
- `B_DEFAULT = 0.0` 으로 두면 `[3]` 표의 모든 열이 같은 값이 된다
- `TERMS` 의 문서 빈도를 `500001` 이상으로 올리면 그 항의 가중치가 음수가 된다
