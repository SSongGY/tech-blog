# 예제 코드 — 결함 제거 효율(DRE) 검산

Capers Jones, *Software Defect Removal Efficiency*(2011)의 표 1(결함 출처별 잠재량과 DRE, 미국 평균 근사치)을
그대로 옮겨, 출처별 전달 결함과 전체 DRE를 다시 계산한다. 표가 반올림해 적은 합계와 맞는지,
전달 결함이 어느 출처에서 오는지, 한 출처의 DRE만 올리면 전체가 얼마나 바뀌는지를 본다.
외부 의존성 없이 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python dre_check.py
```

## 바꿔볼 값

- `DEFECT_ORIGINS`의 출처별 DRE를 자기 조직의 값으로 바꿔 전체 DRE와 전달 결함의 출처 비중을 본다.
- 5·6번의 개선 목표치(99%, 95%)를 바꿔 어느 출처를 올리는 편이 전체 DRE를 더 움직이는지 비교한다.
