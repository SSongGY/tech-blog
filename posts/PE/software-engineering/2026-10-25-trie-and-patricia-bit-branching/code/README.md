# 트라이와 경로 압축 트라이의 구조 검산

의존성 없이 표준 라이브러리(`ipaddress`, `random`)만 쓴다. Python 3.13.5 에서 확인했다.

## 실행

```bash
python trie_properties.py
```

## 무엇을 확인하는가

| 번호 | 확인 대상 | 근거 문헌의 주장 |
|---|---|---|
| 1 | 경로 압축 전후의 노드 수·깊이 | 자식이 하나뿐인 내부 노드를 없애 깊이를 줄인다 (Morrison 1968) |
| 2 | 잎 n개짜리 압축 트라이의 노드 수 | 정확히 2n-1 개 (Nilsson·Karlsson 1998) |
| 3 | 삽입 순서를 바꿨을 때의 모양 | 키 집합만으로 모양이 정해진다 |
| 4 | 압축 트라이의 최장 접두사 일치 | 전수 비교 결과와 같아야 한다 |

4번이 불일치를 하나라도 내면 종료 코드 1 로 끝난다.
