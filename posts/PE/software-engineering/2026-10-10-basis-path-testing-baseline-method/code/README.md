# 기본 경로 테스트 4단계

NIST SP 500-235 의 예제 모듈 `count`(5.4절)를 파이썬으로 옮겨 기본 경로 테스트를
처음부터 끝까지 따라간다. 외부 의존성은 없다.

- `[1]` 제어 흐름 그래프 (노드와 간선)
- `[2]` V(G) 를 두 방법으로 계산하고, 가능한 경로 전체의 랭크와 비교
- `[3]` 기준 경로 방법으로 기본 경로 선택 (기준 입력 `AB`)
- `[4]` 각 경로의 기대 출력과 실제 출력 비교
- `[5]` 분기 커버리지를 채우는 2개짜리 테스트의 경로 랭크
- `[6]` 기능 테스트를 기본 경로로 채우기 (랭크를 올리는 경로만 추가)
- `[7]` 분기 커버리지 집합과 기본 경로 집합의 결함 검출 비교 (전수)
- `[8]` 실행 불가능한 경로 때문에 랭크가 V(G) 에 못 미치는 모듈과 고친 모듈

## 실행

```bash
python basis_path.py
```
