# 기능점수와 COCOMO — 계산 검산

글에 실은 숫자를 직접 계산한다. 표준 라이브러리만 쓴다.

## 실행

```bash
python cost_estimation.py
```

## 무엇을 계산하는가

| 절 | 내용 | 근거 |
|---|---|---|
| 1 | 같은 가상 시스템을 간이법·정통법으로 세어 기능점수 차이를 본다 | 대가산정 가이드 표 3-8·3-12·3-13·3-18 |
| 2 | 규모 보정계수 곡선과 그 최소점, 500FP 하한값 검산 | 같은 가이드의 규모 보정계수 식 |
| 3 | COCOMO 81 기본형 세 모드의 노력·기간·KLOC당 노력 | Boehm(1981) 기본형 계수 |

## 바꿔 볼 값

- `SYSTEM` 의 복잡도 분포를 바꿔 본다. 높음이 많아질수록 정통법이 간이법을 넘어선다.
- `size_factor` 의 500FP 하한을 지워 보면 그 아래에서 계수가 계속 올라간다.
- `COCOMO81` 의 지수 `b` 를 1.0으로 바꾸면 KLOC당 노력이 규모와 무관해진다.
