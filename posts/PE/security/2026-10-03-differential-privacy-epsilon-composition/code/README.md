# 예제 코드 — 라플라스 메커니즘으로 본 ε과 누적 손실

본문이 주장하는 네 가지를 계산해 확인한다. 식은 NIST SP 800-226 부록 B.2와
2.2절을 그대로 옮겼다.

- ε이 작아지면 잡음 척도 `b = Δ/ε`가 커지고 오차 폭이 그만큼 넓어진다
- 이웃 데이터셋에서 같은 출력이 나올 확률밀도의 비는 어디서나 `e^ε`을 넘지 않는다
- 같은 데이터에 대한 분석의 ε은 더해진다. 작은 ε도 반복되면 커진다
- 사람 단위 보호를 위해 기여 건수를 `k`로 묶으면 민감도와 잡음이 `k`배가 된다

## 요구 사항

- Python 3.9 이상 (표준 라이브러리만 사용, 추가 설치 없음)

## 실행

```bash
python dp_laplace.py
```

## 출력 구성

| 섹션 | 내용 |
|---|---|
| `[1]` | ε별 척도 `b`, 이론 95% 오차 폭, 20,000회 표집으로 잰 실제 포함 비율 |
| `[2]` | 632명·633명 데이터셋에서 같은 출력의 확률밀도와 그 비 |
| `[3]` | 순차 합성으로 총 ε이 쌓이는 세 가지 경우 |
| `[4]` | 사람당 기여 상한 `k`에 따른 민감도·척도·오차 폭 |
| `[5]` | 총 ε=1을 질의 `m`개에 나눠 쓸 때 질의당 오차 폭 |

## 계산 조건

- 난수 씨앗 `SEED = 20261003` 고정. 몇 번을 돌려도 같은 값이 나온다
- 개수 질의의 민감도는 1이다. 한 사람을 넣거나 빼는 이웃 정의(unbounded DP)에서
  개수는 최대 1 바뀐다 (NIST SP 800-226 부록 B.3)
- 라플라스 잡음은 같은 척도의 지수분포 두 개의 차로 만든다
- 95% 오차 폭은 `P(|X| > t) = exp(-t/b)`를 0.05로 두고 푼 `t = b·ln 20`이다
