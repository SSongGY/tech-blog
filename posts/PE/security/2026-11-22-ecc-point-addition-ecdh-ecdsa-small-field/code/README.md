# 예제 코드 — 타원곡선 암호를 작은 소수체에서 계산하기

파이썬 표준 라이브러리만 쓴다(`pow(a, -1, m)` 은 Python 3.8 이상).
**학습용이다.** 점이 19개뿐인 곡선이라 실습 [8]처럼 전수 조사로 바로 깨지고,
k 를 고정값으로 넣으므로 실제 서명에 쓰면 안 된다.

## 실행

```bash
python ecc_by_hand.py
```

## 바꿔 볼 값

- `Curve(17, 2, 2)` 를 `Curve(17, 0, 0)` 으로 바꾸면 판별식이 0 이라 `ValueError` 가 난다
- `[7]` 에서 두 번째 서명의 `k` 를 `11` 로 바꾸면 r 이 달라져 개인키 복원 식이 성립하지 않는다
- `[9]` 의 P-256 계산은 순수 파이썬이라 느리다. 실제 구현은 사영 좌표와 고정 시간 연산을 쓴다
