# 가명처리용 암호 기법 3종 검산

본문 "계산으로 확인한 것"의 근거다. 외부 의존성은 없고 키와 난수 시드를 고정했다.
환자·카드번호·급여 데이터는 전부 지어낸 것이다. 구현은 성질을 보이기 위한 학습용이며,
형태보존 암호는 NIST FF1의 뼈대만 흉내 낸 것이라 표준 FF1이 아니다.

- `[1]` 순서보존 암호: 키 없이 범위 질의가 되는지, 조밀한 열과 희소한 열에서 정렬 공격이 얼마나 복원하는지,
  희소한 열에서도 암호문 값으로 평문을 어림할 수 있는지
- `[2]` 형태보존 암호: 자리 수·문자 종류가 유지되는지, 같은 값이 같은 암호문이 되는지, 정의역이 작을 때
- `[3]` 동형 암호(Paillier): 암호문 상태의 덧셈·상수배, 같은 값의 암호문이 달라지는지, 암호문 비교가 뜻이 없는지
