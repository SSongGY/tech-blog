[1] 키 생성 p=61, q=53, e=17
  n = 3233, φ(n) = 3120, λ(n) = lcm(60, 52) = 780
  gcd(e, λ(n)) = 1
  d (φ 기준) = 2753   e*d mod φ = 1
  d (λ 기준) = 413    e*d mod λ = 1
  d_φ - d_λ = 2340 = 3 × λ(n)

[2] RSAEP m=65 -> c = m^e mod n = 2790
  RSADP d_φ: c^2753 mod n = 65
  RSADP d_λ: c^413 mod n = 65
  0..n-1 전부 d_λ 로 복호되는가: True

[3] CRT 복호 (RFC 8017 §5.1.2 단계 2b)
  dP = d mod (p-1) = 53, dQ = d mod (q-1) = 49, qInv = q^-1 mod p = 38
  m_1 = c^dP mod p = 4, m_2 = c^dQ mod q = 12
  h = (m_1 - m_2) * qInv mod p = 1
  m = m_2 + q*h = 65

[4] 서명 RSASP1 s = 123^d mod n = 2746
  검증 RSAVP1 s^e mod n = 123  (위조 s+1 -> 837)

[5] 범위 검사가 없으면
  m=65 의 암호문 2790, m+n=3298 의 암호문 2790
  3298 을 복호하면 65

[6] 교과서 RSA 의 성질
  같은 m=65 를 두 번 암호화: 2790, 2790
  0 과 1 의 암호문: 0, 1 -> 가로챈 1 는 1
  E(7)*E(9) mod n = 3216, E(63) = 3216
  개인키 없이 만든 그 암호문을 복호하면 63
