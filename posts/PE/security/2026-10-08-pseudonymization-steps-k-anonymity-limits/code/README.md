# 예제 코드 — k-익명성·ℓ-다양성·t-근접성 계산

가상 의료 기록 12건과 가상 급여 기록 9건으로 프라이버시 보호 모델 세 가지를 직접 계산한다.
연결 공격, k-익명성을 만족해도 드러나는 동질성·배경지식 공격, 같은 사람들을 두 번 공개할 때의
합성 공격, ℓ-다양성을 채워도 남는 유사성 문제, 그리고 t-근접성(EMD)을 맞추도록 다시 묶은 결과를
차례로 찍는다. 데이터와 이름은 전부 지어낸 것이다. 분수는 `fractions`로 정확히 계산한다.

## 실행

```bash
python privacy_models.py
```

## 바꿔볼 값

- `SALARY`의 급여를 한 동질 집합에 몰리게 바꾸고 `t(급여)`가 얼마나 커지는지 본다.
- 4번의 일반화 B에서 나이 구간을 10년으로 줄이면 합성 공격으로 좁혀지는 사람이 늘어나는지 본다.
- `equal_emd` 대신 질병을 소화기·호흡기로 묶은 계층 거리를 구현해 유사성 문제가 숫자에 잡히는지 본다.
