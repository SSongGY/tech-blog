== 1. 이름을 지워도 준식별자로 다시 붙는다 (연결 공격) ==
   (우편번호, 나이, 성별) 조합이 유일한 행: 12 / 12
   명부의 나래(30125, 27, 여) -> 기록 2번 -> 고혈압
   명부의 자람(30125, 33, 남) -> 기록 9번 -> 위암
   명부 이름과 1:1로 이어진 기록: 12 / 12

== 2. 일반화 A — 우편번호 앞 3자리, 나이 구간, 성별 삭제 ==

-- 동질 집합
   ('301**', '20대')  행 1,2,3,4    크기 4  ℓ=2  민감정보 ['전립선비대증', '고혈압', '전립선비대증', '고혈압']
   ('305**', '40~59')  행 5,6,7,8    크기 4  ℓ=4  민감정보 ['당뇨', '독감', '기관지염', '갑상선염']
   ('301**', '30대')  행 9,10,11,12 크기 4  ℓ=1  민감정보 ['위암', '위암', '위암', '위암']
   => k = 4
   공개 명부로 다시 붙이면 각 이름이 4행 중 하나로만 좁혀진다 (재식별 확률 1/4)

== 3. k=4 인데도 드러나는 것 ==
   동질성 공격: 자람(30125, 33, 남)은 ('301**', '30대') 집합 -> 질병 ['위암']
   배경지식 공격: 나래(30125, 27, 여)는 ('301**', '20대') 집합 -> 후보 ['고혈압', '전립선비대증']
                  '전립선비대증은 여성에게 없다'를 알면 -> 고혈압

== 4. 두 번 공개하면 (합성 공격) ==

-- 일반화 B — 성별 유지, 나이 20년 구간, 우편번호 삭제
   ('남', '20~39')  행 1,3,4,9,11 크기 5  ℓ=3  민감정보 ['전립선비대증', '전립선비대증', '고혈압', '위암', '위암']
   ('여', '20~39')  행 2,10,12    크기 3  ℓ=2  민감정보 ['고혈압', '위암', '위암']
   ('여', '40~59')  행 5,7        크기 2  ℓ=2  민감정보 ['당뇨', '기관지염']
   ('남', '40~59')  행 6,8        크기 2  ℓ=2  민감정보 ['독감', '갑상선염']
   => k = 2
   A 와 B 의 후보 질병 교집합이 1개로 좁혀지는 사람: 5 / 12
   [(2, '고혈압'), (9, '위암'), (10, '위암'), (11, '위암'), (12, '위암')]

== 5. ℓ-다양성을 채워도 남는 것 (유사성·쏠림) ==

-- 일반화 C — 우편번호 앞 3자리, 나이 구간
   ('476**', '20대')  행 1,2,3      크기 3  ℓ=3  민감정보 ['위궤양', '역류성식도염', '위염']
   ('479**', '40~59')  행 4,5,6      크기 3  ℓ=3  민감정보 ['위염', '독감', '기관지염']
   ('476**', '30대')  행 7,8,9      크기 3  ℓ=3  민감정보 ['기관지염', '폐렴', '위염']
   => k = 3
   ('476**', '20대')  급여 [30, 40, 50]  t(급여)=0.375  t(질병, 동일거리)=0.444
   ('479**', '40~59')  급여 [60, 80, 110]  t(급여)=0.167  t(질병, 동일거리)=0.333
   ('476**', '30대')  급여 [70, 90, 100]  t(급여)=0.236  t(질병, 동일거리)=0.333

== 6. t-근접성을 맞추도록 다시 묶는다 ==

-- 일반화 D — 우편번호 앞 4자리, 나이 40 기준
   ('4767*', '≤40')  행 1,3,8      크기 3  ℓ=3  민감정보 ['위궤양', '위염', '폐렴']
   ('4760*', '≤40')  행 2,7,9      크기 3  ℓ=3  민감정보 ['역류성식도염', '기관지염', '위염']
   ('4790*', '>40')  행 4,5,6      크기 3  ℓ=3  민감정보 ['위염', '독감', '기관지염']
   => k = 3
   ('4767*', '≤40')  급여 [30, 50, 90]  t(급여)=0.167  t(질병, 동일거리)=0.444
   ('4760*', '≤40')  급여 [40, 70, 100]  t(급여)=0.083  t(질병, 동일거리)=0.333
   ('4790*', '>40')  급여 [60, 80, 110]  t(급여)=0.167  t(질병, 동일거리)=0.333
   => 급여 기준 최대 t = 0.167 (1/6)

== 7. 검산 — 두 동질 집합을 합치면 t 는 커지지 않는다 (Li 외 2007, Fact 2) ==
   t1=0.375  t2=0.236  합친 집합 t=0.083  <= max(t1, t2): True
