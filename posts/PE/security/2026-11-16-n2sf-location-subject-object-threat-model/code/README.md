# N2SF 보안원칙 검산

국가 망 보안체계(N2SF) 가이드라인 1.0 부록2의 두 정보서비스 모델에서, 「정보 생산·저장」과
「정보 이동」 원칙을 규칙으로 옮겨 계산한 판정이 문서의 판정과 같은지 대조한다.
표준 라이브러리만 쓴다.

## 실행

```bash
python n2sf_principles.py
```

## 바꿔 볼 값

- `MODEL_2["grades"]` 의 객체 등급을 `"S"` 로 바꾸면(기관 내부에 둔 AI) 위배 판정이 사라지는지 본다
- 새 모델을 같은 꼴로 추가해, 위치·주체·객체 등급과 정보 흐름을 넣고 위배 지점을 뽑아 본다
