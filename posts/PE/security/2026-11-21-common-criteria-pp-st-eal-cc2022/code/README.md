# 예제 코드 — CC(공통평가기준) — PP·ST·EAL과 CC:2022에서 달라진 것

CC:2022 Release 1 Part 5 의 EAL 요약표(Table 1)와 등급별 표(Table 2~8), ST 평가 패키지(Table 18·19)를
파이썬 자료로 옮겨 등급 사이의 차이를 계산한다. 표준 라이브러리만 쓴다.

## 실행

```bash
python eal_matrix.py
```

## 바꿔 볼 값

- `EAL_SUMMARY` 의 숫자 하나를 바꾸면 `[1]` 의 대조가 어느 등급에서 어긋나는지 보인다 — 옮겨 적기 실수를 잡는 장치다
- `[3]` 의 결과를 Part 5 §4.4 의 각 EAL "이전 등급보다 의미 있게 늘어난 것" 문장과 맞춰 본다
