[선형 경로] 활성 S-box 4개 — (입력 마스크, 출력 마스크) → 편향
  (B,4) → 1/4
  (4,5) → -1/4
  (4,5) → -1/4
  (4,5) → -1/4
  적층 보조정리 2^(4-1) × Π ε = -1/32
  필요한 기지 평문 N_L ≈ 1/ε² = 1024

[차분 특성] 활성 S-box 4개 — (ΔX, ΔY) → 확률
  (B,2) → 1/2
  (4,6) → 3/8
  (2,5) → 3/8
  (2,5) → 3/8
  특성 확률 p_D = Π β = 27/1024  (= 0.02637)
  필요한 선택 평문 쌍 N_D ≈ c/p_D = c × 37.9
