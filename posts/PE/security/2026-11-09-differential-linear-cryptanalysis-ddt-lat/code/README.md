# 예제 코드 — 차분 분포표와 선형 근사표

표준 라이브러리만 쓴다. Heys 튜토리얼 Table 1 의 4비트 S-box(DES 첫 S-box 의 첫 행)로
차분 분포표(DDT)와 선형 근사표(LAT)를 전부 계산하고, 튜토리얼이 적은 3라운드 경로의
편향(-1/32)과 차분 특성 확률(27/1024)을 같은 표에서 다시 구해 맞춰 본다.
비교용 아핀 S-box 는 비선형성이 없을 때 두 표가 어떻게 되는지 보인다.

## 실행

```bash
python sbox_tables.py
```

## 파일

| 파일 | 무엇 |
|---|---|
| `sbox_tables.py` | 본문 출력을 내는 스크립트 |
| `output.txt` | `blog.py run-example` 이 남긴 수행 기록 |

## 바꿔볼 값

- `HEYS_SBOX` — 다른 4비트 S-box 를 넣으면 차분 균일도와 최대 편향이 바로 나온다
- `path`, `char` — 활성 S-box 를 늘리면 편향과 특성 확률이 곱으로 줄어드는 것을 본다

암호를 깨는 코드가 아니다. S-box 한 개의 통계표를 세는 것까지만 한다.
