# 예제 코드 — SLA 지표 설계와 측정

본문에 실린 숫자를 전부 계산한다. 표준 라이브러리만 쓴다.

## 실행

```bash
python sla_math.py
```

## 바꿔볼 값

| 자리 | 기본값 | 바꾸면 |
|---|---|---|
| `LEVELS` | 99.0 ~ 99.999 | 협약에 적을 후보 수준을 넣어 허용 중단 시간을 본다 |
| `peak_share_per_minute` | 0.0025 | 요청 분포 가정이다. 트래픽이 더 몰릴수록 요청 기준 가용률이 더 떨어진다 |
| `tiers` | 웹·WAS·DB·결제 | 실제 구성 구간을 넣으면 그 구성의 복합 가용률 상한이 나온다 |
| `slo` (5절) | 99.9 | 목표를 올리면 월 오차 예산이 급격히 줄어드는 폭을 본다 |

4절의 응답시간 표본은 `random.Random(20261020)` 으로 시드를 고정했다. 분포 모양은
가정이고(로그정규 + 2% 꼬리), 평균과 백분위 값은 그 표본에서 실제로 계산한 값이다.
