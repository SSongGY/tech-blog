# 예제 코드 — IT 투자 평가, TCO와 ROI

가상 사업의 5년치 비용·편익을 놓고 TCO, 단순 ROI, 할인 순편익, 편익비용비,
회수기간을 직접 계산한다. 외부 통계를 인용하지 않고 글 안의 숫자만으로 재현된다.

할인계수는 OMB Circular A-94 부록 B의 정의 `1/(1+r)^t` 를 그대로 쓴다.

## 실행

```bash
python tco_roi.py
```

## 바꿔볼 값

- `ALTERNATIVES` 의 `hidden` 을 전부 0으로 두면 1번 절에서 순위가 뒤집히지 않는다.
  숨은 비용이 얼마나 커야 판단이 바뀌는지를 역으로 찾아볼 수 있다.
- `part2` 의 할인율 목록에 더 높은 값을 넣으면 초기 투자형 대안이 얼마나 더
  불리해지는지 보인다.
- `ROI_CASES` 의 `benefits` 배열에서 750을 거두는 연차만 옮기면, 총액이 같아도
  할인 순편익이 어떻게 달라지는지 확인된다.
