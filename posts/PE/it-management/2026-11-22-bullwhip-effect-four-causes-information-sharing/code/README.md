## 무엇을 확인하나

1. Lee·Padmanabhan·Whang(1997) 정리 1 — AR(1) 수요에 최적 주문 식 (3.3) 을 적용했을 때 주문 분산이 식 (3.5) 와 맞는지
2. 같은 논문 정리 3 — 무작위·동조·균형 주문의 공급자 측 분산이 식 (3.11)~(3.13) 과 맞는지
3. 논문 밖 확장 — 같은 주문 규칙을 4단계에 이어 붙였을 때, 주문만 보는 경우와 POS 를 공유받는 경우의 단계별 분산 배율

## 바꿔 볼 값

- `check_theorem1` 의 `rho` 를 음수(예: -0.5)로 바꾸면 정리 1 의 조건(0 < ρ < 1)을 벗어난다. 이때 배율이 1 보다 작아지는지 본다
- `check_theorem3` 의 `retailers` 를 25(= 5 × 5)로 바꾸면 k = 0 이 되어 균형 주문의 분산이 Nσ² 와 같아진다
- `check_multistage` 의 `lead_time` 을 키우면 계수 k 가 커져 단계별 증폭이 더 빨라진다
