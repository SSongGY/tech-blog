# 정성 분석과 정량 분석 대조 계산

같은 위험 다섯 건을 두 방식으로 평가해 순위가 어긋나는 자리를 찾고, 통제안의
비용 대비 효과를 계산한다. 표에 들어가는 숫자는 **설명을 위해 만든 가상의 입력값**
이며 어떤 조직의 실측치도 아니다.

## 실행

```bash
python risk_analysis.py
```

표준 라이브러리만 쓴다. 추가 설치가 없다.

## 바꿔 볼 값

- `RISKS` 의 `annual_rate` 를 올리면 정량 순위가 바뀐다. "개인정보 유출" 의
  `0.05` 를 `0.5` 로 올려 보면 1회 손실액이 큰 위험이 어떻게 치고 올라오는지 보인다.
- `likelihood_level`·`impact_level` 을 바꿔 정성 점수가 같아지는 묶음을 만들면
  3번 절이 "순위를 가를 수 없는 묶음"으로 잡아낸다.
- `CONTROLS` 의 `annual_cost` 를 올려 순효과를 음수로 만들어 본다.
