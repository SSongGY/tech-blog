# 예제 코드 — Tibero 7 딕셔너리 뷰

**아직 실행하지 않았다.** 글을 쓴 시점에 검증용 인스턴스에 접속할 수 없었다(`TBR-2131`).
인스턴스가 살아나면 이 스크립트를 돌려 출력을 채우고 글을 `executed`로 올린다.

빈 스키마에 표 하나(`dv_member`)와 인덱스·제약·주석만 만들고, 사전 뷰로 그것들을 찾아본 뒤
표를 지우고 `user_objects`가 0개인지 찍는다. 다른 객체는 조회하지 않는다.
단, 10번(`ALL_`·`DBA_` 건수)과 11번(`V$SESSION` 건수)은 개수만 센다.

## 실행

```bash
tbsql -s <사용자>/<암호> @dictionary_views.sql
```

tbsql 스크립트 모드에서는 문장 뒤 같은 줄에 `--` 주석을 달면 다음 문장이 깨지므로 설명은 `PROMPT`로 적었다.
파일 끝의 `EXIT`가 없으면 프롬프트에서 대기한다.

## 확인할 것

- 2번 `DESC dictionary` — 컬럼 이름. 글에는 매뉴얼이 적은 설명("데이터 사전에 있는 테이블 및 뷰에 대한 주석")만 실었다.
- 8번 — 소문자 `'dv_member'`로 찾으면 0건이 나오는가.
- 9번 — 매뉴얼 목록의 `USER_TBL_COLUMNS`·`USER_IDX_COLUMNS` 대신 Oracle 식 이름 `USER_TAB_COLUMNS`·`USER_IND_COLUMNS`도 받는가.
- 10번 — 일반 사용자로 `DBA_TABLES`를 조회하면 권한 오류가 나는가.
- 11번 — 일반 사용자로 `V$SESSION`을 조회하면 권한 오류가 나는가(매뉴얼: 대부분의 동적 뷰는 DBA 권한 필요).
