# 예제 코드 — Tibero 7 날짜·시간 타입

**아직 실행하지 않았다.** 글을 쓴 시점에 검증용 인스턴스에 접속할 수 없었다(`TBR-2131`).
인스턴스가 살아나면 이 스크립트를 돌려 출력을 채우고 글을 `executed`로 올린다.

빈 스키마에 표 하나(`dt_sample`)만 만든다. `DATE`, 정밀도가 다른 `TIMESTAMP` 세 개, 시간대형 두 개,
간격형 두 개를 두고 같은 값을 넣어 무엇이 남는지 본다. 넣은 행은 `ROLLBACK`으로 되돌리고,
마지막에 표를 지운 뒤 `user_objects`가 0개인지 찍는다. 다른 객체는 조회하지 않는다.

## 실행

```bash
tbsql -s <사용자>/<암호> @datetime_types.sql
```

tbsql 스크립트 모드에서는 문장 뒤 같은 줄에 `--` 주석을 달면 다음 문장이 깨지므로 설명은 `PROMPT`로 적었다.
파일 끝의 `EXIT`가 없으면 프롬프트에서 대기한다.

## 확인할 것

매뉴얼에 적혀 있지 않아 글에서 단정하지 않은 항목이다.

- 2번·3번 — `TIMESTAMP` 값을 `DATE`·`TIMESTAMP(0)`에 넣을 때 소수 초를 버리는지 반올림하는지.
  `23:59:59.5`가 다음 날로 넘어가는지 본다.
- 4번·5번 — 세션 시간대를 `+00:00`으로 바꾸면 `WITH TIME ZONE` 값은 그대로이고
  `WITH LOCAL TIME ZONE` 값만 바뀌는지. `ALTER SESSION SET TIME_ZONE` 문법이 이대로 되는지도 본다.
- 6번 — 같은 순간을 다른 시간대로 적은 두 값이 `=`로 같다고 나오는지.
- 7번·8번 — `DATE + 1`, `DATE - DATE`, `TIMESTAMP - TIMESTAMP`, `TIMESTAMP + 1`의 결과 타입과 값.
  공개 매뉴얼에서 이 연산 규칙을 찾지 못했다.
- 9번 — `DAY` 정밀도 기본값 2를 넘는 `INTERVAL '123 …'`가 `DAY(3)`로 넣을 때 되는지, 컬럼(기본 2)에는 왜 안 되는지.
- 10번 — 1월 31일에 한 달을 더할 때 `ADD_MONTHS`와 `+ INTERVAL '1' MONTH`가 각각 무엇을 내는지.
- 12번 — 시각이 든 `DATE` 행이 `= DATE '2026-10-07'`에 걸리지 않고 반열린 구간에는 걸리는지.
