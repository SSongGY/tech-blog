# 숫자가 섞인 문자열 정렬

파일 이름·번호·버전 문자열을 SQLite 에서 정렬해 보고, 숫자 크기대로 정렬하는 방법을 비교한다.
표준 라이브러리만 쓴다.

## 실행

```bash
python natural_sort.py
```

## 바꿔 볼 값

- `scan_file` 에 `IMG5` 처럼 대문자 접두어를 넣으면 접두어 정렬이 대소문자에서 갈린다. `COLLATE NOCASE` 를 붙여 비교해 본다
- `app_release` 에 `1.10` 처럼 토막이 둘뿐인 값을 넣으면 `patch` 가 무엇이 되는지 본다
- `[8]` 의 마지막 질의에서 `'9876543210'` 을 `'0123456789'` 로 되돌리면 정렬 단계가 다시 사라진다
