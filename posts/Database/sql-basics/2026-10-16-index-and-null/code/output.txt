================================================================
1. IS NULL 은 인덱스를 타는가 — 그리고 = NULL 과 무엇이 다른가
================================================================
  SELECT id FROM employee WHERE manager_id IS NULL
    계획 : SEARCH employee USING COVERING INDEX idx_mgr (manager_id=?)
    건수 : 80
  SELECT id FROM employee WHERE manager_id = NULL
    계획 : SEARCH employee USING COVERING INDEX idx_mgr (manager_id=?)
    건수 : 0
  SELECT id FROM employee WHERE manager_id IS NOT NULL
    계획 : SEARCH employee USING COVERING INDEX idx_mgr (manager_id>?)
    건수 : 20
  SELECT id FROM employee WHERE manager_id <> 3
    계획 : SCAN employee USING COVERING INDEX idx_mgr
    건수 : 19
  SELECT id FROM employee WHERE manager_id IS NOT 3
    계획 : SCAN employee USING COVERING INDEX idx_mgr
    건수 : 99

================================================================
2. 정렬에서 NULL 이 놓이는 자리
================================================================
  SELECT manager_id FROM employee ORDER BY manager_id LIMIT 6
    계획 : SCAN employee USING COVERING INDEX idx_mgr
    결과 : [None, None, None, None, None, None]
  SELECT manager_id FROM employee ORDER BY manager_id NULLS LAST LIMIT 6
    계획 : SCAN employee USING COVERING INDEX idx_mgr
    결과 : [1, 2, 3, 4, 5, 6]
  SELECT manager_id FROM employee ORDER BY manager_id DESC LIMIT 6
    계획 : SCAN employee USING COVERING INDEX idx_mgr
    결과 : [20, 19, 18, 17, 16, 15]
  SELECT manager_id FROM employee ORDER BY manager_id DESC NULLS FIRST LIMIT 6
    계획 : SCAN employee USING COVERING INDEX idx_mgr
    결과 : [None, None, None, None, None, None]

================================================================
3. UNIQUE 와 PRIMARY KEY 는 NULL 을 받는가
================================================================
  UNIQUE 컬럼에 NULL 세 번 삽입 : 3 행
  같은 값 두 번 삽입              : IntegrityError: UNIQUE constraint failed: member.email

  PK 가 TEXT · 일반 rowid 표 : NULL 두 번 통과 (2행)
  PK 가 TEXT · WITHOUT ROWID : NOT NULL constraint failed: t2.code
  PK 가 TEXT · STRICT        : NOT NULL constraint failed: t3.code
  PK 가 TEXT · NOT NULL 명시 : NOT NULL constraint failed: t4.code

================================================================
4. NOT IN 서브쿼리에 NULL 이 섞이면
================================================================
  SELECT count(*) FROM employee WHERE id NOT IN (SELECT manager_id FROM employee)
    결과 : 0건
  SELECT count(*) FROM employee WHERE id NOT IN (SELECT manager_id FROM employee WHERE manager_id IS NOT NULL)
    결과 : 80건
