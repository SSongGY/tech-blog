==============================================================
1. 지역별 합계 — 여기까지는 GROUP BY 한 줄이다
==============================================================
  부산        350
  서울        650
  화성        150

==============================================================
2. ROLLUP 은 SQLite 3.49.1 에 없다
==============================================================
  GROUP BY ROLLUP(region) → no such function: ROLLUP

==============================================================
3. UNION ALL 로 총계 행을 붙인다 — 그런데 줄이 중간에 낀다
==============================================================
  부산        350
  서울        650
  합계       1150
  화성        150
  → ORDER BY region 이 '합계' 도 지역 이름처럼 정렬했다

==============================================================
4. 정렬 키 컬럼을 따로 둔다
==============================================================
      0  부산        350
      0  서울        650
      0  화성        150
      1  합계       1150

==============================================================
5. 두 단계 — 지역×제품, 지역 소계, 총계를 한 결과에
==============================================================
  ORDER BY region IS NULL, ... → 1st ORDER BY term does not match any column in the result set
  → UNION 으로 묶인 질의의 ORDER BY 에는 식을 못 쓴다. 결과 컬럼만 가리킨다
  부산      노트북       250      0      0
  부산      모니터       100      0      0
  부산      NULL      350      1      0
  서울      노트북       500      0      0
  서울      모니터       150      0      0
  서울      NULL      650      1      0
  화성      모니터       120      0      0
  화성      키보드        30      0      0
  화성      NULL      150      1      0
  NULL    NULL     1150      2      1
  → NULL 이 '소계·총계' 표시다. 보일 때만 COALESCE(product, '소계') 로 바꾼다

==============================================================
6. 질의 계획 — UNION ALL 은 표를 읽는 횟수만큼 SCAN 이 찍힌다
==============================================================
QUERY PLAN
`--MERGE (UNION ALL)
   |--LEFT
   |  |--SCAN sale
   |  |--USE TEMP B-TREE FOR GROUP BY
   |  `--USE TEMP B-TREE FOR ORDER BY
   `--RIGHT
      `--SCAN sale

==============================================================
7. 집계를 CTE 에 한 번만 하고, 총계는 그 위에서 더한다
==============================================================
      0  부산        350
      0  서울        650
      0  화성        150
      1  합계       1150
QUERY PLAN
`--MERGE (UNION ALL)
   |--LEFT
   |  |--MATERIALIZE by_region
   |  |  |--SCAN sale
   |  |  `--USE TEMP B-TREE FOR GROUP BY
   |  |--SCAN by_region
   |  `--USE TEMP B-TREE FOR ORDER BY
   `--RIGHT
      `--SCAN by_region
  → 힌트를 안 붙여도 두 번 참조되는 CTE 는 MATERIALIZE 로 한 번만 읽었다
-- NOT MATERIALIZED 를 붙이면
QUERY PLAN
`--MERGE (UNION ALL)
   |--LEFT
   |  |--CO-ROUTINE by_region
   |  |  |--SCAN sale
   |  |  `--USE TEMP B-TREE FOR GROUP BY
   |  |--SCAN by_region
   |  `--USE TEMP B-TREE FOR ORDER BY
   `--RIGHT
      |--CO-ROUTINE by_region
      |  |--SCAN sale
      |  `--USE TEMP B-TREE FOR GROUP BY
      `--SCAN by_region

==============================================================
8. 행을 더하지 않고 칸을 더한다 — SUM() OVER ()
==============================================================
  부산        350   1150  30.4  
  서울        650   1150  56.5  
  화성        150   1150  13.0  
  → 집계 결과 위에 윈도우가 한 번 더 걸린다. 비율을 같은 줄에 적을 때 쓴다
