[exam_score]  5행
  컬럼        | 타입    | 제약
  ------------+---------+-----
  student     | TEXT    | PK
  mid_score   | INTEGER |
  final_score | INTEGER |

  student | mid_score | final_score
  --------+-----------+------------
  kim     |        70 |          85
  lee     |        90 |          60
  park    |      NULL |          75
  choi    |        80 |        NULL
  jung    |      NULL |        NULL

[product]  6행
  컬럼     | 타입    | 제약
  ---------+---------+---------
  id       | INTEGER | PK
  category | TEXT    | NOT NULL
  name     | TEXT    | NOT NULL
  price    | INTEGER | NOT NULL

  id | category | name   | price
  ---+----------+--------+------
   1 | fruit    | apple  |  1200
   2 | fruit    | mango  |  3500
   3 | fruit    | grape  |  2800
   4 | drink    | water  |   900
   5 | drink    | juice  |  2100
   6 | drink    | coffee |  2100

== 1) 인자 개수가 종류를 정한다 ==
  sql> SELECT max(final_score) FROM exam_score
  max(final_score)
  85

  sql> SELECT student, max(mid_score, final_score) FROM exam_score
  student | max(mid_score, final_score)
  'kim' | 85
  'lee' | 90
  'park' | NULL
  'choi' | NULL
  'jung' | NULL

== 2) NULL 을 다루는 방식이 반대다 ==
  sql> SELECT max(3, NULL, 7), min(3, NULL, 7)
  max(3, NULL, 7) | min(3, NULL, 7)
  NULL | NULL

  sql> SELECT max(mid_score), min(mid_score), count(mid_score) FROM exam_score
  max(mid_score) | min(mid_score) | count(mid_score)
  90 | 70 | 3

  sql> SELECT max(mid_score) FROM exam_score WHERE student = 'jung'
  max(mid_score)
  NULL

  sql> SELECT max(mid_score) FROM exam_score WHERE 0
  max(mid_score)
  NULL

== 3) 행마다 두 점수 중 높은 것 ==
  sql> SELECT student, max(mid_score, final_score) AS naive, max(coalesce(mid_score, final_score), coalesce(final_score, mid_score)) AS fixed FROM exam_score
  student | naive | fixed
  'kim' | 85 | 85
  'lee' | 90 | 90
  'park' | NULL | 75
  'choi' | NULL | 80
  'jung' | NULL | NULL

== 4) 타입이 섞이면 ==
  sql> SELECT max('10', 99), typeof(max('10', 99))
  max('10', 99) | typeof(max('10', 99))
  '10' | 'text'

  sql> SELECT max(CAST('10' AS INTEGER), 99)
  max(CAST('10' AS INTEGER), 99)
  99

== 5) MAX 와 같이 쓴 묶지 않은 컬럼 ==
  sql> SELECT student, max(mid_score) FROM exam_score
  student | max(mid_score)
  'lee' | 90

  sql> SELECT name, max(price) FROM product
  name | max(price)
  'mango' | 3500

  sql> SELECT category, name, max(price) FROM product GROUP BY category
  category | name | max(price)
  'drink' | 'juice' | 2100
  'fruit' | 'mango' | 3500

  sql> SELECT name, max(price), min(price) FROM product
  name | max(price) | min(price)
  'water' | 3500 | 900

  sql> SELECT name, avg(price) FROM product
  name | avg(price)
  'apple' | 2100.0
