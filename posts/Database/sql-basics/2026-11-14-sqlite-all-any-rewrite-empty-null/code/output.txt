  -----------+----------+------
           1 | pen      |  1000
           2 | pen      |  1300
           3 | note     |  2500
           4 | ink      |  5000

[rival_offer]  4행
  컬럼     | 타입    | 제약
  ---------+---------+---------
  offer_id | INTEGER | PK
  category | TEXT    | NOT NULL
  price    | INTEGER |

  offer_id | category | price
  ---------+----------+------
         1 | pen      |  1200
         2 | pen      |  1500
         3 | note     |  3000
         4 | note     |  NULL

[1] ALL·ANY 구문을 그대로 쓰면
  sql> SELECT product_id FROM product AS p WHERE p.price < ALL (SELECT r.price FROM rival_offer AS r WHERE r.category = p.category)
  OperationalError: near "ALL": syntax error

  sql> SELECT product_id FROM product AS p WHERE p.price > ANY (SELECT r.price FROM rival_offer AS r WHERE r.category = p.category)
  OperationalError: near "SELECT": syntax error

[1] 오류 위치가 다른 이유 — ALL 은 키워드, ANY 는 이름으로 읽힌다
  sql> SELECT 1 AS any
  any
  1
  (1행)

  sql> SELECT 1 AS all
  OperationalError: near "all": syntax error

  sql> SELECT any(1)
  OperationalError: no such function: any

[2] 분류별 경쟁사 가격 — MIN 은 NULL 을 건너뛰고, 행이 없으면 NULL
  sql> SELECT p.category, (SELECT COUNT(*) FROM rival_offer r WHERE r.category = p.category) AS offer_rows, (SELECT COUNT(r.price) FROM rival_offer r WHERE r.category = p.category) AS priced_rows, (SELECT MIN(r.price) FROM rival_offer r WHERE r.category = p.category) AS min_price FROM (SELECT DISTINCT category FROM product) AS p ORDER BY p.category
  category | offer_rows | priced_rows | min_price
  ink | 0 | 0 | NULL
  note | 2 | 1 | 3000
  pen | 2 | 2 | 1200
  (3행)

[3-A] < ALL 을 MIN 비교로
  sql> SELECT product_id, category, price FROM product AS p WHERE p.price < (SELECT MIN(r.price) FROM rival_offer AS r WHERE r.category = p.category) ORDER BY product_id
  product_id | category | price
  1 | pen | 1000
  3 | note | 2500
  (2행)

[3-B] < ALL 을 NOT EXISTS 로 — '나보다 싸거나 같은 경쟁 가격이 없다'
  sql> SELECT product_id, category, price FROM product AS p WHERE NOT EXISTS (SELECT 1 FROM rival_offer AS r WHERE r.category = p.category AND r.price <= p.price) ORDER BY product_id
  product_id | category | price
  1 | pen | 1000
  3 | note | 2500
  4 | ink | 5000
  (3행)

[3-C] < ALL 을 표준 의미 그대로 — 참이 아닌 비교(거짓·NULL)가 하나도 없다
  sql> SELECT product_id, category, price FROM product AS p WHERE NOT EXISTS (SELECT 1 FROM rival_offer AS r WHERE r.category = p.category AND (p.price < r.price) IS NOT 1) ORDER BY product_id
  product_id | category | price
  1 | pen | 1000
  4 | ink | 5000
  (2행)

[4-A] > ANY 를 MIN 비교로 — 어느 한 경쟁 가격보다라도 비싼 상품
  sql> SELECT product_id FROM product AS p WHERE p.price > (SELECT MIN(r.price) FROM rival_offer AS r WHERE r.category = p.category) ORDER BY product_id
  product_id
  2
  (1행)

[4-B] > ANY 를 EXISTS 로
  sql> SELECT product_id FROM product AS p WHERE EXISTS (SELECT 1 FROM rival_offer AS r WHERE r.category = p.category AND p.price > r.price) ORDER BY product_id
  product_id
  2
  (1행)

[4-C] 두 형태에 NOT 을 씌우면 — NOT (> MIN)
  sql> SELECT product_id FROM product AS p WHERE NOT (p.price > (SELECT MIN(r.price) FROM rival_offer AS r WHERE r.category = p.category)) ORDER BY product_id
  product_id
  1
  3
  (2행)

[4-D] NOT EXISTS
  sql> SELECT product_id FROM product AS p WHERE NOT EXISTS (SELECT 1 FROM rival_offer AS r WHERE r.category = p.category AND p.price > r.price) ORDER BY product_id
  product_id
  1
  3
  4
  (3행)

[5] 상품마다 판정값 — 1 참, 0 거짓, NULL 모름
  sql> SELECT p.product_id, p.category, p.price, p.price < (SELECT MIN(r.price) FROM rival_offer r WHERE r.category = p.category) AS by_min, NOT EXISTS (SELECT 1 FROM rival_offer r WHERE r.category = p.category AND r.price <= p.price) AS by_not_exists, NOT EXISTS (SELECT 1 FROM rival_offer r WHERE r.category = p.category AND (p.price < r.price) IS NOT 1) AS by_strict FROM product AS p ORDER BY p.product_id
  product_id | category | price | by_min | by_not_exists | by_strict
  1 | pen | 1000 | 1 | 1 | 1
  2 | pen | 1300 | 0 | 0 | 0
  3 | note | 2500 | 1 | 1 | 0
  4 | ink | 5000 | NULL | 1 | 1
  (4행)
