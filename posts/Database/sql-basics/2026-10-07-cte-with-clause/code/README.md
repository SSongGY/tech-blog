# 예제 코드 — CTE(WITH 절)

메모리 SQLite에 영업 실적 8건을 넣고, "평균 지역 합계보다 많이 판 지역"을 중첩 서브쿼리와
CTE로 각각 구해 결과가 같은지 본다. 이어서 CTE를 이어 쓰기, 컬럼 이름 목록, 문장 범위,
테이블 이름 가리기, `MATERIALIZED` 힌트에 따른 실행계획 차이를 확인한다.
외부 의존성 없이 파이썬 표준 라이브러리만 쓴다. `dbshow.py`는 표 정의와 데이터를 찍는 도우미다.

## 실행

```bash
python cte_basics.py
```

## 바꿔볼 값

- 10번 질의의 `WHERE region = '서울'`을 `WHERE amount > 200`으로 바꾸면 인덱스가 없는 컬럼이라 두 계획이 어떻게 달라지는지 본다.
- 12번 질의에 `MATERIALIZED`와 `NOT MATERIALIZED`를 차례로 붙여 계획의 `MATERIALIZE` 줄 개수를 센다.
- `SALES`에 광주 실적 한 건(예: 600)을 더하면 3번 결과에서 어느 지역이 빠지는지 계산해 본 뒤 돌려 확인한다.
