1. 피연산자에 ORDER BY 나 LIMIT 을 적으면 파싱 단계에서 막힌다
================================================================
[왼쪽 SELECT 에 ORDER BY]
  SQL  : SELECT name, score FROM seoul ORDER BY score DESC
  SQL  : UNION ALL
  SQL  : SELECT name, score FROM busan
  에러 : OperationalError: ORDER BY clause should come after UNION ALL not before

[왼쪽 SELECT 에 LIMIT]
  SQL  : SELECT name, score FROM seoul LIMIT 2
  SQL  : UNION ALL
  SQL  : SELECT name, score FROM busan
  에러 : OperationalError: LIMIT clause should come after UNION ALL not before

================================================================
2. 맨 끝에 적은 ORDER BY·LIMIT 은 합쳐진 결과 전체에 걸린다
================================================================
[전체 정렬]

  SQL  : SELECT name, score FROM seoul
  SQL  : UNION ALL
  SQL  : SELECT name, score FROM busan
  SQL  : ORDER BY score DESC
  SQL  : LIMIT 2
  행   : 가은 | 90
  행   : 가은 | 90
  합계 : 2행

4. 합친 뒤의 ORDER BY 항은 출력 컬럼으로만 해석된다
================================================================
[출력 컬럼 번호]
  SQL  : SELECT name, score FROM seoul
  SQL  : UNION ALL
  SQL  : SELECT name, score FROM busan
  SQL  : ORDER BY 2 DESC
  행   : 가은 | 90
  행   : 가은 | 90
  행   : 라온 | 80
  행   : 나래 | 70
  행   : 마루 | 60
  행   : 다온 | 50
  합계 : 6행

[결과에 없는 소스 컬럼]
  SQL  : SELECT name FROM seoul
  SQL  : UNION ALL
  SQL  : SELECT name FROM busan
  SQL  : ORDER BY score
  에러 : OperationalError: 1st ORDER BY term does not match any column in the result set

[출력 컬럼에 없는 표현식]
  SQL  : SELECT name, score FROM seoul
  SQL  : UNION ALL
  SQL  : SELECT name, score FROM busan
  SQL  : ORDER BY score * -1
  에러 : OperationalError: 1st ORDER BY term does not match any column in the result set

[출력 컬럼과 글자까지 같은 표현식]
  SQL  : SELECT name, score * -1 FROM seoul
  SQL  : UNION ALL
  SQL  : SELECT name, score * -1 FROM busan
  SQL  : ORDER BY score * -1
  행   : 가은 | -90
  행   : 가은 | -90
  행   : 라온 | -80
  행   : 나래 | -70
  행   : 마루 | -60
  행   : 다온 | -50
  합계 : 6행

[오른쪽 SELECT 에만 있는 별칭]
  SQL  : SELECT name, score FROM seoul
  SQL  : UNION ALL
  SQL  : SELECT name AS who, score FROM busan
  SQL  : ORDER BY who
  행   : 가은 | 90
  행   : 가은 | 90
  행   : 나래 | 70
  행   : 다온 | 50
  행   : 라온 | 80

5. 콤마를 쓴 LIMIT 은 앞이 OFFSET 이다
================================================================
[LIMIT 2 OFFSET 2]
  SQL  : SELECT name, score FROM seoul
  SQL  : UNION ALL
  SQL  : SELECT name, score FROM busan
  SQL  : ORDER BY score DESC
  SQL  : LIMIT 2 OFFSET 2
  행   : 라온 | 80
  행   : 나래 | 70
  합계 : 2행

[LIMIT 2, 3]
  SQL  : SELECT name, score FROM seoul
  SQL  : UNION ALL
  SQL  : SELECT name, score FROM busan
  SQL  : ORDER BY score DESC
  SQL  : LIMIT 2, 3
  행   : 라온 | 80
  행   : 나래 | 70
  행   : 마루 | 60
  합계 : 3행

6. 실행계획 — 어디서 정렬하고 어디서 중복을 지우는가
================================================================
[UNION ALL + 전체 ORDER BY]
  QUERY PLAN
  `--MERGE (UNION ALL)
     |--LEFT
     |  |--SCAN seoul
     |  `--USE TEMP B-TREE FOR ORDER BY
     `--RIGHT
        |--SCAN busan
        `--USE TEMP B-TREE FOR ORDER BY

[UNION (중복 제거) + LIMIT]
  QUERY PLAN
  `--COMPOUND QUERY
     |--LEFT-MOST SUBQUERY
     |  `--SCAN seoul
     `--UNION USING TEMP B-TREE
        `--SCAN busan

[서브쿼리로 피연산자마다 LIMIT]
  QUERY PLAN
  `--COMPOUND QUERY
     |--LEFT-MOST SUBQUERY
     |  |--CO-ROUTINE (subquery-1)
     |  |  |--SCAN seoul
     |  |  `--USE TEMP B-TREE FOR ORDER BY
     |  `--SCAN (subquery-1)
     `--UNION ALL
        |--CO-ROUTINE (subquery-3)
        |  |--SCAN busan
        |  `--USE TEMP B-TREE FOR ORDER BY
        `--SCAN (subquery-3)
