== 5) 행 번호 차이 방식의 실행계획 ==
  [인덱스 없음]
  QUERY PLAN
  |--CO-ROUTINE numbered
  |  |--CO-ROUTINE (subquery-3)
  |  |  |--SCAN attendance
  |  |  `--USE TEMP B-TREE FOR ORDER BY
  |  `--SCAN (subquery-3)
  |--SCAN numbered
  |--USE TEMP B-TREE FOR GROUP BY
  `--USE TEMP B-TREE FOR ORDER BY
  [(user_id, attend_date) 인덱스 뒤]
  QUERY PLAN
  |--CO-ROUTINE numbered
  |  |--CO-ROUTINE (subquery-3)
  |  |  `--SCAN attendance USING COVERING INDEX ix_attendance_user_id_attend_date
  |  `--SCAN (subquery-3)
  |--SCAN numbered
  |--USE TEMP B-TREE FOR GROUP BY
  `--USE TEMP B-TREE FOR ORDER BY
