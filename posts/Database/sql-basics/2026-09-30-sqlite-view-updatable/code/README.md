# 예제 코드 — VIEW — 만들고 쓰는 법, 그리고 한계

메모리 DB에 회원 표 `member`와 주문 표 `orders`를 만들고, 그 위에 뷰를 올려 조회·갱신을 차례로 돌린다.
파이썬 표준 라이브러리만 쓴다.

| 장 | 무엇을 보는가 |
|---|---|
| 1 | 컬럼 이름을 붙인 뷰와 집계 뷰를 만들고 표처럼 조회하는 것 |
| 2 | 뷰가 데이터를 따로 갖지 않아 원본 표의 변경이 바로 보이는 것 |
| 3 | 뷰에 직접 INSERT·UPDATE·DELETE 하면 실패하는 것 |
| 4 | INSTEAD OF 트리거를 달면 뷰에 UPDATE 가 되는 것, 그리고 rowcount |
| 5 | 트리거가 넣은 행이 뷰 조건을 어기면 뷰에 안 보이는 것, WITH CHECK OPTION 이 없는 것 |
| 6 | 뷰를 조회해도 원본 표의 기본 키를 쓰는지 — 실행계획 |
| 7 | `SELECT *` 뷰가 원본 표에 추가된 컬럼을 따라가는지 |
| 8 | 원본 표를 지워도 뷰는 남고 조회할 때 실패하는 것 |

## 실행

```bash
python view_basics.py
```

## 바꿔볼 값

- 4장 트리거의 `UPDATE OF phone`을 지우고 `UPDATE OF` 없이 만들면 `member_name` 갱신도 트리거를 부른다.
- 5장 트리거의 `active` 값을 `0`에서 `1`로 바꾸면 넣은 행이 뷰에 보인다.
- 6장의 조건을 `WHERE member_name = '김하나'`로 바꾸면 계획이 어떻게 달라지는지 본다.
