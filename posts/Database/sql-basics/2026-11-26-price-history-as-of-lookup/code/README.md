# 예제 코드 — 가격 이력 표에서 주문 시점의 가격 찾기

파이썬 표준 라이브러리(`sqlite3`)만 쓴다. 설치할 것이 없다.
Python 3.13.5, SQLite 3.49.1 에서 돌렸다. `dbshow.py` 는 표 정의와 데이터를 찍는 도우미다.

## 실행

```bash
python as_of_price.py
```

## 바꿔 볼 값

- 주문 5 의 날짜를 `2026-02-01` 로 바꾸면 P02 이력 안으로 들어와 [5] 에서 세 방법이 모두 6행을 낸다
- [3-1] 의 `o.order_date < r.valid_to` 를 `<=` 로 바꾸면 [6] 과 같은 중복이 생긴다
- `build_large` 의 세 번째 반복 값 300 을 더 키우면 방법 C 가 붙이는 중간 행이 그만큼 늘어난다. 상품당 날짜 후보가 336개라 335 까지만 넣을 수 있다
- `price_history` 의 기본키를 지우고 [7] 을 다시 보면 방법 A 의 `SEARCH p USING PRIMARY KEY` 가 `SCAN p` 로 바뀐다
