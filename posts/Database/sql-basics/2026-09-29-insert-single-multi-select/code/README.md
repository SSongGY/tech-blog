# 예제 코드 — INSERT — 단건, 다건, SELECT로 넣기

메모리 DB에 회원 표 `member`와 가입 신청을 모아 둔 `signup_staging`을 만든다.
두 표는 이름·이메일 컬럼의 **순서가 반대**다. 단건·다건 INSERT와 에러 두 가지를 본 뒤,
`INSERT ... SELECT *`로 옮겼을 때 값이 뒤바뀌는 것과 그것을 `EXCEPT`로 잡아내는 것을 확인한다.
파이썬 표준 라이브러리만 쓴다.

| 장 | 무엇을 보는가 |
|---|---|
| 1~3 | 단건, 다건, 다건 중 한 행이 실패할 때 |
| 4~5 | 값 개수와 컬럼 개수가 다를 때의 에러 |
| 6~7 | `SELECT *`로 옮긴 결과와, 적재 뒤 검사 질의 |
| 8~9 | 컬럼 이름을 양쪽에 적어 다시 옮긴 결과 |

## 실행

```bash
python insert_basics.py
```

## 바꿔볼 값

- `signup_staging`의 컬럼 순서를 `(name, email)`로 바꾸면 6장의 `SELECT *`도 맞게 들어간다.
  그래도 표 정의가 바뀌는 순간 다시 틀어진다는 점을 생각해 본다.
- 3장의 두 번째 행을 `(5, ...)`로 바꾸면 두 행이 모두 들어가는지 본다.
