스키마와 데이터 — 아래 질의는 전부 이 표를 대상으로 한다
================================================================
[plain]  4행
  컬럼  | 타입    | 제약
  ------+---------+---------
  id    | INTEGER | PK
  title | TEXT    | NOT NULL

  id | title
  ---+--------
   1 | 첫 글
   2 | 둘째 글
   3 | 셋째 글
   4 | 넷째 글

[strict_seq]  4행
  컬럼  | 타입    | 제약
  ------+---------+---------
  id    | INTEGER | PK
  title | TEXT    | NOT NULL

  id | title
  ---+--------
   1 | 첫 글
   2 | 둘째 글
   3 | 셋째 글
   4 | 넷째 글

================================================================
0. 두 표가 sqlite_master 에 어떻게 적혀 있는가
================================================================
  CREATE TABLE plain ( id INTEGER PRIMARY KEY, title TEXT NOT NULL )
  CREATE TABLE sqlite_sequence(name,seq)
  CREATE TABLE strict_seq ( id INTEGER PRIMARY KEY AUTOINCREMENT, title TEXT NOT NULL )

  sqlite_sequence: name='strict_seq'  seq=4

================================================================
1. 마지막 행을 지우고 다시 넣는다
================================================================
  삭제 후  plain=[1, 2, 3]  strict_seq=[1, 2, 3]
  sqlite_sequence: name='strict_seq'  seq=4
  재삽입   plain 이 받은 번호=4  strict_seq 가 받은 번호=5
  현재     plain=[1, 2, 3, 4]  strict_seq=[1, 2, 3, 5]
  sqlite_sequence: name='strict_seq'  seq=5

================================================================
2. 중간 행을 지우고 다시 넣는다
================================================================
  삭제 후  plain=[1, 3, 4]  strict_seq=[1, 3, 5]
  재삽입   plain 이 받은 번호=5  strict_seq 가 받은 번호=6

================================================================
3. 전체를 지우고 다시 넣는다
================================================================
  비운 뒤  plain=[]  strict_seq=[]
  sqlite_sequence: name='strict_seq'  seq=6
  재삽입   plain 이 받은 번호=1  strict_seq 가 받은 번호=7
  sqlite_sequence: name='strict_seq'  seq=7

================================================================
4. 번호를 직접 지정해 넣으면 다음 번호가 어디서부터인가
================================================================
  sqlite_sequence: name='strict_seq'  seq=1000
  자동 부여 plain=1001  strict_seq=1001
  1000번 삭제 후 plain=[1, 1001]  strict_seq=[7, 1001]
  sqlite_sequence: name='strict_seq'  seq=1001
  자동 부여 plain=1002  strict_seq=1002

================================================================
5. 상한에 닿으면 무엇이 일어나는가
================================================================
  plain       성공 — 받은 번호=1787792953505057767
  strict_seq  실패 — OperationalError: database or disk is full

================================================================
6. 번호 재사용이 바깥 참조를 어긋나게 하는 장면
================================================================
  바깥 시스템이 적어 둔 번호: 2  ('장애 보고서')
  같은 번호로 다시 찾으면: '점심 메뉴'

================================================================
7. 롤백된 트랜잭션이 가져간 번호는 돌아오는가
================================================================
  롤백 전 seq=2
  롤백 후 seq=1
  다음 삽입이 받은 번호=2
  남은 행=[(1, '첫 글'), (2, '다음 글')]

================================================================
8. 기본키 타입을 INT 로 적으면
================================================================
  id, typeof(id), rowid, title
    (None, 'null', 1, 'a')
    (None, 'null', 2, 'b')
  INT PRIMARY KEY AUTOINCREMENT — OperationalError: AUTOINCREMENT is only allowed on an INTEGER PRIMARY KEY
