# 예제 코드 — 임시 테이블과 CTE — 어느 쪽을 쓸까

`sale` 표(240행, 지역 4개)를 메모리 SQLite 에 만들고, 집계 함수 안쪽에 `tally()` 를
끼워 넣어 **그 자리를 실제로 지나간 행 수**를 센다. CTE·서브쿼리·임시 테이블이
각각 몸체를 몇 번 도는지가 이 숫자로 드러난다.

## 실행

```bash
python temp_table_vs_cte.py
```

의존성 없음. 파이썬 3.11 이상이면 그대로 돈다.

## 바꿔 볼 값

| 값 | 위치 | 보이는 것 |
|---|---|---|
| `ROW_COUNT` | 파일 상단 | 행이 늘어도 CTE 의 `tally()` 호출이 한 벌로 유지되는지 |
| `ON b.region = '서울'` | `SUBQUERY_TWICE` | 상수 조건을 빼면 서브쿼리 쪽 밀어넣기가 사라진다 |
| `WHERE amount > 1400` | `PLAIN_BODY` | 조건을 느슨하게 하면 평탄화된 몸체가 더 많이 돈다 |
