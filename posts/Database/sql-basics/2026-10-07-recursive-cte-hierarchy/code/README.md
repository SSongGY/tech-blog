# 예제 코드 — 재귀 CTE로 조직도 펴기

외부 의존성 없다. 파이썬 표준 라이브러리 `sqlite3`로 메모리 DB에 직원 표 `employee`(9행, 4단계)를
만들고 재귀 CTE를 한 갈래씩 돌린다. `dbshow.py`는 표 정의와 데이터를 찍는 보조 모듈이다.

## 실행

```bash
python recursive_cte.py
```

확인 환경: SQLite 3.49.1 (파이썬 내장) / Python 3.13.5 / Windows 11. 실행 기록은 `output.txt`.

## 각 장이 보는 것

| 장 | 확인하는 것 |
|---|---|
| 1 | 자기 조인은 조인 횟수만큼만 내려간다 |
| 2 | 재귀 CTE로 특정 관리자 아래 전원을 깊이와 함께 뽑는다 |
| 3 | 방향을 바꿔 한 직원의 상사 체인을 올라간다 |
| 4 | 재귀 단계마다 문자열을 이어 붙여 경로를 만든다 |
| 5 | 재귀 SELECT의 `ORDER BY`가 너비 우선·깊이 우선을 정한다 |
| 6 | `EXPLAIN QUERY PLAN`에 재귀 단계가 어떻게 보이는가 |
| 7 | 재귀 SELECT에 집계 함수·재귀 표 중복 참조를 쓰면 나는 에러 |
| 8 | 종료 조건이 없으면 끝나지 않는다. VDBE 명령 20만 개에서 끊는다. `LIMIT`은 멈춘다 |
| 9 | 데이터에 순환이 있을 때 `UNION ALL` / `UNION` / `UNION` + hop 컬럼의 차이 |

## 바꿔 볼 값

- `STEP_LIMIT`을 키우면 8-A가 더 오래 돌다 끊긴다. 결과는 같다 — 끝나지 않는다.
- 9장의 `LIMIT 12`를 지우면 9-A·9-C는 영원히 돈다. 지우려면 `query_with_guard`로 바꿔 돌린다.
- 5장의 `ORDER BY 3`을 `ORDER BY 3, e.name`으로 바꾸면 같은 깊이 안에서 이름순이 된다.
