# 부분 인덱스 예제

표준 SQL 과 파이썬 내장 `sqlite3` 만 쓴다. 따로 설치할 것이 없다.

## 실행

```bash
python partial_index.py
```

20만 행을 넣고 `VACUUM` 을 여러 번 돌리므로 1~2분 걸린다.
`partial.db` 는 실행할 때마다 지우고 다시 만든다.

## 바꿔 볼 값

| 값 | 기본 | 바꾸면 |
|---|---|---|
| `ROWS` | 200000 | 표가 커질수록 전체 인덱스와 부분 인덱스의 페이지 차이가 벌어진다 |
| `PENDING_EVERY` | 100 | 10 으로 낮추면 색인 대상이 10% 가 되고, 부분 인덱스의 크기 이득이 그만큼 줄어든다 |
| `REPEAT` | 9 | 중앙값을 뽑는 횟수. 측정이 흔들리면 늘린다 |

`PENDING_EVERY` 를 1 로 두면 모든 행이 색인 대상이 되므로 부분 인덱스가
전체 인덱스와 같은 크기가 된다. 부분 인덱스의 이득이 **선택도에서 나온다**는
것을 그 자리에서 확인할 수 있다.
