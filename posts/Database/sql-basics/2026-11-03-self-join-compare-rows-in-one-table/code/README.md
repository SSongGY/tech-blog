# 자기 조인 예제

직원 표 하나를 `e`(직원)·`m`(상사) 두 별칭으로 불러 상사 이름 붙이기, 상사보다 급여가
많은 직원 찾기, 같은 부서 짝짓기, 전날 매출과 비교하기를 돌려 본다. 메모리 DB 라
남는 파일이 없다.

## 실행

```bash
python self_join.py
```

## 바꿔 볼 값

- `build_database()` 의 정사원 급여 520 을 480 으로 낮추면 3번 결과가 0행이 된다
- 4번의 `<>` 와 `<` 를 `<=` 로 바꾸면 자기 자신과의 짝이 들어와 행 수가 또 달라진다
- `daily_sale` 에 `2026-03-04` 행을 넣으면 5번에서 자기 조인과 `LAG()` 의 결과가 같아진다
- 7번에서 `CREATE INDEX` 줄을 지우면 짝짓기 조인의 계획이 어떻게 바뀌는지 본다

## 파일

| 파일 | 무엇 |
|---|---|
| `self_join.py` | 예제 본문 |
| `dbshow.py` | 표 정의와 데이터를 찍는 공용 모듈. `blog.py sync-dbshow` 가 복사한다 |
| `output.txt` | `blog.py run-example` 이 남긴 실행 기록. 손으로 고치지 않는다 |
