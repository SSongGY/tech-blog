# WHERE 조건 — AND와 OR의 우선순위

```bash
python where_and_or.py
```

표준 라이브러리만 쓴다. 메모리 DB에 20,000행을 만들고 끝나면 사라진다.

## 바꿔볼 값

| 값 | 기본 | 바꾸면 |
|---|---|---|
| `RANDOM_SEED` | `20260921` | 데이터가 달라져 건수가 전부 바뀐다. 괄호 유무의 차이는 그대로 남는다 |
| `ROW_COUNT` | `20_000` | 행을 늘리면 4번 실행계획에서 스캔과 인덱스 탐색의 차이가 더 뚜렷해진다 |
| 쿠폰 `NULL` 비율 | `rng.random() < 0.3` | 1.0으로 두면 `NULL`이 사라져 `=` 와 `<>` 의 합이 전체와 같아진다 |
