# 예제 코드 — GROUP BY 여러 컬럼

메모리 SQLite에 판매 12건(지역 3곳 · 상품 3종 · 판매 경로)을 넣고, `GROUP BY`에 컬럼을
하나씩 더하거나 순서를 바꿔 가며 결과 행 수와 실행계획을 비교한다.
부산에는 키보드 판매가 없고, 대구 1건은 판매 경로가 NULL이다.
외부 의존성 없이 파이썬 표준 라이브러리만 쓴다. `dbshow.py`는 표 정의와 데이터를 찍는 도우미다.

## 실행

```bash
python group_by_multiple_columns.py
```

## 바꿔볼 값

- `SALES`에 `(13, "부산", "키보드", "매장", 55)`를 더하면 4번의 그룹 수가 9가 되는지 본다.
- 11번의 인덱스를 `(product, region)`으로 바꾸면 11번과 12번 계획이 어떻게 바뀌는지 본다.
- 8번에 `GROUP BY region, product`를 넣으면 행 수가 몇으로 바뀌는지 센다.
