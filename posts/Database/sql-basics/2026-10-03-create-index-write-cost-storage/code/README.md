# 예제 코드 — CREATE INDEX 기본

메모리 SQLite에 주문 20,000행(고객 2,000명, 상태 3가지)을 시드 고정으로 만든다.
인덱스를 만들기 전과 후의 실행계획과 VM 명령 수를 비교하고, 인덱스를 하나씩 더할 때
늘어나는 페이지 수와 INSERT·UPDATE에 드는 VM 명령 수를 잰다.
외부 의존성 없이 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python create_index_basics.py
```

## 바꿔볼 값

- `ROW_COUNT`를 늘려 1번과 2번의 VM 명령 수가 각각 어떻게 변하는지 본다. 1번은 행 수에 비례해 늘어난다.
- `STATUSES`의 상태 가짓수를 늘려 5번의 인덱스 사용·NOT INDEXED 차이를 다시 본다.
- 시간(ms)은 실행할 때마다 흔들린다. VM 명령 수와 페이지 수는 같은 버전에서 매번 같다.
