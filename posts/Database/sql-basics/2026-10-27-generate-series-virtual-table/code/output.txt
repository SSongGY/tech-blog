-- 달력 LEFT JOIN 의 실행계획
  QUERY PLAN
  |-- CO-ROUTINE calendar
  |   |-- SETUP
  |   |   `-- SCAN CONSTANT ROW
  |   `-- RECURSIVE STEP
  |       `-- SCAN calendar
  |-- SCAN c
  |-- SEARCH o USING AUTOMATIC COVERING INDEX (ordered_on=?) LEFT-JOIN
  `-- USE TEMP B-TREE FOR GROUP BY

4. 멈추는 조건 — WHERE 를 빠뜨리면
================================================================
  WHERE 없이 LIMIT 만으로 멈추는 형태 (공식 문서가 권하는 안전장치)
  x
  -
  1
  2
  3
  4
  5
  (5행)

  WHERE 도 LIMIT 도 없으면 — 끝나지 않으므로 바깥 LIMIT 으로 잘라 본다
  바깥 LIMIT 3 으로 받은 값: [1, 2, 3]
  바깥 LIMIT 이 없었다면 이 질의는 스스로 멈추지 않는다

  `-- USE TEMP B-TREE FOR ORDER BY
