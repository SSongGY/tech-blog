# 배치 삽입 측정 예제

1만 건을 넣는 다섯 가지 조합의 소요 시간을 잰다. 커밋 횟수만 다른 조합을
나란히 돌려, 느려지는 원인이 "INSERT 문 개수"가 아니라 "커밋 횟수"임을 보인다.

표준 라이브러리만 쓴다. 설치할 것이 없다.

## 실행

```bash
python batch_insert.py
```

## 바꿔볼 값

| 값 | 기본 | 바꾸면 |
|---|---|---|
| `ROW_COUNT` | `10_000` | 건수를 늘리면 모든 방식이 비례해 늘어난다. 배수는 거의 그대로다 |
| `CHUNK_SIZE` | `500` | 묶음을 키울수록 커밋 횟수가 줄어 "한 번만 커밋"에 가까워진다 |
| `PRAGMA journal_mode` | `DELETE` | `WAL` 로 바꾸면 커밋마다 저널 파일을 지웠다 만들지 않아 건별 커밋이 덜 느려진다 |
| `PRAGMA synchronous` | `FULL` / `OFF` | 마지막 줄이 `OFF` 다. 커밋마다 디스크 플러시를 생략한다 |

## 파일

| 파일 | 무엇 |
|---|---|
| `batch_insert.py` | 측정 본체 |
| `dbshow.py` | 표 정의·행을 출력 앞에 찍는 도우미 (저장소 공용 사본) |
| `output.txt` | `blog.py run-example` 이 남긴 실행 기록 |
