# 예제 코드 — UPDATE — 조건 없는 UPDATE를 막는 습관

메모리 DB에 회원 표 `member` 5행을 만들고, `WHERE`를 빠뜨린 UPDATE가 무엇을 바꾸는지 본 뒤
"먼저 세고 → 트랜잭션 안에서 바꾸고 → 바뀐 행 수를 대조하는" 절차를 돌린다.
파이썬 표준 라이브러리만 쓴다.

| 장 | 무엇을 보는가 |
|---|---|
| 1 | `WHERE` 없는 UPDATE가 전체 행을 바꾸고, `ROLLBACK`으로 되돌아오는 것 |
| 2 | 센 값과 바뀐 행 수가 같아 `COMMIT`하는 경우 |
| 3 | UPDATE의 조건을 잘못 옮겨 수가 달라지고 `ROLLBACK`하는 경우 |
| 4 | 값이 그대로여도 바뀐 행으로 세는 것 |
| 5 | `SET`의 오른쪽이 바뀌기 전 값을 읽는 것 |
| 6 | `RETURNING`으로 바뀐 행을 돌려받는 것 (SQLite 3.35.0부터) |

## 실행

```bash
python update_basics.py
```

## 바꿔볼 값

- 3장의 `OR`를 `AND`로 고치면 대조가 맞아 `COMMIT`으로 바뀌는지 본다.
- 4장에 `AND grade <> 'gold'`를 붙이면 바뀐 행이 0이 된다. 대조에 쓰는 수가 "조건에 맞은 행"이라는 점을 확인한다.
