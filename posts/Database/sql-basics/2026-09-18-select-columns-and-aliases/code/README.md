# 예제 코드 — SELECT 기본: 컬럼 고르기와 별칭

`select_basics.py` 하나로 끝난다. 표준 라이브러리만 쓰고, 메모리 DB에 20만 행을 만든 뒤
세 가지를 확인한다.

1. `SELECT *` 와 필요한 컬럼만 고른 질의의 실행계획·시간 비교
2. 별칭을 `ORDER BY` / `WHERE` 에서 쓸 때 어떻게 되는지
3. 컬럼을 추가하면 `SELECT *` 의 결과 모양이 어떻게 바뀌는지

## 실행

```bash
python select_basics.py
```

환경: Python 3.13.5, SQLite 3.49.1 (`sqlite3.sqlite_version`으로 출력된다).

## 바꿔볼 값

| 상수 | 기본값 | 바꾸면 |
|---|---|---|
| `ROW_COUNT` | 200,000 | 행 수를 줄이면 두 질의의 시간 차이도 함께 줄어든다 |
| `REPEAT_COUNT` | 5 | 반복 횟수. 최솟값을 쓰므로 늘리면 값이 안정된다 |
| `RANDOM_SEED` | 20260918 | 데이터가 바뀌므로 행 수와 시간이 달라진다 |
| `summary` 컬럼 길이 | 200자 | 이 컬럼을 짧게 만들면 `SELECT *` 의 불리함이 줄어든다 |
