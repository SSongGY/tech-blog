# 예제 코드 — 시간 간격으로 세션 나누기 — LAG로 끊는 자리를 찾고 누적 SUM으로 번호 붙이기

파이썬 표준 라이브러리 `sqlite3` 만 쓴다. SQLite 3.49.1 에서 돌렸다.

## 실행

```bash
python session.py
```

## 바꿔 볼 값

- `SESSION_GAP_SECONDS` — 30분을 15분이나 60분으로 바꾸면 세션 수가 어떻게 달라지는지
- `[5-1]` 의 `>` 를 `>=` 로 바꿔 `SESSION_SQL` 에 넣으면 클릭 6이 새 세션이 된다
- `USER_WINDOW` 에서 `click_id` 를 빼면 같은 시각 두 클릭(9·12)의 순서가 엔진에 맡겨진다
