# 예제 코드 — 숫자 타입과 반올림: 돈을 다룰 때

메모리 SQLite에 상품 가격 4건을 넣는다. 같은 가격 문자열을 `REAL`, `DECIMAL(10, 2)`, `INTEGER`(센트) 세 컬럼에 나란히 넣는다.
1절에서 실제 저장 부류를 보고, 2~6절에서 더하기·비교·나누기·`round`·`CAST`·정수 범위를 돌린다.
파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python numeric_money.py
```

## 바꿔볼 값

- `PRICES`의 `"20.00"`을 `"20.50"`으로 바꾸고 1-A에서 `amount_dec`의 부류가 어떻게 바뀌는지 본다.
- 2-C의 `i < 10`을 `i < 100`으로 바꾸면 오차가 얼마나 커지는지 본다.
- 5-A·5-B의 `id = 3`을 다른 상품으로 바꿔 `CAST`가 맞는 값을 내는 가격과 틀리는 가격을 찾아본다.
