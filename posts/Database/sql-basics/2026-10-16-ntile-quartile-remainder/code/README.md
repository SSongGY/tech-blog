# NTILE 예제

메모리 SQLite에 13행짜리 매출 표를 만들고, `NTILE()`이 행을 몇 개씩 나누는지
묶음 크기까지 세어 본다. 외부 의존성은 없다.

## 실행

```bash
python ntile_demo.py
```

## 바꿔 볼 값

- `main()`의 `(row_count, tiles)` 목록 — 행 수와 묶음 수를 바꾸면
  몫 `q`와 나머지 `r`이 어떻게 묶음 크기로 풀리는지 바로 보인다.
  행 수보다 묶음 수가 크면(예: `(3, 5)`) 뒤쪽 묶음은 아예 생기지 않는다.
- 3번 질의의 `PARTITION BY region` — 지우면 전체가 한 묶음이 되어
  지역별 등급이 아니라 전체 등급이 나온다.
- 5번 질의의 `500 AS amount` — 동점을 몇 행으로 만드느냐에 따라
  동점이 묶음 경계를 넘는 자리가 달라진다.

`probe_ntile.py`는 규칙을 확인하려고 찔러 본 쪽이라 예제에 싣지 않았다.
