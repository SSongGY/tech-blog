## 1. DISTINCT는 무엇을 지우는가
[1-1 중복 포함]
  SQL  : SELECT team FROM employee
  행   : 개발
  행   : 개발
  행   : 개발
  행   : 영업
  행   : 영업
  행   : 영업
  행   : 지원
  행   : 지원

[1-2 중복 제거]
  SQL  : SELECT DISTINCT team FROM employee
  행   : 개발
  행   : 영업
  행   : 지원

[1-3 컬럼 두 개]
  SQL  : SELECT DISTINCT team, grade FROM employee
  행   : 개발 | 선임
  행   : 개발 | 책임
  행   : 영업 | 선임
  행   : 영업 | 책임
  행   : 지원 | 책임

[1-4 name을 끼우면]

  행   : 개발 | 김서연

  행   : 영업 | 이하늘
  행   : 영업 | 최유진
  행   : 영업 | 정우성
  행   : 지원 | 한지민
  행   : 지원 | 오세훈

## 2. 인덱스가 없을 때의 실행계획
[2-1 DISTINCT]
  SQL  : SELECT DISTINCT team FROM employee
  계획 : SCAN employee
  계획 : USE TEMP B-TREE FOR DISTINCT

[2-2 GROUP BY]
  SQL  : SELECT team FROM employee GROUP BY team
  계획 : SCAN employee
  계획 : USE TEMP B-TREE FOR GROUP BY

[2-3 그냥 SELECT]
  SQL  : SELECT team FROM employee
  계획 : SCAN employee

## 3. 인덱스를 만들면 달라지는가
[3-1 DISTINCT]
  SQL  : SELECT DISTINCT team FROM employee
  계획 : SCAN employee USING COVERING INDEX ix_employee_team

[3-2 DISTINCT 두 컬럼]
  SQL  : SELECT DISTINCT team, grade FROM employee
  계획 : SCAN employee USING INDEX ix_employee_team
  계획 : USE TEMP B-TREE FOR DISTINCT

[3-3 두 컬럼 인덱스 생성 후]
  SQL  : SELECT DISTINCT team, grade FROM employee
  계획 : SCAN employee USING COVERING INDEX ix_employee_team_grade

## 4. 정렬은 덤이지 약속이 아니다
[4-1 grade만]
  SQL  : SELECT DISTINCT grade FROM employee
  행   : 선임
  행   : 책임

[4-2 grade, team]
  SQL  : SELECT DISTINCT grade, team FROM employee
  행   : 선임 | 개발
  행   : 책임 | 개발
  행   : 선임 | 영업
  행   : 책임 | 영업
  행   : 책임 | 지원

[4-3 위 질의의 계획]
  SQL  : SELECT DISTINCT grade, team FROM employee
  계획 : SCAN employee USING COVERING INDEX ix_employee_team_grade

[4-4 순서를 요구하면]
  SQL  : SELECT DISTINCT grade, team FROM employee ORDER BY grade, team
  행   : 선임 | 개발
  행   : 선임 | 영업
  행   : 책임 | 개발
  행   : 책임 | 영업
  행   : 책임 | 지원

[4-5 그때의 계획]
  SQL  : SELECT DISTINCT grade, team FROM employee ORDER BY grade, team
  계획 : SCAN employee USING COVERING INDEX ix_employee_team_grade
  계획 : USE TEMP B-TREE FOR ORDER BY

## 5. DISTINCT가 지워지는 경우
[5-1 PK에 DISTINCT]
  SQL  : SELECT DISTINCT id FROM employee
  계획 : SCAN employee USING COVERING INDEX ix_employee_team

[5-2 PK에 DISTINCT 없이]
  SQL  : SELECT id FROM employee
  계획 : SCAN employee USING COVERING INDEX ix_employee_team
