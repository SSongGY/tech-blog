스키마와 데이터 — 아래 질의는 전부 이 표를 대상으로 한다
================================================================
[audit_log]  0행
  컬럼   | 타입    | 제약
  -------+---------+---------
  seq    | INTEGER | PK
  action | TEXT    | NOT NULL

  (행 없음)

[member]  2행
  컬럼      | 타입    | 제약
  ----------+---------+---------
  member_id | INTEGER | PK
  name      | TEXT    | NOT NULL

  member_id | name
  ----------+-----
          1 | 가영
          2 | 나래

[wallet]  2행
  컬럼      | 타입    | 제약
  ----------+---------+-------------------
  member_id | INTEGER | PK
  balance   | INTEGER | NOT NULL DEFAULT 0

  member_id | balance
  ----------+--------
          1 |     500
          2 |     800


[1] 트리거가 없을 때 뷰에 쓰기
INSERT: OperationalError: cannot modify member_wallet because it is a view
UPDATE: OperationalError: cannot modify member_wallet because it is a view
DELETE: OperationalError: cannot modify member_wallet because it is a view

[2] 뷰에는 BEFORE/AFTER 트리거를 만들 수 없다
BEFORE: OperationalError: cannot create BEFORE trigger on view: member_wallet
AFTER: OperationalError: cannot create AFTER trigger on view: member_wallet

[3] INSTEAD OF INSERT 한 줄이 두 표에 나뉘어 들어간다
INSERT: 성공, rowcount=0
  member:
   (1, '가영')
   (2, '나래')
   (3, '다은')
  wallet:
   (1, 500)
   (2, 800)
   (3, 100)

[4] 뷰에 UPDATE — 여러 행이면 트리거가 행마다 돈다
UPDATE: 성공, rowcount=0
   (1, '가영', 550)
   (2, '나래', 800)
   (3, '다은', 150)
  audit_log:
   (1, 'insert 3')
   (2, 'update 1')
   (3, 'update 3')

[5] 조건에 맞는 행이 없으면 트리거는 돌지 않는다
UPDATE: 성공, rowcount=0
  audit_log 행 수: 3 -> 3

[6] 뷰에 쓴 건수는 rowcount 에 잡히지 않는다
뷰 UPDATE: 성공, rowcount=0
  트리거가 남긴 audit_log: 3행 늘어남
표 UPDATE: 성공, rowcount=3

[7] RETURNING 은 뷰에서 쓸 수 있는가
INSERT RETURNING: 성공, rowcount=0
  돌려받은 행: [(4,)]

[8] 뷰의 WHERE 에 걸리지 않는 행을 INSERT 하면
INSERT INTO rich (잔액 10): 성공, rowcount=0
  rich 뷰에서 보이는 행: 0
  member_wallet 에서 보이는 행: 1
