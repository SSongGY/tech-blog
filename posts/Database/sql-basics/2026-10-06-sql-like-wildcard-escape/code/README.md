# 예제 코드 — LIKE와 와일드카드

메모리 SQLite에 상품 14행을 넣고 `LIKE`의 `%`·`_`가 무엇과 맞는지, 글자 그대로의 `%`·`_`를
`ESCAPE`로 찾는 법, 대소문자·NULL·숫자 컬럼에서의 동작, 와일드카드 위치에 따른 실행계획을 차례로 찍는다.
외부 의존성 없이 파이썬 표준 라이브러리만 쓴다. `dbshow.py`는 표 정의와 데이터를 찍는 도우미다.

## 실행

```bash
python like_wildcards.py
```

## 바꿔볼 값

- 9번의 `ESCAPE '!'`를 `ESCAPE '\'`로 바꾸고 패턴도 `'%100\%%'`로 바꿔 본다. 이스케이프 문자는 아무 글자나 정할 수 있다.
- `PRODUCTS`에 `"100%"`처럼 퍼센트로 끝나는 이름을 넣고 8번과 9번의 행 수를 다시 본다.
- 21번 앞에 `conn.execute("PRAGMA case_sensitive_like = ON")`을 넣으면 `LIKE 'a%'`의 계획이 바뀐다.
  대신 대소문자를 가리게 되므로 1번의 결과도 달라진다.
