# 예제 코드 — WITHOUT ROWID 테이블 — 기본키가 곧 저장 순서

표준 라이브러리만 쓴다. 메모리 DB 라 파일이 남지 않는다.

## 실행

```bash
python without_rowid.py
```

## 바꿔볼 값

- `WORD_COUNT` — 행 수. 늘려도 크기 비율은 거의 그대로다
- `show_sizes()` 의 BLOB 길이 — 200·2000 사이 값을 넣어 보면 비율이 뒤집히는 지점을 찾을 수 있다
- `PRAGMA page_size` 를 1024 로 바꾸면 공식 문서가 말한 "행이 페이지의 1/20 이하" 기준이 어떻게 움직이는지 볼 수 있다
