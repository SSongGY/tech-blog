[인덱스]
  이름       | 대상 표 | 정의
  -----------+---------+------------------------------------------------
  idx_people | people  | CREATE INDEX idx_people ON people(grade, phone)

================================================================
1. 이 빌드가 쌓을 수 있는 통계 — stat4 는 컴파일 옵션이다
================================================================
  STAT 관련 컴파일 옵션: 없음
  → ENABLE_STAT4 가 없으므로 ANALYZE 는 sqlite_stat1 만 만든다

================================================================
2. ANALYZE 전 — 통계 표 자체가 없다
================================================================
  sqlite_stat1 존재: False

-- ANALYZE 전
QUERY PLAN
`--SCAN people

================================================================
3. ANALYZE 실행 — sqlite_stat1 에 무엇이 쌓이는가
================================================================
  tbl    | idx        | stat
  -------+------------+-------------
  people | idx_people | 30000 10000 1

-- ANALYZE 후
QUERY PLAN
`--SEARCH people USING INDEX idx_people (ANY(grade) AND phone=?)

================================================================
4. stat 문자열의 숫자 읽기 — 지금은 평균이 실제와 맞는다
================================================================
  전체 30000행 · grade 값 3종 · 값 하나당 평균 10000행
    basic     10000행
    gold      10000행
    vip       10000행

================================================================
5. 통계는 스냅샷이다 — 데이터를 바꿔도 따라오지 않는다
================================================================
  grade 가 전부 다른 행 30,000개를 더 넣었다
  전체 60000행 · grade 값 30003종 · 값 하나당 평균 1행
    basic     10000행
    gold      10000행
    vip       10000행
    vip-00000      1행

  그런데 sqlite_stat1 은 그대로다:
  tbl    | idx        | stat
  -------+------------+-------------
  people | idx_people | 30000 10000 1

-- 데이터만 바뀐 뒤
QUERY PLAN
`--SEARCH people USING INDEX idx_people (ANY(grade) AND phone=?)

================================================================
6. 다시 ANALYZE — 통계가 계획을 되돌린다
================================================================
  tbl    | idx        | stat
  -------+------------+-------------
  people | idx_people | 60000 2 1

-- 재-ANALYZE 후
QUERY PLAN
`--SCAN people

  평균 2행은 어느 등급도 설명하지 못한다 — vip·gold·basic 은 각각 10,000행이다.
  sqlite_stat1 은 값별 분포를 담지 않으므로 이 치우침이 보이지 않는다.

================================================================
7. 경계는 어디인가 — 선두 컬럼의 중복 개수를 1씩 올려 본다
================================================================
  중복 | stat             | 계획
  -----+------------------+----------------------------------------------
