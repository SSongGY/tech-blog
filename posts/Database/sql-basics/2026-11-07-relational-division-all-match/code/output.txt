== 1) 기본 — 두 방법이 같은 답을 낸다 ==
  NOT EXISTS : ['kim']
  GROUP BY   : ['kim']
  EXCEPT     : ['kim']

== 2) 필수가 아닌 과목까지 세면 ==
  lee 의 수강 과목: ['ai', 'db', 'os']
  required_course 와 조인하지 않고 COUNT(*) : ['kim', 'lee']
  required_course 와 조인한 GROUP BY       : ['kim']

== 3) park 이 db 를 한 번 더 들으면 ==
  park 의 수강 행: [('db', '2025-1'), ('network', '2025-2'), ('db', '2026-1')]
  COUNT(*)              : ['kim', 'park']
  COUNT(DISTINCT course): ['kim']
  NOT EXISTS            : ['kim']

== 4) 필수 과목이 하나도 없으면 ==
  required_course 행 수: 0
  NOT EXISTS : ['choi', 'kim', 'lee', 'park']
  GROUP BY   : []
  EXCEPT     : ['choi', 'kim', 'lee', 'park']

== 5) 실행계획 ==
  [이중 NOT EXISTS]
  QUERY PLAN
  |--SCAN s
  |--CORRELATED SCALAR SUBQUERY 2
  |  |--SCAN r
  |  `--CORRELATED SCALAR SUBQUERY 1
  |     `--SCAN e
  `--USE TEMP B-TREE FOR ORDER BY

  [GROUP BY HAVING]
  QUERY PLAN
  |--SCAN e
  |--SEARCH s USING INTEGER PRIMARY KEY (rowid=?)
  |--SEARCH r USING COVERING INDEX sqlite_autoindex_required_course_1 (course=?)
  |--USE TEMP B-TREE FOR GROUP BY
  |--SCALAR SUBQUERY 1
  |  `--SCAN required_course
  |--USE TEMP B-TREE FOR count(DISTINCT)
  `--USE TEMP B-TREE FOR ORDER BY

== 6) (student_id, course) 인덱스를 만든 뒤 ==
  [이중 NOT EXISTS]
  QUERY PLAN
  |--SCAN s
  |--CORRELATED SCALAR SUBQUERY 2
  |  |--SCAN r
  |  `--CORRELATED SCALAR SUBQUERY 1
  |     `--SEARCH e USING COVERING INDEX ix_enrollment_student_id_course (student_id=? AND course=?)
  `--USE TEMP B-TREE FOR ORDER BY

  NOT EXISTS : ['kim']
