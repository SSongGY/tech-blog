# 예제 코드 — 서브쿼리 세 가지 — 스칼라, 인라인 뷰, 상관

메모리 SQLite에 부서 3개·직원 8명을 넣고, "부서 평균보다 급여가 많은 직원"을 상관 서브쿼리와
인라인 뷰로 각각 푼다. 서브쿼리 안에 넣은 `tick()` 함수가 서브쿼리 본문이 행을 몇 번 봤는지 센다.
외부 의존성 없이 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python subquery_kinds.py
```

## 바꿔볼 값

- `EMPLOYEES`에 직원을 늘리면 2-A의 `tick()` 횟수는 대략 (직원 수)²으로, 3-B는 직원 수만큼 늘어난다.
- `build_database()`의 `deterministic=False`를 `True`로 바꿔 `tick()` 횟수가 달라지는지 본다.
- 5절의 `CREATE INDEX`를 지우면 5-A 실행계획이 4-B와 같아진다.
