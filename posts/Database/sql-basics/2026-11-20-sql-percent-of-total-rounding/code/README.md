# 예제 코드 — 구성비 — SUM() OVER()로 전체 대비 비율을 구하고 반올림 합을 100에 맞추기

파이썬 표준 라이브러리 `sqlite3` 만 쓴다. SQLite 3.49.1 에서 돌렸다.

## 실행

```bash
python share.py
```

## 바꿔 볼 값

- `sale` 의 `amount` — 금액을 바꾸면 `[4]` 의 반올림 합이 99 가 되기도 101 이 되기도 한다
- `[5]` 의 `ORDER BY remainder DESC, category` 에서 `category` 를 빼면 나머지가 같은 행끼리 누가 1 을 받을지 엔진이 정한다
- `[1]` 의 `100.0` 을 `100` 으로 바꾸면 비율이 정수로 잘린다
