# 시작·종료 이벤트 짝짓기 예제

로그인·로그아웃이 따로 찍힌 이벤트 로그를 상관 부질의와 `LEAD` 두 방식으로 구간으로 묶고,
로그아웃이 빠졌을 때 결과가 어떻게 갈리는지 본다. 표준 라이브러리만 쓴다.

## 실행

```bash
python pair_events.py
```

## 바꿔 볼 값

- `build_database()`의 데이터에서 U2의 `09:10` 로그인 뒤에 로그아웃을 넣으면 두 방법의 결과가 같아진다
- `total_minutes()`의 `open_end`를 바꾸면 끝나지 않은 세션을 몇 시까지로 칠지 정할 수 있다
- `build_large()`의 세션 수를 늘려 VDBE 명령 수가 어떻게 늘어나는지 본다
