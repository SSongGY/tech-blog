# 문자열을 구분자로 나누기 — 예제

쉼표로 묶인 `tags` 컬럼을 행으로 펼치는 두 가지(재귀 CTE, `json_each`)를 돌려 보고,
경계값에서 둘이 어떻게 갈리는지와 쪼개 저장한 표의 실행계획을 비교한다.

의존성은 없다. 파이썬 표준 라이브러리의 `sqlite3`만 쓴다.

## 실행

```bash
python split_demo.py
```

## 바꿔볼 값

| 자리 | 바꾸면 |
|---|---|
| `ARTICLES` 의 `tags` | 태그 개수가 달라지면 펼쳐진 행 수가 그만큼 달라진다 |
| `cases` 리스트 | 경계값을 더 넣어 두 방식이 갈리는 지점을 넓힐 수 있다 |
| `SPLIT_CTE` 의 `','` | 구분자를 `'||'` 같은 여러 글자로 바꾸면 `instr` 뒤의 `+ 1` 도 길이만큼 바꿔야 한다 |
| `ANALYZE` 호출 제거 | 통계 없이도 `article_tag` 쪽이 인덱스를 타는지 확인할 수 있다 |

## 파일

- `split_demo.py` — 본문의 모든 출력을 만드는 스크립트
- `dbshow.py` — 표 정의와 데이터를 출력 앞에 찍는 도우미 (`references/dbshow.py` 사본)
- `output.txt` — `blog.py run-example` 이 남긴 실행 기록
