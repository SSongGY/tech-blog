== 1. 조건에 따라 값을 고른다 ==

[1-A 검색 CASE — 위에서부터 첫 번째로 맞는 WHEN]
  id | amount | size_grade
  (1, 120, '대형')
  (2, 80, '중형')
  (3, 40, '소형')
  (4, 55, '중형')
  (5, 95, '중형')
  (6, 30, '소형')
  (7, 60, '중형')
  (8, 150, '대형')
  (9, None, '소형')

[1-B WHEN 순서를 뒤집으면]
  id | amount | size_grade
  (1, 120, '중형')
  (2, 80, '중형')
  (3, 40, '소형')
  (4, 55, '중형')
  (5, 95, '중형')
  (6, 30, '소형')
  (7, 60, '중형')
  (8, 150, '중형')
  (9, None, '소형')

[1-C ELSE 를 빼면]
  id | amount | size_grade
  (1, 120, '대형')
  (2, 80, None)
  (3, 40, None)
  (4, 55, None)
  (5, 95, None)
  (6, 30, None)
  (7, 60, None)
  (8, 150, '대형')
  (9, None, None)

== 2. NULL 을 찾을 때 ==

[2-A 단순 CASE 로 NULL 을 찾으면]
  id | amount | state
  (8, 150, '확정')
  (9, None, '확정')

[2-B 검색 CASE 에 IS NULL]
  id | amount | state
  (8, 150, '확정')
  (9, None, '미확정')

== 3. 행을 열로 돌린다 (수동 피벗) ==

[3-A 피벗 전 — 월·지점별 합계]
  sale_month | branch | total
  ('2026-01', '대구', 55)
  ('2026-01', '부산', 40)
  ('2026-01', '서울', 200)
  ('2026-02', '대구', 30)
  ('2026-02', '서울', 95)
  ('2026-03', '대구', None)
  ('2026-03', '부산', 150)
  ('2026-03', '서울', 60)

[3-B CASE 피벗 — ELSE 없음]
  sale_month | seoul | busan | daegu
  ('2026-01', 200, 40, 55)
  ('2026-02', 95, None, 30)
  ('2026-03', 60, 150, None)

[3-C CASE 피벗 — ELSE 0]
  sale_month | seoul | busan | daegu
  ('2026-01', 200, 40, 55)
  ('2026-02', 95, 0, 30)
  ('2026-03', 60, 150, 0)

[3-D CASE 피벗의 실행계획]
  QUERY PLAN
  |--SCAN sale
  `--USE TEMP B-TREE FOR GROUP BY

== 4. 건수를 셀 때 ==

[4-A COUNT(CASE ... THEN 1 END)]
  sale_month | seoul_cnt
  ('2026-01', 2)
  ('2026-02', 1)
  ('2026-03', 1)

[4-B COUNT(CASE ... THEN 1 ELSE 0 END)]
  sale_month | seoul_cnt
  ('2026-01', 4)
  ('2026-02', 2)
  ('2026-03', 3)

[4-C 같은 일을 FILTER 절로]
  sale_month | seoul_cnt | seoul
  ('2026-01', 2, 200)
  ('2026-02', 1, 95)
  ('2026-03', 1, 60)
