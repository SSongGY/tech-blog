# 예제 코드 — CASE WHEN

메모리 SQLite에 지점별 매출 9건을 넣고 `CASE`로 등급을 매긴 뒤, 같은 표를 지점을 열로 놓은
보고서로 돌린다. `WHEN` 순서, `ELSE` 유무, NULL 찾기, 피벗에서 `ELSE 0`을 쓸 때의 차이,
`COUNT`에 `ELSE 0`을 붙이는 실수를 차례로 찍는다. 외부 의존성 없이 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python case_when_pivot.py
```

## 바꿔볼 값

- `SALES`에 `(10, "2026-02", "부산", 70)`을 넣으면 3-B의 2월 `busan`이 `None`에서 70으로 바뀐다.
  3-C는 0에서 70으로 바뀐다. 두 결과가 달랐던 자리가 사라진다.
- 9번 행의 `None`을 숫자로 바꾸면 2-A와 2-B의 결과가 같아진다. 단순 CASE 가 NULL 을 못 찾는
  것은 값이 NULL 일 때만 드러난다.
- 3-B에 `'광주'` 열을 하나 더 붙여 본다. 없는 지점이라 모든 달이 `None`이다. 피벗은 열을
  질의에 적힌 대로 만들 뿐, 데이터에 어떤 값이 있는지 스스로 찾지 않는다.
