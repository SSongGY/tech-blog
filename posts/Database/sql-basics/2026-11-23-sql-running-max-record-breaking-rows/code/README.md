# 예제 코드 — 최고 기록을 갱신한 행 고르기

파이썬 표준 라이브러리(`sqlite3`)만 쓴다. 설치할 것이 없다.
Python 3.13.5, SQLite 3.49.1 에서 돌렸다. `dbshow.py` 는 표 정의와 데이터를 찍는 도우미다.

## 실행

```bash
python record_breaking_rows.py
```

## 바꿔 볼 값

- `mina` 의 4번 판 점수를 150 에서 151 로 바꾸면 [2]·[4] 의 결과가 같아진다. 동점이 없으면 `>` 와 `>=` 가 갈리지 않는다
- [3-2] 의 바닥값 `-1` 은 점수가 0 이상일 때만 맞다. 음수 점수가 있는 데이터에서는 `prev_best IS NULL` 쪽을 쓴다
- [5-1] 의 `ORDER BY played_on` 뒤에 `, play_id` 를 붙이면 같은 날 두 판의 순서가 정해져 결과가 매번 같아진다
- `GROUPS` 프레임은 SQLite 3.28.0 부터 된다. 그보다 낮은 판에서는 [5-2] 가 문법 오류를 낸다
- [7-3] 의 `total` 을 늘리면 `NOT EXISTS` 의 명령 수가 판 수의 제곱에 가깝게 늘어나는지 본다
