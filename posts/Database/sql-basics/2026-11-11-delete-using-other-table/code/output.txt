[discontinued]  2행
  컬럼       | 타입    | 제약
  -----------+---------+-----

  product_id
  ----------
          20
          40

[removed_pair]  2행
  컬럼       | 타입    | 제약
  -----------+---------+---------
  member_id  | INTEGER | NOT NULL
  product_id | INTEGER | NOT NULL

  member_id | product_id
  ----------+-----------
          1 |         30
          2 |         10

== 1) 다른 DB 의 문법을 그대로 쓰면 ==
  sql> DELETE c FROM cart_item c JOIN discontinued d ON d.product_id = c.product_id
  -> OperationalError: near "c": syntax error

  sql> DELETE FROM cart_item USING discontinued d WHERE d.product_id = cart_item.product_id
  -> OperationalError: near "USING": syntax error

  sql> DELETE FROM cart_item WHERE qty > 1 LIMIT 1
  -> OperationalError: near "LIMIT": syntax error

  sql> SELECT COUNT(*) AS limit_option FROM pragma_compile_options WHERE compile_options = 'ENABLE_UPDATE_DELETE_LIMIT'
  limit_option
  0

== 2) 단일 키 — 단종 상품을 담은 장바구니 행 지우기 ==
  sql> DELETE FROM cart_item WHERE product_id IN (SELECT product_id FROM discontinued)
  지운 행 2
  남은 행 (1,10) (1,30) (2,10) (2,30)

  sql> DELETE FROM cart_item WHERE EXISTS (SELECT 1 FROM discontinued d WHERE d.product_id = cart_item.product_id)
  지운 행 2
  남은 행 (1,10) (1,30) (2,10) (2,30)

== 3) 복합 키 — (회원, 상품) 짝으로 지우기 ==
  sql> DELETE FROM cart_item WHERE member_id IN (SELECT member_id FROM removed_pair) AND product_id IN (SELECT product_id FROM removed_pair)
  지운 행 4
  남은 행 (1,20) (3,20)

  sql> DELETE FROM cart_item WHERE EXISTS (SELECT 1 FROM removed_pair r WHERE r.member_id = cart_item.member_id AND r.product_id = cart_item.product_id)
  지운 행 2
  남은 행 (1,10) (1,20) (2,30) (3,20)

  sql> DELETE FROM cart_item WHERE (member_id, product_id) IN (SELECT member_id, product_id FROM removed_pair)
  지운 행 2
  남은 행 (1,10) (1,20) (2,30) (3,20)

== 4) 같은 표를 부질의에서 다시 읽기 ==
  상품을 두 개 이상 담은 회원의 행을 지운다. 지우는 도중에 다시 세면 마지막 행은 1이 되어 남는다
  sql> DELETE FROM cart_item WHERE (SELECT COUNT(*) FROM cart_item AS c2 WHERE c2.member_id = cart_item.member_id) >= 2
  지운 행 5
  남은 행 (3,20)

  평균보다 적게 담은 행을 지운다. 지우는 도중에 평균을 다시 내면 기준이 올라간다
  sql> SELECT AVG(qty) AS avg_qty FROM cart_item
  avg_qty
  2.6666666666666665

  sql> DELETE FROM cart_item WHERE qty < (SELECT AVG(qty) FROM cart_item)
  지운 행 3
  남은 행 (1,30) (2,30) (3,20)

== 5) 지우기 전에 같은 조건으로 센다 ==
  sql> SELECT COUNT(*) AS will_delete FROM cart_item WHERE product_id IN (SELECT product_id FROM discontinued)
  will_delete
  2

  sql> DELETE FROM cart_item WHERE product_id IN (SELECT product_id FROM discontinued)
  지운 행 2
  남은 행 (1,10) (1,30) (2,10) (2,30)
