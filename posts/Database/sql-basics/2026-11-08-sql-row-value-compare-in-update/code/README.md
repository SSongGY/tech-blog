# 예제 코드 — 행 값(row value)으로 여러 컬럼을 한 번에 다루기

파이썬 표준 라이브러리(`sqlite3`)만 쓴다. 설치할 것이 없다.

## 실행

```bash
python row_value.py
```

## 바꿔볼 값

- 2절의 `(2026, 3)` 을 `(2026, NULL)` 로 바꿔 어느 행이 NULL 판정으로 빠지는지 본다
- 4절 `quota` 표에 `(2026, NULL)` 행을 넣고 `NOT IN` 결과가 어떻게 변하는지 본다
- 5절 `UPDATE` 의 부질의가 0행을 돌려주도록 조건을 바꾸고, 두 컬럼에 무엇이 들어가는지 본다
