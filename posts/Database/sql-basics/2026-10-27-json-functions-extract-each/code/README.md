# SQLite JSON 함수 예제

표준 라이브러리만 쓴다. 메모리 DB 에 주문 표를 만들고 `payload` 컬럼에 JSON
문서를 넣은 뒤, 값을 꺼내고 배열을 펴고 인덱스를 태우는 과정을 차례로 찍는다.

## 실행

```bash
python json_demo.py
```

## 바꿔 볼 값

| 어디 | 무엇 | 보이는 것 |
|---|---|---|
| 7절 (가) `CREATE INDEX idx_status` | 이 줄을 지우고 돌리기 | 식 인덱스가 없을 때 같은 질의가 `SCAN` 으로 바뀐다 |
| 7절 (나) `->>` → `->` | 비교 연산자 쪽 표현을 바꾸기 | `->` 는 JSON 텍스트를 돌려주므로 `= 'paid'` 가 맞지 않는다 |
| `ORDERS` 의 `"tags": []` | 빈 배열에 값 넣기 | 4절 `json_each` 결과 행 수가 어떻게 달라지는지 |
| 8절 `'$.ship.zip'` | 4번 주문에 `zip` 추가하기 | 없는 경로와 `null` 값이 똑같이 `None` 으로 나오는 이유 |
