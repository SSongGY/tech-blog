# 피벗과 언피벗 예제

분기별 매출 행을 지역 한 줄로 펴고(피벗), 그 결과를 다시 행으로 되돌린다(언피벗).
SQLite 메모리 DB만 쓰므로 설치할 것이 없다.

## 실행

```bash
python pivot_unpivot.py
```

## 바꿔볼 값

- `ROWS` 에서 `("대구", 4, ...)` 행을 추가하면 4번 출력의 `q4_sum` NULL 이 사라진다.
  빈 칸이 왜 0 이 아닌지 확인하는 자리다.
- `PIVOT_CASE` 의 `SUM` 을 `MAX` 로 바꾸면 같은 지역·분기에 행이 둘 이상일 때
  결과가 달라진다. 합계인지 대표값인지를 집계 함수가 정한다.
- `UNPIVOT_JOIN` 의 `quarter_no` 에 `(5)` 를 넣으면 CASE 의 `ELSE` 가지가
  5분기까지 `q4` 로 받아 버린다. `ELSE` 를 `WHEN 4 THEN` 으로 바꿔 두면
  그 행의 값이 NULL 이 되어 WHERE 에서 걸러진다.
