# 예제 코드 — CROSS JOIN과 SELF JOIN — 언제 쓰는가

메모리 SQLite에 매장 2곳·매출 7건·직원 5명을 넣고, 빠진 날짜를 0으로 채우는 질의(`CROSS JOIN`)와
같은 표끼리 비교하는 질의(`SELF JOIN`)를 돌린다. 외부 의존성 없이 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python cross_and_self_join.py
```

## 바꿔볼 값

- `STORES`에 `(3, "분당점")`을 넣으면 1-A가 15행, 2-C가 15행이 된다. 분당점은 닷새 모두 0이다.
  2-A에는 분당점이 아예 나오지 않는다.
- `CALENDAR_CTE`의 끝 날짜를 `'2026-09-10'`으로 바꾸면 2-C가 매장당 10행으로 늘어난다.
- `EMPLOYEES`에 같은 부서 직원을 한 명 더 넣으면 5-A는 16행, 5-B는 12행, 5-C는 6행이 된다.
  n명이면 n², n(n-1), n(n-1)/2 로 늘어난다.
- 6-A와 6-B의 실행계획을 비교한다. `CROSS JOIN`으로 쓴 쪽은 `FROM`에 쓴 순서대로 표를 훑는다.
