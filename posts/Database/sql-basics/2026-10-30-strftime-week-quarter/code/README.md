# strftime 주차·분기 예제

SQLite 의 `strftime()` 포맷 문자와 날짜 수정자가 주차·분기 집계에서 어떤 값을 내놓는지
직접 돌려 확인한다. 추가 의존성이 없다. 파이썬 표준 라이브러리의 `sqlite3` 모듈만 쓴다.

## 실행

```bash
python strftime_demo.py
```

## 파일

| 파일 | 무엇 |
|---|---|
| `strftime_demo.py` | 본문에 실린 질의를 순서대로 돌린다 |
| `dbshow.py` | 표 정의와 데이터를 출력 앞에 찍는 도우미 |
| `output.txt` | 실제 실행 기록 (`blog.py run-example` 이 만든다) |

## 바꿔 볼 값

- `ROWS` 의 날짜를 다른 해의 연말·연초로 바꾸면 `%U` · `%V` · `%W` 가 갈리는 모양이 달라진다.
  2026-01-01 은 목요일이라 ISO 1주차에 들어가지만, 금요일로 시작하는 해(2027)는
  1월 1일이 전년도 53주차가 된다.
- 5번 절의 `'2026-01-31'` 을 2월이 29일인 해(2024-01-31)로 바꾸면 `+1 month` 의
  기본값이 어디로 넘어가는지 하루 차이로 달라진다.
- 6번 절은 이 환경(SQLite 3.49.1)에 없는 수정자를 모아 둔 것이다. 3.54.0 이상에서
  돌리면 `end of month` 와 `weekday -1` 이 값을 낸다.
