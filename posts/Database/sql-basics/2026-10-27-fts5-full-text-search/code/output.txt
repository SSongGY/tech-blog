스키마와 데이터 — 아래 질의는 전부 이 표를 대상으로 한다
================================================================
[note]  5행
  컬럼  | 타입    | 제약
  ------+---------+---------
  id    | INTEGER | PK
  title | TEXT    | NOT NULL
  body  | TEXT    | NOT NULL

  id | title         | body
  ---+---------------+--------------------------------------------
   1 | 백업 실패     | 야간 백업이 디스크 공간 부족으로 중단되었다
   2 | 공간 정리     | 오래된 로그를 지워 디스크 공간을 확보했다
   3 | 스위치 교체   | 네트워크 지연이 사라졌다
   4 | 인덱스 재생성 | 조회가 느려 인덱스를 다시 만들었다
   5 | 백업 재시도   | 백업 작업을 새벽으로 옮겨 다시 돌렸다

================================================================
1. LIKE 로 본문을 찾는다
================================================================
  LIKE '%디스크%'  -> [(1, '백업 실패'), (2, '공간 정리')]
  실행계획(detail 원문): SCAN note

  인덱스를 만든 뒤에도
    body LIKE '%디스크%'                             SCAN note USING COVERING INDEX idx_note_body
    body LIKE '야간%'                               SCAN note USING COVERING INDEX idx_note_body
    body = '네트워크 지연이 사라졌다'                        SEARCH note USING COVERING INDEX idx_note_body (body=?)

================================================================
2. 접두 LIKE 가 인덱스를 타는 조건
================================================================
  기본                       LIKE '야간%'  -> SCAN t
  case_sensitive_like=ON   LIKE '야간%'  -> SEARCH t USING COVERING INDEX i (v>? AND v<?)
  COLLATE NOCASE 인덱스       LIKE '야간%'  -> SEARCH t USING COVERING INDEX i (v>? AND v<?)

================================================================
3. FTS5 가상 테이블을 붙인다
================================================================
  MATCH '디스크'  -> [(1, '백업 실패'), (2, '공간 정리')]
  실행계획(detail 원문): SCAN note_fts VIRTUAL TABLE INDEX 0:M2

  FTS5 가 만든 표: ['note_fts', 'note_fts_config', 'note_fts_data', 'note_fts_docsize', 'note_fts_idx']

================================================================
4. 기본 토크나이저가 만든 토큰 — 한국어에서 가장 자주 걸리는 곳
================================================================
  토큰 31개
    공간  공간을  교체  네트워크  느려  다시
    돌렸다  디스크  로그를  만들었다  백업  백업이
    부족으로  사라졌다  새벽으로  스위치  실패  야간
    오래된  옮겨  인덱스  인덱스를  작업을  재생성
    재시도  정리  조회가  중단되었다  지연이  지워
    확보했다

  본문만 대상으로 같은 낱말을 세 가지로 찾아본다
    질의       MATCH 낱말     MATCH 낱말*    LIKE %낱말%   
    백업       [5]          [1, 5]       [1, 5]      
    로그       []           [2]          [2]         
    작업       []           [5]          [5]         
    지연       []           [3]          [3]         
    디스크      [1, 2]       [1, 2]       [1, 2]      

================================================================
5. 어디가 맞았는지 보여주는 함수
================================================================
  highlight(note_fts, 1, '[', ']')
    야간 백업이 [디스크] 공간 부족으로 중단되었다
    오래된 로그를 지워 [디스크] 공간을 확보했다

  snippet(note_fts, 1, '<', '>', '…', 4)
    야간 백업이 <디스크> 공간…
    오래된 로그를 지워 <디스크>…

  bm25 로 매긴 순서 (값이 작을수록 위)
    rowid=1  bm25=-0.4486  백업 실패
    rowid=5  bm25=-0.4486  백업 재시도
