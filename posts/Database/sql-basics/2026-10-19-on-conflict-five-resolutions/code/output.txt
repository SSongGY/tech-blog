스키마와 데이터 — 아래 질의는 전부 이 표를 대상으로 한다
================================================================
[inventory]  2행
  컬럼 | 타입    | 제약
  -----+---------+---------------
  sku  | TEXT    | PK
  qty  | INTEGER | NOT NULL
  note | TEXT    | DEFAULT '정상'

  sku   | qty | note
  ------+-----+--------------
  A-100 |  10 | 정상
  A-200 |  20 | 재고조사 대상

================================================================
1. 같은 배치를 다섯 가지 해결 방식으로 — 무엇이 남는가
================================================================
[(생략 = OR ABORT)]
  결과        IntegrityError: UNIQUE constraint failed: inventory.sku
  트랜잭션    열려 있음
  남은 sku    ['A-100', 'A-200', 'T-001']
  기존 A-100  qty=10  (원래 10, 배치가 넣으려던 값은 99)
  선행 T-001  남음
  앞선 B-010  사라짐
  뒤따른 B-030 사라짐

[OR ROLLBACK]
  결과        IntegrityError: UNIQUE constraint failed: inventory.sku
  트랜잭션    끝났음 (되감김)
  남은 sku    ['A-100', 'A-200']
  기존 A-100  qty=10  (원래 10, 배치가 넣으려던 값은 99)
  선행 T-001  사라짐
  앞선 B-010  사라짐
  뒤따른 B-030 사라짐

[OR ABORT]
  결과        IntegrityError: UNIQUE constraint failed: inventory.sku
  트랜잭션    열려 있음
  남은 sku    ['A-100', 'A-200', 'T-001']
  기존 A-100  qty=10  (원래 10, 배치가 넣으려던 값은 99)
  선행 T-001  남음
  앞선 B-010  사라짐
  뒤따른 B-030 사라짐

[OR FAIL]
  결과        IntegrityError: UNIQUE constraint failed: inventory.sku
  트랜잭션    열려 있음
  남은 sku    ['A-100', 'A-200', 'B-010', 'B-020', 'T-001']
  기존 A-100  qty=10  (원래 10, 배치가 넣으려던 값은 99)
  선행 T-001  남음
  앞선 B-010  남음
  뒤따른 B-030 사라짐

[OR IGNORE]
  결과        에러 없음
  트랜잭션    열려 있음
  남은 sku    ['A-100', 'A-200', 'B-010', 'B-020', 'B-030', 'T-001']
  기존 A-100  qty=10  (원래 10, 배치가 넣으려던 값은 99)
  선행 T-001  남음
  앞선 B-010  남음
  뒤따른 B-030 남음

[OR REPLACE]
  결과        에러 없음
  트랜잭션    열려 있음
  남은 sku    ['A-100', 'A-200', 'B-010', 'B-020', 'B-030', 'T-001']
  기존 A-100  qty=99  (원래 10, 배치가 넣으려던 값은 99)
  선행 T-001  남음
  앞선 B-010  남음
  뒤따른 B-030 남음

================================================================
2. REPLACE 는 고치는 것이 아니라 지우고 다시 넣는다
================================================================
[REPLACE 전]  rowid=2  qty=20  note='재고조사 대상'
[REPLACE 후]  rowid=3  qty=55  note='정상'

================================================================
3. REPLACE 와 NOT NULL
================================================================
[NOT NULL + DEFAULT]  REPLACE 로 NULL 을 넣으면 → '이름없음'
[NOT NULL, DEFAULT 없음]  IntegrityError: NOT NULL constraint failed: no_default.name

================================================================
4. 표 정의의 ON CONFLICT 와 문장의 OR — 누가 이기는가
================================================================
[표 정의 IGNORE, 문장은 그냥 INSERT]  남은 memo → '처음'
[문장에 OR REPLACE 를 적으면]        남은 memo → '문장의 OR REPLACE'

================================================================
5. IGNORE 가 건너뛰는 범위
================================================================
[OR IGNORE 로 4행 투입 — NULL 1행, CHECK 위반 1행 포함]  남은 행 → [(1, 10), (4, 40)]
