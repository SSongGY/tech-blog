# 예제 코드 — 날짜와 시간 다루기: 저장과 연산

메모리 SQLite에 주문 6건을 넣는다. 주문 시각은 일부러 형식을 섞었다(`2026-9-5`, `2026/09/28`, 시각 없는 날짜).
1절에서 그대로 정렬·비교해 틀리는 것을 보고, 2절에서 ISO 8601로 고친 뒤 다시 본다.
3~7절은 저장 형태(TEXT·REAL·INTEGER), 수식어로 더하고 빼기, 차이 구하기, `strftime`, 시간대 표기를 돌린다.
파이썬 표준 라이브러리만 쓴다.

`unixepoch()`는 SQLite 3.38.0, `timediff()`는 3.43.0, `floor`·`ceiling` 수식어는 3.46.0부터 있다.
그보다 낮은 판에서는 해당 줄이 에러를 낸다.

## 실행

```bash
python date_time_basics.py
```

## 바꿔볼 값

- 4-B의 `'2026-01-31'`을 윤년인 `'2028-01-31'`로 바꾸고 `+1 month`가 어디로 가는지 본다.
- 1-B의 끝값을 `'2026-09-30 23:59:59'`로 바꾸면 6번(`2026-09-30`)과 5번이 둘 다 잡히는지 본다.
- 7-A에 `'localtime'` 수식어를 붙여 이 PC의 시간대로 바꿔 본다. 실행 환경에 따라 결과가 달라진다.
