# 예제 코드 — UUID v4·v7 기본키와 B-Tree 채움률

표준 라이브러리만 쓴다. 행 10만 개를 정수·UUID v4·UUID v7 키로 각각 넣고,
파일을 직접 읽어 B-Tree 마다 리프 페이지 수와 채움률을 센다.

## 실행

```bash
python uuid_pk_btree.py
```

## 파일

| 파일 | 무엇 |
|---|---|
| `uuid_pk_btree.py` | 본문 출력을 내는 스크립트 |
| `output.txt` | `blog.py run-example` 이 남긴 수행 기록 |

## 바꿔볼 값

- `ROW_COUNT` — 늘리면 v4 의 삽입 시간이 캐시를 넘는 지점에서 더 벌어진다
- `ROWS_PER_MS` — v7 에서 같은 밀리초에 들어오는 행 수. 크게 하면 그 안의 무작위 꼬리가 길어진다
- `SEED` — 키를 만드는 난수 시드. 바꿔도 채움률은 거의 같아야 한다

파이썬 3.13 의 `uuid` 모듈에는 `uuid7()` 이 없어 RFC 9562 §5.7 의 비트 배치대로 직접 만든다.
삽입 시간은 디스크와 캐시에 따라 흔들리고, 페이지 수와 채움률은 시드가 같으면 같다.
