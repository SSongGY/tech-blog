# 예제 코드 — WAL 프레임을 바이트로 읽기

임시 폴더에 WAL 모드 SQLite 파일을 만들고, 커밋할 때마다 `app.db`와 `app.db-wal`의 크기와
내용을 확인한다. WAL 헤더·프레임 헤더를 파일 포맷 명세대로 해석하고 누적 체크섬을 직접 계산한다.
연결을 열어 둔 채 파일을 복사해 비정상 종료 상황을 만들고, 복사본에서 어떤 커밋이 살아남는지 본다.
외부 의존성 없이 파이썬 표준 라이브러리만 쓴다. 임시 폴더는 끝나면 지워진다.

## 실행

```bash
python wal_frames.py
```

## 바꿔볼 값

- `PAGE_SIZE`를 `1024`로 바꾸면 프레임 하나가 1,048바이트가 되어 WAL 파일 크기가 줄어든다.
- `PRAGMA wal_autocheckpoint = 0` 줄을 지우면 기본값(1,000페이지)으로 돌아가는데, 이 예제는 프레임이 적어 결과가 같다.
- `corrupt_at`을 마지막 커밋 프레임이 아니라 프레임 0의 위치로 옮기면 5-C에서 살아남는 커밋이 더 줄어든다.
