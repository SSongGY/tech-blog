# 커밋 횟수 측정 예제

표준 라이브러리만 쓴다. 측정 조합마다 임시 폴더에 새 `.db` 파일을 만들고 1만 건을
넣은 뒤, 걸린 시간과 WAL 파일 크기·프레임 수를 찍는다. 끝나면 폴더째 지워진다.

시간은 디스크와 OS 캐시 상태에 따라 흔들린다. 절대값이 아니라 **조합 사이의
배수**를 본다.

## 실행

```bash
python commit_batching.py
```

## 바꿔 볼 값

| 어디 | 무엇 | 보이는 것 |
|---|---|---|
| `ROWS` | 1만 → 10만 | 커밋 1회 쪽은 거의 선형으로 늘고, 1만 회 쪽은 fsync 횟수가 그대로 따라붙는다 |
| 2절 `synchronous` | `NORMAL` 과 `FULL` | WAL 모드에서 커밋마다 fsync 를 하느냐가 만드는 차이 |
| 3절 `journal_mode` | `DELETE` → `TRUNCATE` | 커밋마다 저널 파일을 지우는 대신 길이만 0으로 만들 때 |
| 4절 `wal_autocheckpoint` | `0` → `100` | WAL 파일이 어느 크기에서 멈추는지 |
