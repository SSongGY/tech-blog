  이름                  | 대상 표 | 정의
  ----------------------+---------+------------------------------------------------------------
  ix_post_created_at_id | post    | CREATE INDEX ix_post_created_at_id ON post (created_at, id)

한 페이지 10행 · 시간은 5회 실행의 중앙값

-- 1. 실행 계획
   OFFSET
   QUERY PLAN
   `--SCAN post USING INDEX ix_post_created_at_id
   키셋 — 행 값 비교
   QUERY PLAN
   `--SEARCH post USING INDEX ix_post_created_at_id (created_at<?)
   키셋 — OR 로 풀어 쓴 조건
   QUERY PLAN
   `--SCAN post USING INDEX ix_post_created_at_id
   키셋 — created_at 만 비교
   QUERY PLAN
   `--SEARCH post USING INDEX ix_post_created_at_id (created_at<?)

-- 2. 페이지 깊이별 비용 (명령 개수 / 시간 중앙값 ms) — 결과가 OFFSET 과 같은가
   키셋 A = 행 값 비교
   키셋 B = OR 로 풀어 쓴 조건
   키셋 C = created_at 만 비교
   건너뛴 행 |            OFFSET |          키셋 A   |          키셋 B   |          키셋 C

         100 |       391   0.012 |       165   0.013 = |       719   0.017 = |        83   0.011 =
