# 예제 코드 — NULL이 인덱스, 집계, 비교에서 각각 다르게 동작하는 이유

주문 표 하나로 NULL이 비교·묶기(GROUP BY·DISTINCT·UNION·ORDER BY)·UNIQUE·집계에서 각각 어떻게
다뤄지는지 찍는다. 마지막에는 NULL이 90%인 20만 행 표에 일반 인덱스와 부분 인덱스를 걸어
실행계획과 파일 크기를 비교한다. 임시 폴더에 DB 파일을 만들었다가 지운다.
외부 의존성 없이 파이썬 표준 라이브러리만 쓴다.

## 실행

```bash
python null_four_rules.py
```

## 바꿔볼 값

- `NULL_RATIO` 를 `0.1` 로 낮추면 부분 인덱스와 일반 인덱스의 크기 차이가 거의 사라진다.
- `ORDERS` 의 6번 주문 금액을 `0` 으로 바꾸면 4-A의 `COUNT(amount)` 가 6이 되고 `AVG` 가 낮아진다.
- 5-G의 `IS NULL` 을 `= 'C0042'` 로 바꾸면 강제한 부분 인덱스로 실행된다.
