# 예제 코드 — LSM 트리 압축 방식별 증폭 세기

파이썬 표준 라이브러리만 쓴다. 난수 시드는 고정(`20261108`)이다.

## 실행

```bash
python lsm_compaction.py
```

## 바꿔볼 값

- `LEVEL_MULTIPLIER` 를 4 로 낮춰 레벨 수가 늘고 쓰기 증폭이 어떻게 변하는지 본다
- `TIER_TRIGGER` 를 8 로 올려 크기 계층 쪽의 쓰기 증폭과 run 수가 어떻게 맞바뀌는지 본다
- `experiment` 의 키 공간을 5,000 으로 줄여 갱신이 더 몰릴 때 공간 증폭이 어디까지 가는지 본다
